> 「实测」= 本目录跑出；「推断」= 由数字推出。`PREREG.md` 跑前写死（mtime 早于首个训练进程），跑完未改。

## 1. 2AFC 定义（PREREG §1 原文）+ 机会的实测值

- **定义**：`pair_2afc = #{ argmax(l_A[s],l_A[t]) = s ∧ argmax(l_B[s],l_B[t]) = t } / n`
  —— 受限到该对两个 gold，**两侧各自选中自己的 gold**；平局取靠前索引（torch argmax 语义）。
  **n = 280** held-out 对（b1 260 / b2 20）；配对 = `b_pairs.jsonl` 行内相邻 `_src`+`_variant`，
  袋多重集相同、骨架不同；**按对整体切分**（方向内 md5 分层 10/10）⇒ 两侧永不同 split，句面/袋元组零交叉（跑前+跑后断言全过）。
- **机会_R 独立均匀随机猜（实测）**：MC **2000 轮 × 280 对**、seed 20261007 ⇒ **均值 .249337**（rep_sd .02544、se_of_mean .00057）；
  判据用 SE 沿用既有口径 `sqrt(0.25/n) = .029881`。
- **机会_P 置换零模型（实测）**：取该臂**本臂 logits**，对 pair 下标置换 **1000 次**（seed 同上，同侧对同侧、gold 用第 i 对）⇒ **均值 .0926 ± .0165**（各臂 .072–.100）。
- **盲/常值预测器（实测，同一代码路径）= .0000**（两侧同 logits ⇒ 受限 argmax 同侧 ⇒ 恒 0）。
- **门槛（PREREG 写死）** = max(.249337+2×.029881, .092561+2×.00052) = **.309099**；40 类 argmax 门槛 = .5+2SE = **.559761**。

## 3. M0–M5 逐条实测 + 判定 + 机制

- **M0 过**：三个零假设全部**实测**（上 .2493 / .0926 / .0000），未引用 .25 或 .5。
- **M1（主）过**：MP .5571/.5643、MP+ .5821/.5929 均 **> .3091**、**两 seed 同号**；b1 单列 .5769–.6231 同样过。
- **M2 未过**：40 类 argmax M .1464/.1536、MP .0321/.0321、MP+ .1500/.1643，**全部 < .5598**；
  与 P4 对账同判（P4：M 0/0、MP 0/0、MP+ .0192/.0173、门槛 .5439 ⇒ 判无效），本单元绝对值更高（域内训练）。
- **M3 过（必报齐）**：地板见主表下（逐规则 + `max_naive_complete` = .1786 并列报出，未只取单值）；`n_slots` 的 L/非 L 已分列。
- **M4 过**：三臂 × 两 seed 随机标签 2AFC **.0643–.0929 ≤ 机会_R − 2SE = .1895**；配对 SE（真 − 随机标签）= **+.468…+.529，t = +13.8…+16.5**；数字实测，其解释为**推断**：随机标签臂掉到机会**以下**而非「掉回多数类」，因该模型两侧预测相关 ⇒ 独立猜 .25 并不是它的零点（这正是 Lead 抽查时口径不自洽的来源）。
- **M5 过（必报齐）**：`shuffle_content`（幸存 **278/280** 对，fail-closed 剔 4 侧）2AFC **不掉**：
  M .5683→.5683 / .5504→.5468；MP .5612→.5612 / .5683→.5719；MP+ .5827→.5755 / .5935→.5935；
  `shuffle_all` 落到 **.1893–.2429**（≤ 机会_R）；`aux_only` **不适用**（本模型无标签通道），替代列 = `n_slots` 查表（2AFC 恒 0）。
- **判定（三选一）＝ 3「两口径矛盾需澄清」**：M1 过 ∧ M2 未过 ⇒ 两口径结论相反（PREREG §6 预写分支），**不硬选**。
- 补充实测（防误读）：**M 臂 2AFC 也过门槛**（.5679/.5500）；臂间**配对 SE** —— 2AFC 上 MP−M = −.011/+.014（t=−.36/+.50，**两 seed 不同号**）、MP+−M = +.014/+.043（t=.73/2.21）⇒ **未测出「配对监督在 2AFC 上显著优于常规监督」**（≠「没有效果」）；40 类上 MP−M = **−.114/−.121（t=−5.6/−5.8）显著更差**，MP+ ≈ M（ns）。
- **机制（推断，按 PREREG 预写规则）**：`shuffle_content` 不掉 + `shuffle_all` 落回机会 ⇒ 2AFC 信号来自**结构字面（功能词/标点/槽序），不依赖内容词**；P20「结构进了表示」在此口径上被读出，但绝对分类（40 类）仍远未达标。
