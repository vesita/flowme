## 0. 要回答的唯一问题

**现有 5 张卡有没有「拒答出口」？给它不属于自己领域的输入，它会不会照样开火？**

背景：元决策在本项目已被两次证伪（路由 98.83%→9.19%，输入类型 91.67%→29.78%，
均低于多数类基线）。拒答同属元决策族，**先验上可能同病** ⇒ 本实验只负责测出数字。

## 2. 「开火」的定义（测量函数）

- **开火** = `engine.predict(text, tasks=[card])` 在该样本上返回 **≥1 条锚点**（`pred_cls != 0` 才会被 append，
  类 index 0 即背景类，见 `plugin.py:57`「index 0 是背景类（不发射切片）」）。
- **不开火** = 该卡在该样本上吐 0 条锚点 = 事实上的「不适用 / 拒答」。
- **开火率** = 组内开火样本数 / 组内样本数。
- **bg_fp** = 组 A（分布内背景样本）的开火率（背景本该不开火）。

## 3. 分组与规模（写死）

- **组 A（分布内背景）**：该卡自己的 `build_dataset(...)` 样本里 `spans == []` 的背景样本。
  ⚠ 这 5 张卡的 `build_dataset` **没有 `split` 参数**（只有 cloze_fill / reply_pick 有），
  故沿用本仓库既有 eval 口径：`random.Random(42).shuffle(data)` 后取前 `max(200, len//10)` 作 val
  （与 `experiments/core_branch/eval_old_cards_branch.py:val_split` 同构），再筛背景样本，**取前 200 条**。
  各卡 `build_dataset(6000)`。
- **组 B（分布外，三个子集）**：
  - **B1 交叉背景**：其余 4 张卡 val split 的背景样本各 **50 条**（该卡领域外的输入）；
  - **B2 对抗路由**：`experiments/adversarial_routing/adversarial.jsonl` 中 `true_label != 该卡` 的行，取前 **200**；
  - **B3 输入类型对抗**：`experiments/input_type/adversarial.jsonl` 的 `text`，取前 **200**。
  - **组 B 池化** = B1∪B2∪B3；**B1/B2/B3 各自单独报**。
- 样本去重按文本字面；组内条数不足则全取并如实报数。

## 4. 预注册判据（跑前写死，不许改）

- **P1（拒答成立）**：对**每张卡**，`fire(B池化) ≤ fire(A) + 0.10`。任一张卡违反 ⇒ P1 不成立。
- **P2**：**逐卡报分项**（不许只报平均），并报**最差的那张卡**（Δ = fire(B) − fire(A) 最大者），
  它是架构的下限。
- **P3（对「全开火」基线）**：`fire(B池化) ≤ 0.85` 且逐卡均 ≤ 0.85。
  阈值 0.85 = 至少拒掉 15% 的分布外输入；若只比 100% 低 2~3pt，「拒答出口」等价于不存在。
  （「全开火」= 100%，是本任务的多数类基线式对照：多数类就是"永远开火"。）
- **确定性（显式决策前提）**：全部样本跑**第二遍**，逐样本 `sha256(JSON(result, sort_keys=True))` 必须
  **100% 逐字一致**；不一致则「显式决策」这条的前提不成立，判定降为**证据不足**。
- **已知答案对照（测量函数自检）**：
  - **L1 机械对照**（必须 100%）：`fire([]) == False`、`fire([一条锚点]) == True`；
    对 3 条真实 `predict` 返回，人工数出的切片数与测量函数读到的锚点数**逐条一致**。
  - **L2 模型已知答案对照**（10 条手挑）：**「该开火」组必须全中**，总符合率 ≥ 8/10；
    未达 ⇒ 判 **证据不足**，不给拒答结论。
- **判定三选一**：
  - `拒答成立` ⟺ P1 ∧ P2(报告完整) ∧ P3 ∧ 确定性 ∧ 对照通过；
  - `证据不足` ⟺ 对照或确定性未过、或关键数据缺失；
  - `拒答不成立（分布外照样开火）` ⟺ 对照通过但 P1 或 P3 不成立。
- **若判不成立 ⇒ 推论（与 dev-notes/15 §9 铁律 1 同源）**：拒答也必须**显式化**，
  由调用方或确定性规则决定，不能指望模型自己在分布外闭嘴。

## 5. 附加测量（非判据，只报数）

- **置信度校准曲线**：按样本内**最高锚点 confidence** 分桶 `[0.5,0.6) … [0.9,1.0]`，
  组 A / 组 B 分别报 `开火率 / 样本数 / 平均 confidence`。
- **闭合性**：`compose.filter` / `compose.pair` 产物 vs 卡（引擎）产物的**键集、区间语义、类型**代码检查，
  外加**一次真实组合调用**（sentiment × negation）并尝试把产物**回喂** `to_items` / `filter` / `render`。
- **可溯源**：清点 `engine.predict` 返回的全部字段，对照 `(module_id, 输入, 参数)` 三元组，缺什么如实写。
