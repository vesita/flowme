# 输入类型分类不变量验证（E-A / P-类型）

**唯一问题**：冻结基座表征上的类型判别头，能否在对抗集上守住 dev-notes/15 §2 的输入侧不变量？
任何输入必须先被判成一个显式类型（含「未知」出口）；置信度不足 ⇒ 判「未知」且不得进功能头。

> §1–§5 在跑探针**之前**写死（预注册），事后不改；结果填在 §6–§8。
> 「实测」= 本目录跑出来的数字；「推断」= 由数字推出；「口径判断」= 构造时人为规定的标签归属。

## 1. 类型定义与判别式（4 + 1 类，fail-closed）

类型由**输入整体要求处理什么结构**决定；句中「提及」某结构不算该结构（这是 A1–A3 的口径基础）。

| 类型 | 判据（`labeler()`，`build_data.py` L60-L97，任何文本都能给出闭集 5 类之一） |
|---|---|
| `candidates` | 有 `\|1）…\|4）` 恰好按序完整、无空条目、头部无空位、无空位落在候选条目、非顶层多轮 |
| `cloze` | 选择族（有候选列表）：完整列表 + **头部**有空位（`__`/`＿＿`）且条目里无空位；无列表时：有非标识符空位 ⇒ 仍是填空 |
| `multi_turn` | 顶层结构：首行是说话人标记行且 ≥2 个说话人行（说话人闭集：用户/模型/助手/客服/医生/顾客/老师/学生/甲/乙/A/B + `：`） |
| `unknown` | ① 长度 <4 / 无汉字 / 含 U+FFFD；② 候选列表不完整、超量、缺号或有空条目（`\|\d）` 后紧跟 `\|` 或结尾）；③ 空位落在候选条目里（结构错位） |
| `plain` | 以上皆非（普通陈述句） |

- **fail-closed 在哪**：`labeler` 是全函数，无 fallback 分支；构建时任一行 `labeler != 真值` 直接 `AssertionError`；
  每类条数 <40、四份数据有重复文本、对抗样本 `naive == true`（不具对抗性）、ID 非 unknown 样本 `naive != true`（表面有歧义）也全部抛错。**构造不出足量样本就报错，不静默降级。**
- **辅助判据** `naive()`（表层捷径，顺序：有 `_`/`＿` ⇒ cloze；有 `N）` ⇒ candidates；有说话人 `：` ⇒ multi_turn；否则 plain）：
  对抗集要求每行 `naive != true_label`；分布内非 unknown 样本要求 `naive == true_label`（表面无歧义，歧义全部集中在对抗集）。
- **空位口径**：选择族内任何 `__`/`＿＿` 都算空位（`119__`、`6x__` 在真卡样本里合法）；
  无列表时 `__` 紧贴 ASCII 字母 = 标识符成分（`__init__`/`user__name`）不算空位，紧贴汉字/数字算；`＿＿` 恒算空位。
- **引号转述多轮对话的口径（A3）**：以顶层结构为准 —— 外层是叙述句 ⇒ `plain`；即使引号内有换行与说话人标记。
  与之对偶：ID `multi_turn` 必须首行就是说话人标记行。全数据集保持一致（`labeler` 只看顶层）。

## 2. 数据集规模与分布（`stats.json`，全部 fail-closed 校验过）

| 文件 | 规模 | 分布 | 构造 |
|---|---|---|---|
| `id_train.jsonl` | 2000 | 5 类 × 400 | 池：plain/multi_turn 取自 `resolve_corpus_files(*dialogue.txt)`；candidates/cloze 取 `reply_pick`/`cloze_fill` 的 `build_dataset`；unknown 走 F1 规则族（残缺 155 / 混合 105 / 乱码 81 / 空短 59） |
| `id_test.jsonl` | 600 | 5 类 × 120 | 与训练**同构造分布**：同一池、同一规则族，`SPLIT_SEED=20240927` 洗牌后切片（前 400 训 / 后 120 测） |
| `adversarial.jsonl` | 225 | plain 135 / unknown 90 | 5 规则 × 45，模板与填充池独立，见 §3 |
| `known_answers.jsonl` | 15 | 5 类 × 3 | 手写定稿，不参与训练，见 §5 |

**不重合性**（构建期断言，实测全 0）：train∩test / train∩adv / test∩adv / adv∩ka = 0（逐文本精确匹配）；
四份文件并集大小 = 2840 = 各自之和。对抗集与已知答案的模板/填充全部手写，训练池里不存在；
unknown 训练样本用 **F1 头部措辞**（`选项|`/`回答|`/`题目：`…），对抗集用 **F2 措辞**（`问：…`）——
同规则族、留出模板，避免「对抗集只是训练分布的重复」。

**多数类基线（跑前算死）**：分布内测试集 = 120/600 = **20.0%**；对抗集 = 135/225 = **60.0%**（plain）。

## 3. 对抗集构造规则（5 规则 × 45 = 225，逐条 `rule`/`template_id`/`naive_label` 可追溯）

| 规则 | 表面像 A（naive） | 真值 B | 构造与校验 |
|---|---|---|---|
| `adv_plain_mentions_candidates` | candidates | plain | 陈述句里**提到**编号格式 `1）…2）`（无管道符）；断言 naive=candidates、labeler=plain |
| `adv_plain_underscore_id` | cloze | plain | 下划线是标识符成分（`__init__`/`user_name`/`MAX__COUNT`）；断言 naive=cloze、labeler=plain |
| `adv_plain_quoted_dialogue` | multi_turn | plain | 引号/叙述框架里**转述**多轮对话（15 条含换行、首行仍是叙述句）；断言 naive=multi_turn、labeler=plain |
| `adv_truncated_candidates` | candidates | unknown | 列表截断/缺号/超量/空条目（F2 模板）；断言 naive=candidates、labeler=unknown |
| `adv_mixed_cand_cloze` | cloze | unknown | 完整候选列表但空位落在**候选条目**里（既非择优也非填空）；断言 naive=cloze、labeler=unknown |

样例（每类 2 条原文，取自 `adversarial.jsonl`）：

```
adv_plain_mentions_candidates  他写了 1）加班 和 2）休息 两个选项，最后交了白卷。
                               评论区吵翻了，有人站 1）早起，有人站 2）跑步。
adv_plain_underscore_id        Python 里 __init__ 方法在对象创建时会被自动调用，别写重复的构造逻辑。
                               这个字段叫 user_name，之前有人写成 username 结果对不上。
adv_plain_quoted_dialogue      他复述了那场争论：“用户：你听我说完。模型：我听得清楚。”说完就不再提了。
                               他在群里贴了一段转述：\n用户：明天再说吧\n模型：那就定下来\n然后补了一句“就这么回事”。
adv_truncated_candidates       问：明早的班车几点发|1）六点开门|2）九点才有
                               问：这道菜要不要焯水|1）七点检票|2）坐地铁最快|3）
adv_mixed_cand_cloze           问：明早的班车几点发|1）六点开门__九点才有|2）打车太贵|3）周末有空|4）八点发车
                               问：周末去哪儿玩合适|1）爬山|2）逛展__宅家|3）加班|4）钓鱼
```

## 4. 探针口径（复用 `experiments/adversarial_routing/probe_e4_style.py`）

冻结 `checkpoints/base_encoder.pt` → `NanoDocEncoder`；有效 token `doc_memory` mask-mean-pool，D=128；
零初始化单层逻辑回归（5 类），AdamW lr=0.05、wd=1e-4、200 epoch、batch 64；**seed 42/43**（数据文件固定，seed 只改探针初始化与批次序）。
训练只用 `id_train.jsonl`；同一探针评 ① `id_test.jsonl` ② `adversarial.jsonl` ③ `known_answers.jsonl`。
命令：`uv run python experiments/input_type/run_probe.py --seeds 42,43`（GPU，裸 `uv run python`）。

## 5. 判据与对照（**跑前写死，事后不改**）

设 `id` = 分布内测试集准确率，`adv` = 对抗集准确率，`U` = 对抗集上 `unknown` 类召回（拒答出口代理指标）：

- **P1**：`adv ≥ id − 10pt`；
- **P2**：`U ≥ 0.70`；
- **P3**：`adv > 60.0%`（对抗集多数类基线 M_adv；不高于它 = 与瞎猜不可区分）；
- **两 seed（42/43）同号才下结论**。判定三选一：
  **① 不变量成立** = P1∧P2∧P3 在两 seed 全通过；
  **② 不变量不成立（诊断：模型判不了类型）** = 存在某条判据在两 seed **都**不通过；
  **③ 证据不足** = 其余情况（某判据只在一个 seed 通过）。
  若判②，直接推论：**类型应由调用方显式声明**，而不是靠模型判。

| 对照 | 做法 | 有效性声明 |
|---|---|---|
| 多数类基线 | 分布内 20.0% / 对抗集 60.0%（跑前算死） | 无条件成立 |
| 打乱标签 | 训练标签 randperm 后重训同一探针 | 有效（破坏 X–Y 对应）；逐 seed 噪声大，只作方向性证据 |
| 随机高斯特征 | 特征整体换 N(0,1)，标签不变 | 有效且独立（剥离全部语言结构） |
| 正交阵随机投影 | **不用** | dev-notes/11：精确保持余弦，不构成独立证据，明确弃用 |
| 已知答案 15 条 | 5 类 × 3，人工定稿（`known_answers.jsonl`），先于结论出数 | 标注质量对照；探针在其上出错不改判据，只说明错误性质 |

已知答案 15 条在跑探针前逐条人工复核：标签与 §1 口径一致（3 plain 结构无标记 / 3 candidates 列表完整 /
3 cloze 头部空位 / 3 multi_turn 首行说话人 / 3 unknown = 残缺、混合、乱码）。

## 6. 实测结果（2026-10-06 跑完；2 seed，数据文件固定）

命令与耗时（GPU，裸 `uv run python`）：

```
uv run python experiments/input_type/build_data.py          # 40.8s，fail-closed 全过
uv run python experiments/input_type/run_probe.py --seeds 42,43   # 24.0s，日志 logs/input_type_probe.log
```

产物：`id_train.jsonl` / `id_test.jsonl` / `adversarial.jsonl` / `known_answers.jsonl` / `stats.json` / `results.json`。

### 6.1 主表（均值 + 两 seed 原值）

| 指标 | seed 42 | seed 43 | 均值 | 判据线 |
|---|---|---|---|---|
| ① 分布内测试集 acc（5 类，n=600） | 92.33% | 91.00% | **91.67%** | 多数类 20.0% |
| ② 对抗集 acc（n=225） | 27.56% | 32.00% | **29.78%** | 多数类 **60.0%** |
| ②−① 跌幅 | −61.9pt | −59.0pt | **−60.4pt** | P1 允许 −10pt |
| ② 上 `unknown` 召回（P2） | 0.567 | 0.711 | **0.639** | ≥0.70 |
| ⑤ 已知答案 15 条 | 10/15 | 10/15 | **66.67%** | 标注质量对照 |
| ③ 打乱标签 · 分布内 / 对抗 | 13.8% / 15.1% | 19.0% / 8.4% | 16.4% / 11.8% | 机会水平附近 |
| ④ 随机高斯特征 · 分布内 / 对抗 | 21.7% / 13.8% | 23.2% / 19.1% | 22.4% / 16.4% | 贴 20% 机会水平 |
| 正交阵随机投影 | 未采用 | 未采用 | — | 明确弃用（不充数） |

③④ 两条空洞对照都落在机会水平，主臂 29.78% 虽高于对照但 **远低于 60% 多数类基线** ⇒
对抗集上存在一点信号，但方向系统性错误（见 6.2），不是随机乱猜、也到不了可用。

### 6.2 对抗集分规则明细（两 seed）

| 规则（表面 → 真值） | acc 42 / 43 | 预测跟随表层 naive 的比例 | 主要预测去向 |
|---|---|---|---|
| 引号转述多轮 multi_turn → plain | **0.0% / 0.0%** | 100% / 100% | 100% 判 `multi_turn` |
| 提到候选格式 candidates → plain | 11.1% / 6.7% | 48.9% / 40.0% | `candidates` 49%/40%、`cloze` 33%/40% |
| 标识符下划线 cloze → plain | 13.3% / 11.1% | 40.0% / 35.6% | `cloze` 40%/36%、`multi_turn` 29%/36% |
| 截断候选 candidates → unknown | 33.3% / 48.9% | 64.4% / 48.9% | `candidates` 64%/49% |
| 混合 cloze → unknown | 80.0% / 93.3% | 20.0% / 6.7% | `unknown` 80%/93% |

- 分布内分类型召回（42/43）：plain 0.908/0.875、candidates 0.933/0.858、cloze 0.942/0.942、multi_turn 0.958/0.975、unknown 0.875/0.900。
- 混合规则之所以能对（86.7%）：训练里有**同族** unknown（F1 混合 105 条）；截断规则只对 41.1%（F2 留出措辞）。
- 引号转述 0% 且 100% 判 multi_turn ⇒ 与路由实验同病：**按表层特征系统性答错**，不是噪声。

### 6.3 已知答案 15 条（先于结论出数，两 seed 逐条一致）

10/15 对；错的 5 条：`ka-01` plain→unknown；`ka-03/04/05` 手写 candidates **全部**→unknown；
`ka-13` 混合 unknown→candidates。标签经复核与 §1 口径一致 ⇒ **探针问题**（对没见过的问句措辞“过度拒答”），
不是标注问题；判据不改。该错误方向与 P2 相反 —— 探针既会漏拒（对抗集 A1–A3 判进功能头），
也会误拒（手写候选输入判 unknown），两头都不稳。

### 6.4 探索性（**未预注册**）：置信度门限能否救回不变量

对 softmax 最大置信度扫 τ=0.00~1.00（步 0.05），低于 τ 改判 unknown：
**两 seed 全网格无任何一个 τ 使 P1∧P2∧P3 同时成立**。τ 升到 0.95 时 unknown 召回
0.57→0.70（seed42）/ 0.71→0.83（seed43），但对抗集 acc 只从 27.6%→31.6% / 32.0%→35.1%，
仍远低于 60% 基线；τ=1.0 是「全部判 unknown」的退化点，对抗集 acc = 40.4%（恰等于 unknown 占比），
分布内 acc 同时崩到 51.5%，P1/P3 依然双双不过。该结果只作讨论，不参与 §5 判定。

## 7. 判定（按 §5 预注册判据）

- **P1**（adv ≥ id−10pt）：27.56% < 82.33%、32.00% < 81.00% ⇒ **两 seed 都不通过**（跌 59~62pt）。
- **P2**（unknown 召回 ≥0.70）：0.567 ✗ / 0.711 ✓ ⇒ 两 seed 不同号：既不满足「两 seed 全过」也未触发「两 seed 都不过」，按 §5 规则**该条单独看属证据不足**，不参与触发。
- **P3**（adv > 60.0%）：29.78% ≪ 60% ⇒ **两 seed 都不通过**。

⇒ 命中「存在判据在两 seed 都不通过」⇒ 三选一判 **② 不变量不成立（诊断：模型判不了类型）**。

**推论（dev-notes/15 §2 预先写好的出路）**：**输入类型应由调用方显式声明（或用确定性规则门禁判），
而不是靠模型判。** 本实验的真值本身即由 30 行确定性字符串规则 `labeler()` 给出，2840/2840 条自洽、
fail-closed —— 类型是文本的**显式结构属性**，规则可判而模型判不了；把类型判定塞进模型，
换来的是「引号转述 100% 送进多轮头、手写候选 100% 被拒答」这种静默误路由，正是该不变量想防的违反症状。
E-D 的调用计划不应依赖模型自判类型。

## 8. 遗留与不确定

- **实测**：§6 全部数字（2 seed、同一份固定数据文件；特征两 seed 共用只提一次，seed 只改探针初始化与批次序，管线确定性）；构建期 fail-closed 断言 2840 条全过、四份数据零重合；对照臂贴机会水平。
- **口径限制（推断）**：结论只对「冻结基座表征 + 线性探针 + mean-pool」成立，不等于更大类型头的端到端行为（未实测）；但该口径正是本项目已被验证的探针口径，与路由实验同构，可比。
- **对抗集标签空间偏斜（推断）**：5 条规则的真值只落 plain/unknown 两类，多数类基线 60% 偏高，P3 因此偏严；但 P1（−10pt）与 P2 不受影响，且 A3 类 0% 远低于任何门槛 ⇒ 判定不依赖 P3 单独成立。
- **A3 口径是判断不是事实（口径判断）**：引号转述判 plain 是「顶层结构」口径；若改判 unknown，
  这 45 条的**对错不变**（探针 100% 判 multi_turn，两种口径下都错），adv acc 不变、unknown 召回反被稀释 ⇒ 结论方向不变（推断，未重跑）。
- **A2 的 ASCII 占比高于分布内 plain（推断）**：标识符样本带英文，语体与分布内 plain 不同域，未做同语体配平；A2 acc 仅 12.2%，方向与 A1/A3 一致，但单独归因未分离。
- **P2 跨 seed 不同号（实测）**：0.567 / 0.711，均值 0.639 < 0.70；拒答出口这条**单独看证据不足**，整体判定建立在 P1、P3 两 seed 同号不通过上。
- **样本量（实测）**：对抗集 225（每规则 45），已知答案 15；单规则单 seed 分辨率约 ±7pt，已用 2 seed 交叉验证；未做第三 seed（预注册要求 ≥2，42/43 已满足）。
