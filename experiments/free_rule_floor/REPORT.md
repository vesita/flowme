## 1. PREREG 要点 + 新臂为什么是「预注册对照」

- **写死了什么**：臂表（A/N/U/UP）、配方、seed、电池 11 条清单、F0–F5 门槛、负对照门槛、三选一判定；**本单元零可调自由度**，F0 失败只修探针不改判据，跑完判据一字未改。
- **为什么算预注册**：N 臂的假设方向来自**上一个已冻结实验**的 4 条实测链（randlabel 不掉 / 杀模块不掉 / n_slots 免费规则吻合 / 打 mask 即掉回多数类）；`bag_modules` 的 PREREG §7 明令「不做事后补训」，所以该臂当时**不可能**被加进去。本单元是新立项，把这条**强推断**转成一次性直接实验 —— 臂与阈值全部在见到本单元任何输出之前声明 ⇒ **跑前声明的对照臂 = 预注册对照，不是事后调参**。
- **N 臂定义（写死）**：`skel = skel_out(h) + aux(z)`，`z = f(n_slots)` —— GRU 每步输入为**同一可学常向量**、只按 `mask` 掩码均值；`logits(mask, type_t, role_t, cls_t, pos_b)` **只用 `mask`**。参数：A 186,088 / **N 191,408（+5,320）** / U 191,544（+5,456）/ UP 193,088。
- **selfcheck 全过**：trunk/gen 初值跨臂逐位同；N 第 0 步 == A；把 aux 置随机非零后**改标签内容不改 N 的 logits、改 n_slots 会改**；n=1..4 的 z 两两不同；梯度可到 aux。
- **技术勘误（跑前记录，判据未改）**：初稿写「GRU 输入恒 0」，被自检拦下（零输入 + PyTorch 零隐态 ⇒ 旁路恒 0、N≡A），改为每步同一可学常向量；该编辑（09:48:58）早于 run 脚本（09:49）与首训 unit（09:50:07），**判据未动**。

## 6. 负对照 + F0–F5 逐条 + 判定

**负对照（硬门，必做）**：U-rand（训练标签跨行 randperm、mask 不动）test **.8416/.8496**、adv2 **.3660/.3690**；Δ vs A = **+.2020(t=24.785) / +.2072(t=25.251)**、adv2 +.1350(12.28)/+.1300(11.81) —— 与 `bag_modules` B3 的 +.202(t=24.785) **逐位一致** ⇒ 「增益不消失」复现，**管线同构，F1 有效**。

- **F0 通过**（6/6 位级相同）｜**F1 见上**（4/4 配对 >2SE、两 seed 同号）｜**F2 见上**（新旧两口径都报）｜**F3 见上**（逐臂 true→shuffled + N 打 mask）｜**F4 通过**（每臂 2 seed、同号、配对 SE 全列）｜**F5 见 §2**（11 条逐规则 + seen_rate + 新旧差）。
- **判定（三选一，按跑前写死的 F1 门）：模块内容有独立贡献。** 依据：N ≢ U，差 +.0256~.0350 在 test/adv2、两 seed 全部 >2×SE（t=5.1~8.0）。**不判**「增益由 n_slots 承载」是因为该门要求 |Δ| ≤ 2SE，实测不满足；**不判**「证据不足」是因为效应定号清晰、两出口一致。
- **机制分解（实测 + 推断分层）**：
  ① **实测**：n_slots-only 已承载增益的 70–87%（§4），免费规则 `n_slots→多数` 单特征即 .8316/.336 ≈ U 的 .8328/.3490 ⇒ **信息量上 n_slots 已足够**。
  ② **实测**：评测期**只打乱标签内容**（保留 mask）U 只掉 .0056~.018、UP 掉 .0044~.025，远小于 U−N 的 .0256~.035 ⇒ **U 超出 N 的部分，大部分不是"内容语义"**。
  ③ **实测**：U-rand（随机标签）**4/4 高于** U（test +.0088/+.0156、adv2 +.0170/+.0150）⇒ 内容正确性**不承载**增益。
  ④ **推断（未测）**：残差更可能来自**旁路容量/优化**——N 只能表达 4 个不同 logit 向量（n_slots 的全部信息），U 能表达任意逐槽输入；若把 `n_slots` 以**非加性**方式并进 trunk，N 可能更高。**该臂未测**（PREREG 固定为加性旁路，禁止事后补臂）。
  ⑤ **实测**：N 的 `head_only`（去旁路）test .4964/.5448、adv2 .053/.076，远低于 A 的 .6396/.2310；U 是 .3292/.3280 —— 两臂都把骨架判断搬进旁路，**表征并未变好**（与 `bag_modules` ③ 一致）。
