## 1. 审计口径（我定的运算规则，先写死再算）

- **Δ_min = 2×SE**。
  - 文档已报「Δ±SE」⇒ 直接用（SE 来源标【原文】）。
  - 文档只给**逐 seed 的 SE** ⇒ 我算**均值的 SE**：`SE_pooled = sqrt(SE_1² + … + SE_k²) / k`，故 `Δ_min = 2·SE_pooled`【我算】。
  - 文档给 **t 或 z**（未单列 SE）⇒ `SE = |Δ| / |t|`，`Δ_min = 2|Δ|/|t|`【我算】。
  - **SE 未报且无法从 t/p 反推（不一致对数、逐项 hits 未知）⇒ 标「不可算」，不猜。**
- **分档**（优先级：先看文档判词是否被它自己卡住 ⇒ ④；否则按数值）：
  - **① 判死成立/判词站得住**：`|Δ| ≥ Δ_min` 且方向与写死判据一致（含"有效"与"判死"两类判词）。
  - **② 有信息量的 null**：`|Δ| < Δ_min`（该口径未测出差异），**但 Δ±2SE 区间已把文档当作有意义的效应量挡在外面**（pp 口径取 R35 的 **1pp**；CE 口径取文档自己当作有意义的量级 **0.0287 nats**）⇒ 可写"未测出 ≥X 的效应"。
  - **③ 功效不足**：`|Δ| < Δ_min` **且**区间仍容许 ≥1pp（或文档的有意义量级）的效应 ⇒ **该口径只能写"未测出差异"，不得写成"没有效果"**。
  - **④ 不可判**：文档判词本身是「不可判/作废/只报方向/条件性（不判提升也不判无影响）」，理由为 **未饱和（R35，`methodology/RULES.md:46`）/ 口径冲突（含 SE→0 的退化 2SE、判据口径缺陷、两套门槛并存）/ R42 每格各自饱和（`RULES.md:53`）/ 地板条款**，或 **SE 未报 ⇒ Δ_min 不可算**。
  - 附注规则：文档给出**明确判词**、只是**附带** R35"未饱和 ⇒ 量级是下界"的，仍按数值入 ①/②/③，并在表中标 **R35 附注**。
- **判据不是 2SE 型的**（±5pp 非劣、地板+2SE、上限步数）⇒ 判据列照抄原文，Δ_min 仍按 2SE 核算；SE 未报则不可算。
