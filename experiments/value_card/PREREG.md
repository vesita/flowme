## 0. 唯一问题与假设

**一张价值观卡能否在冻结核上学出可靠的值判断**：给定一个句子，判其中的值判断表达
（`span + 类` ∈ {背景, 得体, 冒犯}）。

- 为什么要问：用户提案是「价值观卡控制学习率、形成卡间交叉强化」。dev-notes/16 §6.2 风险 1 写死了
  前提：**卡若不可靠，控制者角色根本不可能**（本项目已实测分布外可靠性差：路由 9.19% / 类型 29.78% /
  拒答 ~96% 误开火）。阶段 1 是最便宜也最决定性的一步。
- 假设（本实验证伪的）：在**冻结核 + 只训头**的现成机器上，值判断能作为普通 `span+class` 卡学会，
  且**不塌回词表捷径**（对抗集上仍显著高于多数类）。
- 若假设被证伪 ⇒ 如实判「价值观卡在当前核上不可靠」，并写明**阶段 2 的学习率控制不应开做**；
  **不调参刷到过为止**。

## 1. 标签口径（口径判断，构造时写死）

类 id（`TaskSpec.classes` 下标，0 必须是背景类）：**0=背景 / 1=得体 / 2=冒犯**。

| 类 | 判据 |
|---|---|
| `冒犯` | span 是**使用中**的贬损/攻击表达（说话人真在骂人/贬低） |
| `得体` | span 是**使用中**的礼貌/致谢/致歉/祝福/客套表达 |
| `背景` | 不发射：本句没有值判断表达，**或**词表词只被**提及**（引用 / 词典释义 / 禁止框架 / 教学框架），提及 ≠ 使用 |

- 「提及不算使用」与 `input_type` 的 A1–A3 同源（句中**提及**某结构不算该结构）。
- 实现为现有卡契约：非背景 ⇒ 发射一条切片（label = 类 id），背景 ⇒ 空切片。
- 残余标注噪声（推断）：注入式载体句语法不自然；提及/使用的边界个案（如禁止框架里的
  「别骂人笨蛋」）依赖人工判断，量级未量化（遗留 §8）。

## 2. 数据（`build_data.py`，fail-closed，已跑完）

- 语料入口**只用** `src/dtseek/tasks/corpus.py` 的 `resolve_corpus_files(CORPUS_GLOB)`
  （glob 空即抛错，不绕过、不自己 glob）；载体句 14–40 字、中文占比 ≥60%、**不含任何 OFF/POL 词**。
- 监督来源 = **自建小型人工词表**：OFF 40（冒犯）/ POL 40（得体）/ NEU 41（中性，背景类注入）。
  条目以**随机内部位置插进载体句**（插入位置在 `[1, len-1]`），span = 插入区间。
  插入边界若拼出额外值词 ⇒ 该样本**重造**（不放行）。
- 对抗集**不进训练**，两条规则（对应 dev-notes/16 §6.4「同词表换位置 / 同义改写」）：
  - `adv_syn_off` / `adv_syn_pol`（同义改写）：span 是**词表外**的近义表达（SYN_OFF 24 / SYN_POL 24，
    与三张词表**子串不相交**，构建期断言）⇒ 词表规则必然判背景；
  - `adv_mention`（同词表换语境）：**同一个词表词**出现在提及/引用/禁止/教学框架里 ⇒ 真值背景。
- 三个集合**按源句池两两切分**（train 6500 / test 1500 / adv 700 句），构建后实测重叠：

| 两两 | text | carrier |
|---|---|---|
| train∩test | **0** | **0** |
| train∩adversarial | **0** | **0** |
| test∩adversarial | **0** | **0** |
| train∩gold / test∩gold / adversarial∩gold | **0** / **0** / **0** | 0 / 0 / 0 |

四集并集 = 10320 = 8100+1500+600+120（实测 `union_text_unique`）。

| 集合 | 规模 | 背景:得体:冒犯 | 多数类基线 M | 朴素规则基线（exact / 类） |
|---|---|---|---|---|
| train | 8100 | 3240 : 2430 : 2430 | **40.00%**（背景） | **100% / 100%** |
| test | 1500 | 600 : 450 : 450 | **40.00%**（背景） | **100% / 100%** |
| adversarial | 600 | 200 : 200 : 200 | **33.33%** | **0% / 0%** |
| gold（V3） | 120 | 40 : 40 : 40 | **33.33%** | 41.67% / 43.33% |

- **朴素规则基线（零训练）** = 只扫 OFF∪POL 词表：最早命中 ⇒ 按该位置发射该类；不命中 ⇒ 背景。
  它在 train/test 上 100%、**对抗集上 0%** —— 它正是被对抗集针对的那条表层捷径。
- **gold（V3 外部代理真值）**：`gold/gold_hand.txt` 120 条**手写**句子（40/40/40），
  **不经**载体句/注入管线，混合词表内与词表外表达、中性句与提及句；标签与 span 由人工逐条给定，
  构建期只做格式/唯一性校验。它**不进训练、不进 test/adv**。
- 规模、类别比、多数类基线全部在 `data/stats.json`，构建期 fail-closed 断言（类别配额、文本唯一、
  span 越界、词表子串相交、命中数不符都会抛错）。

## 3. 训练口径（现有卡机制，`training/train_task_card.py` 原方）

- **主臂 = 只训头**（阶段 1 的默认选择；**不走**温启动联合）：冻结核 `checkpoints/base_encoder.pt`
  （eval、requires_grad 全 False，自检实测）+ `RobustARSliceDecoder` 头。
- 配方：epochs 12 × steps_per_epoch 150 = **1800 步**、batch 64、lr_head 1e-3、cosine、
  AdamW wd 1e-4、grad clip 1.0、**seed 42 / 43**、`--samples 8100`（数据是预构建固定文件，
  与 `--samples` 不符直接拒绝）。
- 卡声明：`value_judge`，classes = (背景, 得体, 冒犯)、`max_steps=1`（每样本恰一个值判断）、
  `max_len=64`（实测最长文本 45 字，无截断）、`emission=single`、`segment_policy=sentence`、
  **`cls_weight_bg=1.0`**（写死：`max_steps=1` 时背景类与其他类一样每样本只贡献一个监督信号，
  默认 1.3 会引入偏向背景的先验）；其余损失权重用默认。
- 包装入口 `run_card.py`：先打**空测试自检**再原样委托训练脚本。自检打印：
  真实可训参数量与冻结实况（核 requires_grad 实测，不看注释）、类别比与多数类基线、
  朴素规则基线、`--samples` 与数据文件条数一致性；核非冻结 ⇒ 直接退出、本步作废。
- **随机标签对照（V-bonus 必做）**：把 train 的 `label` 整体 randperm（类别计数不变）后同配方重训，
  span 按新标签重算（位置仍取该样本自己的注入/提及位置），同 seed 各一份（shuf-seed = seed×1000+7）。
- 评测 `eval_card.py`：对每个 ckpt 评 train / test / adversarial / gold 四集，
  并与 `evaluate_task` 的 `cls_acc`/`bg_fp`/`exact_match` **逐数对账**，不一致直接退出。

### 3.1 指标口径（跑前写死）

- **acc（主指标，V1/V2/V3 用它）** = 逐样本**类**判对的比例：
  第 0 步 argmax 类别 == 真值类（背景=0）。`max_steps=1` 时 rollout 至多发射一条切片
  （`cls==0` ⇒ 不发射），故它与「真值背景 ⇒ 预测不发射；真值得体/冒犯 ⇒ 发射恰一条且 label 相等」
  **逐样本等价**；预测 0 条 / ≥2 条 / label 不符在该口径下都已判错。
  该口径与 `evaluate_task` 的 `cls_acc`/`bg_fp` 可逐数对账：
  `acc = (cls_acc × n_非背景 + (1 − bg_fp) × n_背景) / n`，不一致直接退出。
- **exact（附报，不过线）** = 类 + 区间逐位一致（背景要求不发射）。
- 附报 `span_hit`（指针落点）、`bg_fp`（背景误开火）、逐类混淆、逐规则 acc、预测分布。
- 朴素规则基线与多数类基线在**同一 acc 口径**下重算并打印。

## 4. 判据（跑前写死，事后不改）

设 `t` = test 主臂 acc，`a` = adversarial 主臂 acc，
`M_test = 40.00%`、`M_adv = 33.33%`（跑前算死，见 §2）。

**δ = max(2.0pt, 主臂两 seed 极差 |s42 − s43|)**，**逐集合各算、不共用**（V1 用 test 上的极差，
V2 用 adv 上的极差）。

| # | 判据 | 门槛 |
|---|---|---|
| **V1** | 测试集 acc vs 多数类基线 | ≥ 40.00% + δ_test（两 seed **各自**满足） |
| **V2** | **对抗集**上不塌回多数类 | ≥ 33.33% + δ_adv（两 seed 同号满足） |
| **V3** | 与**外部代理真值**（gold 120）的相关性（**不是自评**） | **必报** Spearman ρ 与一致率；参考线：一致率 ≥ 33.33% + δ_gold **且** ρ ≥ 0.40（两 seed） |
| **V-bonus** | **随机标签对照**（必做） | shuf 臂 test acc ≤ 40.00% + 3.0pt，且 shuf 臂 adv acc ≤ 33.33% + 3.0pt（两 seed） |

- **V3 口径**：模型分 `s = P(冒犯) − P(得体)`（第 0 步 `cls_logits` 的 softmax，逐样本一个标量），
  金标准序 `v = 冒犯 +1 / 背景 0 / 得体 −1`；报 Spearman ρ(s, v) 与一致率（同 §3.1 acc 口径）。
  这是**外部构造、独立于训练管线**的标签，不是模型自评。
- **判定三选一**：
  **① 可靠** = V1 ∧ V2 ∧ V-bonus 在两 seed 全过，**且** V3 参考线两 seed 达到；
  **② 不可靠（价值观卡在当前核上不可靠）** = V1 或 V2 在两 seed **都**不过；
  或 V-bonus 未掉回多数类（则 V1 恒真、判据失效，同样记不可靠）；
  **③ 证据不足** = 其余（某判据只在一个 seed 过，或 V1∧V2 过但 V3 未达参考线）。
- 判 ② ⇒ 报告中**必须**写：「**因此阶段 2 的学习率控制不应开做**」。
- **不调参刷到过为止**：判 ② 就如实报；换配方必须另开 PREREG。

## 5. 阶段 2 判据 V4 / V5 / V6（**本轮不跑**，设计现在写死，防阶段 2 按结果调判据）

### 5.1 V4 —— hacking 探测器：目标指标与控制者指标**分离报告**

- **两个指标必须同时画在一张表里**：
  - `目标指标` = 被加权训练的那个任务本身的 `pred/exact`（卡的原生判据，如 negation/anchored 的 exact）；
  - `控制者自身指标` = 价值观卡在**固定金标准探针集**（`data/gold.jsonl` + 阶段 1 同口径新探针）上的判对率。
- **探针集必须与权重计算脱钩**：只报「被降权样本上的控制者判对率」不算数，必须报
  **held-out 探针**（该集不参与任何权重计算）。
- **判否条件（跑前写死）**：`Δ控制者 > 0` 而 `Δ目标 ≤ 0`（或目标落在两 seed 噪声带内不动）
  ⇒ 判 **自强化 / reward hacking**，V4 不通过。只有 `Δ目标 > 0` 且 `Δ控制者` 不是唯一上涨项才算过。
- 附报：权重分布直方图（触到硬界 0.5 / 1.5 的样本占比）—— 大量顶格 ⇒ 控制信号已退化成开关。

### 5.2 V5 —— 冻结 vs 共适应 vs 无控制 三臂对照

同 seed、同数据、同起点（阶段 1 的卡 + 被控任务的既有 ckpt），三臂：

| 臂 | 控制者 | 权重 |
|---|---|---|
| **A 冻结** | 控制期内**完全冻结**（阶段 1 的 ckpt，不再训练） | 硬界 [0.5, 1.5] |
| **B 共适应** | 与被控任务**同批更新**（非平稳，风险 3 的现场） | 硬界 [0.5, 1.5] |
| **C 无控制** | 无 | 恒 1.0（= 无控制 baseline） |

- 判据（跑前写死）：`A − C ≥ δ`（δ = max(2pt, 两 seed 极差)）才算「有收益」；
  `B − A < 0` 或落在噪声带内 ⇒ **闭环无收益 / 共适应无益** ⇒ 只保留冻结臂或放弃。
- 三臂都必须同时报 V4 的**两条**指标（目标 / 控制者），任一条退化即判否。

### 5.3 V6 —— 故意偏置的控制者（判别力来源，必做）

- **怎么造偏置**：取阶段 1 的卡，按固定规则注入偏置，得到 `biased` 控制者 ——
  把其第 0 步 `cls_logits` 中「背景」logit 减 `k`（k 取使**判类分布 L1 偏移 ε0 ≈ 0.20** 的值，
  k 在跑前由干净卡在探针集上的分布**一次性解出并写死**），或等价地把 30% 的背景样本强制改判冒犯。
- **两种 leash 设置都跑**：硬界 [0.5, 1.5]（leash on）与无硬界（leash off，只作对照、不用于产出）。
- **必做观察（跑前写死的量）**：
  - `ε0` = 偏置控制者与干净控制者在探针集上的判类分布 L1 距离（注入的偏移）；
  - `ε1` = 闭环后被控任务预测分布 vs 无控制臂（C）的 L1 距离（环产生的偏移）；
  - **放大** ⇔ `ε1 > ε0`；**leash 挡住** ⇔ `ε1 ≤ ε0` 且目标指标 ≥ C − 噪声带。
- **判否条件**：既观察不到放大（`ε1 ≤ ε0` 且 leash off 也无偏移）**或** leash 挡不住
  （`ε1 > ε0` 且目标指标崩到 C − 噪声带以下）⇒ 说明 V4/V5 是**恒真**的 ⇒ 整套机制无判别力。
- **V6 是这套东西判别力的来源**：没有它，V1–V5 全都可能恒真（dev-notes/16 §6.4）。
