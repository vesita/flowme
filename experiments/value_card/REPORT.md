## 1. 数据集

**类别定义（口径判断，PREREG §1）**：`0=背景 / 1=得体 / 2=冒犯`
- 冒犯 = span 是**使用中**的贬损/攻击表达；得体 = **使用中**的礼貌/致谢/致歉/祝福表达；
- 背景 = 不发射 —— 本句无值判断表达，**或**词表词只被**提及**（引用/词典/禁止/教学框架），提及 ≠ 使用。

**来源**：语料入口只走 `dtseek.tasks.corpus.resolve_corpus_files(CORPUS_GLOB)`（fail-closed）；

对抗集只用**词表外**近义表达（SYN_OFF/SYN_POL 各 24）与**同词表换语境**（8 个提及模板）。

## 4. δ 怎么算的（原始极差，PREREG §4）

| 判据集 | s42 | s43 | 原始极差 | δ = max(2.0pt, 极差) | 门槛 = M + δ |
|---|---|---|---|---|---|
| test | 49.13 | 49.93 | **0.80pt** | **2.0pt** | 42.00 |
| adversarial | 36.17 | 35.50 | **0.67pt** | **2.0pt** | 35.33 |
| gold | 40.00 | 36.67 | **3.33pt** | **3.33pt** | 36.66 |

- **V1**：49.13 ≥ 42.00 ✅、49.93 ≥ 42.00 ✅ ⇒ 两 seed 通过（超门槛 +7.13 / +7.93pt）。
- **V2**：36.17 ≥ 35.33 ✅、35.50 ≥ 35.33 ✅ ⇒ 两 seed 通过，但**只超门槛 0.84 / 0.17pt（边缘）**。
- **V3**（外部代理 gold，非自评）：一致率 40.00 ≥ 36.66 ✅、36.67 ≥ 36.66 ✅（仅 +0.01pt）；
  **Spearman ρ = 0.3223 / 0.2976，两 seed 均 < 0.40 ⇒ V3 不过**。
  ρ 用 s = P(冒犯) − P(得体)（第 0 步 softmax）对金标准序（冒犯+1/背景0/得体−1），
  实现与 scipy `spearmanr` 逐值一致（交叉验证过）。
- **V-bonus**（随机标签对照，必做）：shuf test 34.20 / 38.67 ≤ 43.0 ✅；shuf adv 32.50 / 13.67 ≤ 36.33 ✅
  ⇒ **确实掉回多数类及以下**（多数类 40% / 33.33%）⇒ V1 不是恒真。

## 5. 判定

**③ 证据不足**（PREREG §4 的第三支：V1∧V2∧V-bonus 过，但 **V3 未达参考线**）。

- **机制（实测）**：卡学到的是**弱信号**——同分布 train 只有 62~64%（朴素规则 100%）、test 49~50%；
  换到词表外的对抗表达仍有 +2.2~2.8pt 于多数类（朴素规则 0%），说明**不是纯词表记忆**；
  但金标准上**冒犯类召回塌到 0.125 / 0.075**、预测几乎不发冒犯类（120 条只判 7 / 5 条），
  三个类的分数均值排序正确（冒犯 > 背景 > 得体）却**类内散布过大** ⇒ ρ≈0.30 < 0.40。
- **推断**：gold 是手写自然句（均长 12.68 字、无注入痕迹），train/test 是注入句（均长 28.8 字），
  语体差会同时压低 gold 一致率与 ρ；这是**口径限制**，不改判据。
- **推断（未验证）**：1800 步可能没训饱和（train 62~64% 未到平台）；
  按 PREREG **不调参重跑**，换配方必须另开 PREREG。

**⇒ 不建议进入阶段 2**（PREREG 判 ① 才开阶段 2；`summary.json` 的 `recommend_stage2=false`）。
阶段 1 没有证明「价值观卡可靠」，而 §6.3 要求控制者角色以可靠性为前提；
在 ρ<0.40、V2 仅 +0.17pt 边缘通过的证据下开学习率控制，等于把一个**相关性未达线**的卡放进反馈环。

## 6. PREREG 里 V4 / V5 / V6 的设计摘要（**阶段 2 才跑**，设计已写死）

- **V4 hacking 探测器**：目标指标（被加权任务本身的 pred/exact）与**控制者自身指标**（价值观卡在
  **固定金标准探针集**上的判对率，该集不参与任何权重计算）**分离报告**；
  判否 = `Δ控制者 > 0` 而 `Δ目标 ≤ 0`（或落在两 seed 噪声带内）⇒ 判自强化；
  附报权重分布直方图，触硬界（0.5/1.5）占比过高 ⇒ 控制信号退化成开关。
- **V5 三臂对照**：同 seed/数据/起点 —— **A 冻结控制者**（控制期完全冻结）vs **B 共适应**（与被控任务
  同批更新）vs **C 无控制**（权重恒 1.0）。判否：`A − C < δ` 无收益，或 `B − A < 0`/落在噪声带内
  ⇒ 共适应无益；三臂都必须同时报 V4 的两条指标。
- **V6 故意偏置控制者**：取阶段 1 的卡，把第 0 步「背景」logit 减 k（k 由干净卡在探针集上的分布
  **一次性解出并写死**，使判类分布 L1 偏移 ε0 ≈ 0.20），leash on（硬界 [0.5,1.5]）与 leash off 各跑一遍；
  量 `ε1` = 闭环后被控任务预测分布 vs 无控制臂的 L1 距离。**放大 ⇔ ε1 > ε0**；
  **leash 挡住 ⇔ ε1 ≤ ε0 且目标指标 ≥ C − 噪声带**；既不放大又挡不住 ⇒ V4/V5 恒真、整套机制无判别力。

## 8. 遗留与不确定

**实测**：以上全部数字（2 seed、同一份固定数据文件；管线确定性，seed 只改头初始化与批次序）；
四集零重叠；对账 `reconcile_ok` 全 True；ρ 与 scipy 一致；shuf 真实执行（shuf=1 打印）。

**推断 / 口径限制**：
- gold 由**同一实验者**手写（非第三方标注），V3 的"外部"= 独立于构造管线与模型自评；
- gold 与 train/test 语体不同（长度、无注入痕迹），可能压低 ρ（未做同语体配平）；
- 结论只对「冻结核 + 只训头 + 1800 步」成立；**温启动联合臂本轮未做**（阶段 1 附加项，PREREG 未承诺）；
- 标签残余噪声（提及/使用的边界个案）未量化，未做人工抽检；
- V2 与 V3 一致率均**边缘通过/失败**（+0.17pt / +0.01pt），样本量 600 / 120 下单 seed 分辨率约 ±2~4pt，
  已用 2 seed 交叉，第三 seed 未跑（PREREG 要求 ≥2，已满足）。
