# 选择重排（experiments/select_rerank）—— 预注册判据

> **本文在首次训练之前写死**（mtime 必须早于任何 train 进程启动时刻），跑完不改；结果填进 `REPORT.md`。
> 口径：「实测」= 本目录跑出来的数字；「推断」= 由数字推出；「口径判断」= 构造时人为规定的标签归属。

## 0. 唯一问题

**在本项目的核上，「选择」能不能做？** —— 用 `dev-notes/13` §9 的**方案 B**：

> **上下文编码一次 + 每个候选单独编码一次 + 一个打分头在 K 个候选向量上打分。**

- **不发射锚点**（候选身份就是下标）⇒ 正好绕开 A 族唯一确定失败的那一环
  （`experiments/anchored_select`：锚点双命中 0.75%，冻结臂起点塌到 0）。
- **K = 2（一对一错）**，指标 = **选中正例的准确率**，**chance = 50%**。这是最干净的「选择」。
- **机制必须与 A 族分开报**（`dev-notes/16` §5.5）：A = 把候选标进**共享输入**一次编码（已否）；
  B = **每个候选独立编码**再打分。A 否 ≠ B 否；本实验只测 B。

## 1. 两臂数据（配方写死，照做）

两臂都从语料取句，入口**只用** `dtseek.tasks.corpus.resolve_corpus_files(CORPUS_GLOB)`（glob 空即抛，不绕过）。
每条样本 = `{context, cand_0, cand_1, label}`，**恰好一正一负**，**候选顺序随机化且两位置各占 50%**（否则位置是捷径）。

| 臂 | 正例候选 | 负例候选 | 关键性质 |
|---|---|---|---|
| **S（有捷径）** | 上下文里的**逐字片段** | 同长度带的**无关片段**（别句取来，保证不在上下文） | 「逐字含于上下文」规则**能**区分 ⇒ 复刻 `anchored_select` |
| **N（干净）** | 片段中某词换成**同义词**（语义等价，**不是逐字片段**） | **同位置**换成**反义词**（语义不等价，也不是逐字片段） | **两类都不是逐字片段** ⇒ 逐字规则**恒判同一侧**、准确率 ≈50%（**无预测力**） |

- **等长替换**：同义/反义词与原词**等长**（构造期断言）⇒ 两候选除替换处外**逐字相同**，
  杀掉「谁字数多/谁更长」这类表层规则（长度规则一并报）。
- **共享汉字对称**（构造期断言）：`share(w,同义) == share(w,反义)`（都共享或都不共享一个汉字）——
  否则零训练规则「替换处仍与原词共享一个字 ⇒ 判正」有预测力（初版词表 46/67 对不对称，已重做）。
- **臂 N 才是「选择能力」的检验**；若 **N 不过而 S 过** ⇒ 归因为**学到捷径**。

### 1.1 集合与规模（informative 分裂 ≥ 2000）

| 集合 | 每臂规模 | 正:负 | S 臂构造 | N 臂构造 |
|---|---|---|---|---|
| train | 8000 | 1:1 | 逐字片段 vs 无关片段 | 同义 vs 反义（**训练对**词表，被换词落在片段**前部**：距头部 0~2 字） |
| test | **2500** | 1:1 | 同 train | 同 train |
| adversarial | **2500** | 1:1 | 见下（**与 N 臂同构造**） | 见下 |

- **词表**：训练对 95 组、留出替换对 53 组（`build_data.py::TRAIN_PAIRS / HOLDOUT_PAIRS`，构造期断言等长/互异/词头唯一/共享字对称）。
- **test/adv 各 2500 ⇒ 二项 SE = sqrt(0.25/2500) = 1.00pt**（A 族 600 条 ±3.6pt 就是分辨率不够）。
- **adv 不进训练**，考「换个说法 / 换位置」，两种类型各半（**逐条带 `ctype`**）：
  - `heldout_pair`（**换说法**）：用**留出替换对** —— 词头取自训练词头（保证句内命中率），
    但两个**输出串**与训练词表（词头∪同义∪反义）**零交集**（构造期断言）⇒「背训练词表」在对抗集给不出答案；
  - `shifted_pos`（**换位置**）：用训练词表，但被换的词从**前部**挪到片段**尾部**（距尾部 0~2 字）。
  - **两臂 adv 同构造**（正 = 同义替换、负 = 反义替换），只换源句池 —— 这样 S/N 的 adv 可直接对比。
- 源句池**按索引切、两两不相交**（规模按 `--probe` 实测构造成功率定，实测值见 `data/stats.json::pools`）：
  S-train/S-test/S-adv/N-train/N-test/N-adv = **9000/3200/30000/70000/22000/30000**，外加捐献池 3000；
  构造后**实测**所有池对重叠，**必须 = 0**。
- 全局唯一性：`context` 与每个 `candidate` 字符串在整个数据集（含两臂）**只出现一次**，实测重叠 = 0。

### 1.2 必报的零训练基线（构建期算死并写进 `data/stats.json`）

| 基线 | 规则 | 期望 |
|---|---|---|
| **朴素逐字规则** | `候选 ∈ 上下文` ⇒ 判正；恰好一侧命中才选它，否则（双命中/双不中）**固定选下标 0** | S-train/test **1.00**；**N 臂与两臂 adv ≈ 0.50** |
| 长度规则 | 更长者判正；等长（N 臂必然）⇒ 固定选下标 0 | N 臂 ≈0.50；S 臂报出 |
| **共享字规则**（`align_share_rule`） | 把候选对齐回原片段找替换位，「与原词共享汉字」多的一侧判正；同侧 ⇒ 固定下标 0 | N 臂 **0.50**（由共享字对称保证）；S plain 不可算（N/A） |
| 上下文字重叠（`ctx_char_overlap_rule`） | 候选里出现在上下文中的**字种数**更多者判正；等值 ⇒ 固定下标 0 | ≈0.50，**残余偏置如实报**（不设门槛，只报数） |
| 盲猜 / 多数类 | 候选顺序随机化 ⇒ **50.0%**（构建期断言 1:1） | 无条件成立 |

- **数据有效性硬判**：若朴素逐字规则在 **N-train ≥ 90%** ⇒ **该臂数据无效**，如实报（不改判据迁就）。

### 1.3 截断守卫（逐样本，A 族的静默截断教训）

用与训练**同口径**的 `tokenizer.encode(text, max_length=spec.max_len)`（`spec` 见 `build_data.py::SPEC`，
ctx 64 / cand 32，均 < 核的 128）实际编码，**并与未截断的全长比对**；不满足 ⇒ **丢弃该样本并报条数**。
训练期 dataset 再断言一次（双保险）。期望 0 条，报实际值。

## 2. 模型与训练口径（写死）

- **结构（方案 B）**：冻结核 `checkpoints/base_encoder.pt`（`NanoDocEncoder`，hidden 128）分别编码
  `context`（一次）与两个 `candidate`（各一次，**共享同一核**），masked mean-pool 得
  `v_ctx (128)`、`v_cand (K,128)`；打分头对每个候选算
  `score = MLP([v_ctx; v_cand; v_ctx⊙v_cand; |v_ctx−v_cand|])` —— **同一个小 MLP 作用在 K 个候选上**
  （对候选位置**等变** ⇒ 下标不是特征）；`softmax over K` + 交叉熵。
- **冻结实况（每次训练必打印并写进结果）**：核参数 `requires_grad` 全 False、`eval()` 模式；
  可训参数**只有打分头**。
- **训练**：只训打分头，**不动核**；batch 64、**1800 步**（= `anchored_select` 的 12 ep × 150 步总量；
  本数据 8000/64 = 125 步每轮 ⇒ 14.4 轮，`train_rerank.py::STEPS=1800` 写死）、lr_head 1e-3、
  AdamW(wd 1e-4)、cosine、grad clip 1.0、**seed 42 / 43**（与 `anchored_select` 同配方同 seed，可直接对比）。
- **随机标签对照（P3 必做）**：train 标签整体 `randperm`（保持 1:1）后同配方重训，两臂各 2 seed。
- 评测 = 训练结束后对**该臂** train/test/adv 全量前向，指标 = `argmax == label` 的比例。

## 3. 判据（跑前写死，两 seed 同号才下结论）

设 `acc` = 选中正例准确率，`M = 50.0%`，`SE = sqrt(0.25 / n)`（二项 SE，按 chance 计，
test/adv = **1.00pt**，train = 0.559pt），`余量 = acc − 50%`，门槛 = **余量 > 2×SE**。

| # | 判据 | 门槛 |
|---|---|---|
| **P1** | **臂 N** 测试集选中正例准确率 vs 50% | **余量 > 2×SE（= 2.00pt）**，且报 SE 与余量/SE，**两 seed 同号过线** |
| **P2** | **臂 N** 对抗集 vs 50% | 同 P1 口径（SE = 1.00pt，门槛 52.00%） |
| **P3** | 随机标签对照（臂 N，两 seed；S 臂附报） | test 准确率 **≤ 50% + 2×SE（52.00%）**，否则 P1 恒真 ⇒ 判据作废 |
| **P4** | **臂 S** 对照（两 seed，test 与 adv 都报） | 只报数字 + 逐条基线；**S 过（test 与 adv 均 > 2×SE）而 N 不过 ⇒ 判「只在有捷径时存在」** |
| **P5** | 若走温启动联合：老卡不退化 | Δ ≥ −各自噪声带（pronoun 2.83 / sentiment 0.41 / relation 1.39 / person 0.33 pt）；**本实验核全程冻结 ⇒ 不适用（N/A），如实报** |

**判定三选一（不许硬选）**：

- **① 选择能力存在** = P1 ∧ P2 ∧ P3 **两 seed 全过**。
- **② 只在有捷径时存在（= 字符串匹配）** = P1 或 P2 在两 seed **都**不过，且 **P4 的臂 S test 过线**
  （即：有捷径时确实能选，无捷径时不能）。此时若 S-adv 也过线，如实报「S 训练可能带出部分语义信号，
  但 N 不过 ⇒ 仍归因为捷径主导」。
- **③ 证据不足** = 其余（某判据只在一个 seed 过 / S 与 N 都不过 / P3 不过使判据失效）。
- **≥ 2 seed 才下结论；不调参刷过**：判 ②/③ 就如实报；换配方必须另开 PREREG。
