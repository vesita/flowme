# 两级骨架机制实测：覆盖率能抬到多少、四道保证还立不立

判据跑前写死于 `PREREG.md`（mtime `09:34:45`，早于首次运行 `09:35:01`，**跑后未改**）。
语料与 `experiments/card_flow/` **逐句同批**（`results_real.json` 断言 identical），Tier-1 侧本批复现 36/120 = 30.0%，与基线一致。

## 1. Tier-2 的句式从哪来（实现）

**自由的只有句法与词序；词一个都不自由。** 产出是一份「槽序 + 功能词序列」结构指令，四步：

1. **选片段**：`filter_candidates` 之后的**已定型有效**候选，按 `(s0,-len,card,cid)` 排序贪心取 leftmost-longest **非重叠**子集 ⇒ 槽序恒为 span 升序。真卡没有题元标签 ⇒ **词序自由度实测为 0**，方向不可能互换（这正是 C4 的做法：用带题元夹具的 T01 单独验方向）。
2. **填间隙**：① 输入中**有据**的逻辑词（`因为所以但要能可以`，出现在 gap 内，最长→表序）→ ② gap 内从左第一个形式词 `，、；：和与` → ③ 不插；**句末** = 输入末标点 ∩ `。！？!?…`，否则 `。`。
3. **渲染**：`t2_render` 按单元铺 `ref_map`（内容 `ref:<cid>`，功能词 `T2`），逐字写入，无推理、无后处理、无重试。
4. **判**：`t2_structure_problems` 门禁（schema / 逐字 / 有效集 / 类型 / 升序不重叠 / 功能词封闭表 + 逻辑词有据）→ `t2_deref_verify` → **独立解析器 `t2_parse`**（与指令实现完全无关，只看字符串）：0 解析 `tier2_parse_no_way`、≥2 解析 `tier2_parse_ambiguous` ⇒ **不计分**。

**降级链 R0 全片段 → 依次去尾 → 最左单片段**；本实测 72/72 全在 R0，链从未被用到。
句式来源：**无模型生成**。句法 = `内容 (间隙 内容)* 句末` 一条文法 + `PREREG §3.3` 写死的间隙/句末规则；功能词只从封闭表或输入取；内容词 100% 是被筛候选的原文切片。

## 2. 覆盖率主表（真卡 120 句）

| 口径 | n_ok/120 | 覆盖率 | 拒答率 |
|---|---|---|---|
| 仅 Tier-1（card_flow 25 骨架） | 36/120 | **30.0%** | 70.0% |
| **两级**（Tier-1 ∪ Tier-2） | **108/120** | **90.0%** | **10.0%** |
| Δ | +72 | **+60.0pp** | −60.0pp |

- **C2 可解析率**：分母 = 构造出 R0 的 72 句 → **100%**（0 解析不出、0 歧义）；更严分母 = 进入 Tier-2 的 84 句 → **85.71%**（差的 12 句是**构造不出**句式，不是解析失败）。
- **C6 分布**：Tier-2 占产出 72/108 = 66.7%、占全样本 60.0%。拒答 12 条 = `tier2_type_inventory` 10（有有效候选但**全无类型**）+ `tier2_no_valid_candidate` 2；Tier-1 侧同批原因 = `compose:type_inventory` 82 + `filter:no_valid_candidate` 2。
- **结构事实**：凡有已定型有效候选的 72 句，Tier-2 **全覆盖（72/72 = 100%）**——瓶颈已从「骨架表」移到「候选类型库存」（推断，见 §6）。
- **句式分布**：单片段 63 / 双片段 9 / ≥3 片段 0；间隙连接 `，`5、`∅`3、**有据逻辑词 `能`1**；句末 72/72 全是 `。`（**实测退化**：抽样按句末标点切分，句末自由度本批未被触发）。
