**本文件在任何管线运行之前写死；判据不因结果调整。** 若事后必须改判据，按 dev-notes/16 §7.6.1
的纪律：新旧两个数字都报、理由与时间写进本文件末尾，不得只报新判据。

- 规格出处：`dev-notes/16-…（方案框架）.md` §7.3（候选风险序）、§7.4（内容 token 上锁）、
  §7.7（结构指令 + 确定性渲染 + 三条硬规则）、§7.9（解引用层四不变量 + 两道独立检查）。
- 只允许写：`experiments/card_flow/`、`logs/`、`/tmp`。`src/` 等其余目录只读。
- 语料入口只走 `src/dtseek/tasks/corpus.py::resolve_corpus_files()`（fail-closed，不自己 glob）。

## 0. 要回答的问题

用**现有零件**（指针卡 + 可核对谓词 + 手写骨架表 + 确定性渲染）能否**生成文本**，
且 G1–G4 四条不变量**同时**成立。

## 1. 样本与抽样规则（跑前写死）

- 语料：`resolve_corpus_files()` 命中的对话文件里取
  `lccc_dialogue.txt` 与 `dailychat_dialogue.txt` 两个（若文件名不存在则按同规则取排序前两个
  含 `dialogue` 的命中文件，并在报告中记明）。
- 切句：去掉行首 `用户：` / `模型：` 前缀后，按 `。！？!?；` 切句；
  合格句 = 长度 6..40 且含 ≥6 个汉字。
- 抽样：每个文件按出现顺序取前 50000 条合格句，用 `random.Random(42).sample(..., 60)`
  各抽 60 条 ⇒ **N = 120**。种子与规则固定，重跑必得同一批句子。
- 对抗组 / 故障注入组：**手写固定用例**（不抽样），逐条写死预期（见 §3）。

## 2. 硬判据 G1–G4（门槛跑前写死）

| # | 不变量 | 门槛（判死） | 统计口径 |
|---|---|---|---|
| **G1** | 拒答必须显式 | 缺块 / 类型不符 / 越界 / 无证据逻辑词 / 指派冲突 ⇒ 必须返回 `{"status":"reject",…}`，**不许出现任何 `text` 字段**；**必须拒的用例（A1A2A3-A4 A6–A13）拒答率 = 100%**，**正例（A3正确/A5/A14）必须渲染成功、不许误拒** | 必拒用例 `reject` 计数 / 必拒用例数；正例误拒数必须 = 0 |
| **G2** | 零信息新增 | 每条成功输出的**每个内容片段**必须逐字等于原文 span，且该候选必须**通过②筛选谓词**；**越界 1 条即不过** | 成功输出条数 K，违规片段数必须 = 0 |
| **G3** | 引用映射完整 | 文本的**每个内容字符**必须被映射覆盖：`片段 ↦ 结构 ref id ↦ 原始 span`，**100%**；映射条数与被填槽位数必须**完全相等**（双向） | 成功输出 K 条，未覆盖字符数必须 = 0，映射链断裂数必须 = 0 |
| **G4** | 逐字可复现 | 同一输入跑两次完整流（含渲染），输出文本**逐字相同**（`==` 按字节比较 UTF-8） | 成功输出 K 条，不一致数必须 = 0 |

**总体判定**：G1–G4 全过 **且** §3 对抗组全部符合预期 ⇒
「**卡片流端到端成立（在当前骨架表规模下）**」；否则如实判不过，并指出卡在哪一段。
**不许为了让不变量过而放宽谓词** —— 放宽即视为没测。

## 3. 对抗组（每条预期先写死，逐条实测）

| id | 输入 / 注入 | 预期 |
|---|---|---|
| A1 | `我打你`（夹具角色块：我=施事，你=受事）→ 指派 施事=你/受事=我 | **必拒**（`theme_conflict`） |
| A2 | `我打你`（**无题元标签**的普通候选）→ 指派把 你 放在 我 之前 | **必拒**（`reorder_unjustified`，无标签只许复述） |
| A3 | `你打我`（同 A1/A2 两分支） | 方向**不许互换**：正确指派出 `你打我。`，互换指派必拒 |
| A4 | 输入**无**因果/转折/情态依据，结构却用含 `因为`/`所以`/`但`/`要` 的骨架 | **必拒**（`logic_no_evidence`），不许编因果 |
| A5 | 输入**有** `但`（原文含）时用含 `但` 的骨架 | 必须**正确渲染**（不误拒） |
| A6 | 数字：结构里 ref 的 surface 被改动（`3`→`4`） | **必拒**（`span_not_verbatim`） |
| A7 | 专名：结构里 ref 的 surface 被改动（`张伟`→`王强`） | **必拒** |
| A8 | 否定：结构丢掉已指派的否定槽位（`丢失`） | **必拒**（`ref_render_mismatch`） |
| A9 | 情态：骨架含 `要` 而输入无 `要` | **必拒**（`logic_no_evidence`） |
| A10 | 缺块：骨架槽位在 `assign` 里无条目 | **必拒**（`schema_missing_slot`） |
| A11 | 类型不符：`名` 槽指派 `形` 候选 | **必拒**（`type_mismatch`） |
| A12 | 越界：候选/引用 span `e0 > len(text)` | **必拒**（筛选期 `out_of_bounds`，结构期 `span_not_verbatim`） |
| A13 | 渲染器注入（毒渲染：额外塞一个内容词） | **必拒**（`unmapped_output`，解引用侧检查） |
| A14 | 正确方向的对照（A1/A2/A3 的合法分支） | 必须**正确渲染**，且题元方向与原文一致 |

**双向都要测**：对抗组既要有"必须拒"，也要有"必须对"的正例（A5/A14），否则拒答率 100% 也能满分。

## 4. 骨架覆盖率（本设计的新瓶颈，必报数）

- **C1** = `compose 成功的句子数 / 120（全部抽样句）`
- **C2** = `compose 成功的句子数 / 至少有 1 条有效候选的句子数`
- 逐段拒绝原因分布：`no_valid_candidate / type_inventory(缺哪种类型) / logic_gate / order_theme / distinct`
- **口径**：覆盖率按"至少存在一个骨架可被该句有效候选完全填充（含题元、顺序、逻辑词证据门禁）"计；
  骨架表在跑前写死（≤40 条），跑完不得为提高覆盖率增删骨架。**若增删，新旧覆盖率都报 + 理由时间写进本文件。**

## 5. 拒答率与前向时间

- **拒答率** = 120 条真实句中 `status=reject` 的比例；分段报（①候选空 / ②筛选 / ③重整 / ④渲染 / ⑤解引用）。
  预期**不为 0**（§7.8 已预先写死：槽位化会把错误显式暴露 ⇒ 初期拒答率升高）。
- **前向时间**（若跑真卡）：`MultiTaskEngine.predict` 逐卡计时，报每卡均值/中位数（ms），
  并与"段数 × 解码步数"逐步对账（编码 1 次共享 + 每卡 max_steps 步解码）。

## 6. 谓词清单（跑前写死，跑中不许改）

②筛选（对每条候选，全部通过才算 `valid`）：
`F1 in_bounds`（0≤s0<e0≤len）、`F2 non_empty`、`F3 canonical_class`（class_name 属于该卡
注册表类别且 class_id>0 背景不许）、`F4 no_punct`（span 内无标点）、`F5 verbatim`
（`text[s0:e0] == surface` 逐字）。

⑤结构侧 schema/evidence（对结构指令）：骨架 id 存在、`assign` 覆盖全部槽位且无多余键、
`refs` 与 `assign` 键集合相等、span 逐字且在界内、候选属有效集、槽位类型 == 候选类型、
题元一致（有标签）或保持原文顺序（无标签）、逻辑词字面在原文有据。

⑤解引用侧：被填槽位集合 == 映射 ref 集合（双向）；输出**每个字符**必须落在
"某个映射片段"或"骨架字面"或"标点空白"上，否则 `unmapped_output`。

## 7. 已知扩展与边界（先声明，免得事后解释）

- 槽位类型实装 5 种：`名 / 动 / 形`（§7.7 规定）+ **`否`**（否定标记，来源=否定卡切片，
  否定必须走槽位才能保留 span 引用）+ **`数`**（**现有卡不产数字切片**，仅夹具可填，用于测"数字改动/丢失必拒"）。
- **题元标签**（施事/受事/时）：**现有 5 张卡都不产题元**。真实流里候选题元恒为 `None`
  ⇒ 走 §7.7 的 fail-closed 分支：**只复述、不换方向**（顺序谓词）。带题元的分支用**夹具角色块**测（A1/A3/A14）。
- **"选骨架 + 填槽"本轮不是模型**：由确定性穷举搜索给出；真卡推理只提供候选。
  ⇒ 本测能证明的是"管线与四不变量成立"，**不能**证明提案模型的准确率（S1–S3 未做，如实标 N/A）。
- 假卡（词典匹配的模拟指针卡）先跑通管线自检；真卡推理最后做一次小规模。

## 8. 判定

G1–G4 全过 + 对抗组 14 条全部符合预期 ⇒ **成立（在当前骨架表规模下）**；否则不过，指出卡段。
