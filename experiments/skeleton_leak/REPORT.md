## 6. Q0–Q5 逐条 + 判定 + 机制

- **Q0 过（实测，2 seed 无关）**：a_bal 上免费规则 **.0000 ≤ .0385+2×.0155=.0695**；桶熵 2.8270（n=2 桶 1.000 归一）、MI .4311（旧 test 1.0315 / adv2 .8667）。
- **Q1 过（按 PREREG 主门槛）**：U/P/UP 两型两 seed 全过 1/40+2SE、同号；A 仅 C 型过（B t=1.14）。**严参照 B 不过**（见 §4）。
- **Q2 过**：排名 UP>U>P>A 与 test 同序；配对 Δ vs A 两 seed 同号、t=2.9–10.1；每格附卡−完备 max_naive。
- **Q3（三项对照，见 §2/§3）**：泄露量 规则 .336→**0.0000**、MI .8667→.4311、n=2 桶熵 2.49→3.14；难度 多数类 .288→.0385、完备 max_naive .336→.1404、四臂 adv2 .231–.380 → a_bal .064–.159（**更难**：绝对值降 3–5 倍，因 26 类近均匀、且计数红利被清零）；规模 n=1000→1040、同 14 文件过滤、句级汉字比 ≥.600。
- **Q4 过（必报）**：完备电池 = max(majority/len_bucket/first_char/last_char/punct_pattern/fw_list/tree2/tree4/**n_slots**/本集多数类)，fit=train，逐格入表 §3；新集合上 `annotation_inverse_pos_sort` 单列披露 .998–1.000（标注函数的逆，非可学规则）。
- **Q5 部分过**：规模/语言/三型可构造性全报（§1）；**负向对照在 a_bal 与 test(UP) 未落回**（如实报 §5），诊断为 h 通道读句而非旁路。
- **判定（三选一）：存在真实的选骨架能力** = Q0 过 ∧ Q1 主门槛过（U/P/UP 两型两 seed；A 仅 C 型）。**但强度必须并列读**：① 干净出口绝对 acc 仅 .0635–.1587（26 类，多数类 .0385、盲猜 .025）；② 严格最小对上模型**基本不读功能词**（pair_success ≤2.14%、对内预测 79–85% 不变、acc 距成对机会 .5 差 t=−25~−31）；③ **无一臂显著超过完备免费电池**（仅 UP +1 SE）⇒ 能力的形态是「句面/先验倾向」，**不是**「功能词最小对判别」。
- **机制（实测）**：① **标签通道=计数通道**：aux_only test .6104/.8004 → a_bal **0.0000/.0144**（它输出的正是 L 骨架，集内不存在）；② **L 行分解**（a_lit=a_bal+160 行，同袋同洗牌）：U 在 L 行 **.875/.844**、非 L 行 .131/.130，UP .875/.862 vs .157/.159，A .550/.550 vs .064/.066，P .763/.800 vs .084/.085 ⇒ **分数主要随计数可预测的 4 类进出**；③ h 通道 test .6396 → a_bal .0635，U 的 head_only .0635 ≈ A 同格 ⇒ 干净出口上 h 通道没变好；④ 负向对照残差 = head_only ≈ A 臂同格（推断，基于三者数值一致）。
