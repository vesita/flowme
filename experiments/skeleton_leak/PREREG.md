# PREREG —— P3 计数泄露消除的对抗集（`experiments/skeleton_leak/`）

写死时间：2026-10-07 09:5x（`mtime` 早于**首次评测**；本文件跑前定稿，跑后不改，改哪条都要在 REPORT 如实记）。

**唯一问题**：在**一个 `n_slots`（袋项个数）不泄露骨架标签的出口上**，已有四臂模型能选到什么程度？

**⚠️ 边界（写死）**：本单元回答的是「**在无计数泄露的出口上模型能选到什么程度**」；
**不回答**「换特征能否提升」（下一波单元），**也不回答因果**。

## 0. 背景（既有实测，本单元不重跑）

`experiments/bag_modules/REPORT.md`：骨架 acc A(test .6396/.6424, adv2 .2310/.2390)、
U(.8328/.8340, .3490/.3540)、P(.7708/.7764, .3160/.3100)、UP(.8416/.8440, .3800/.3760)；
免费规则 `n_slots→train 多数骨架` test **.8316** / adv2 **.336**（零训练、`seen_rate` 全 1.0）；
B3 随机标签失败；评测期打乱标签输入 test .8328→.4060。A 臂与 `struct_supervision` B 臂同口径。

**实测前置事实（本文件引用的数字，来自 train/test/adv2 直接统计，非模型评测）**：

| n_slots 桶 | train 行数 | 桶内骨架数 k | 桶内多数骨架 m_b（train） | 桶内多数占比 |
|---|---:|---:|---|---:|
| 1 | 122 | 3 | **#35 `[1]吗`** | .5574 |
| 2 | 4402 | 24 | **#0 `[1]，[2]`** | .7576 |
| 3 | 2311 | 2 | **#1 `[1]，[2]，[3]`** | .9031 |
| 4 | 1165 | 1 | **#2 `[1]，[2]，[3]，[4]`** | 1.0000 |

⇒ **泄露骨架集合 L = {35, 0, 1, 2}**（= `n_slots→train多数` 规则的全部输出）。

**构造数学（跑前推导，写死为设计依据；REPORT 标为「推断」并用实测验证）**：
`n_slots` 是 `skeleton` 的函数 ⇒ `MI(n_slots; skeleton) = H(n_slots)` **恒等**，MI 只能靠降 `H(n_slots)` 降；
而规则 acc = Σ_b P(gold = m_b)，多数类 = max_s P(s)。**若 ≥2 个桶的 m_b 同时在集内且桶内等量，
则 规则 = Σ_b p_b/k_b > max_b p_b/k_b = 多数类，Q0 必不过**（等量构造在多桶下数学上无法消除泄露）。
⇒ **A 型主集必须满足：集内至多保留一个 m_b（本单元取「一个都不留」）。**

## 1. 语料与口径（写死，与 `struct_supervision/build_data.py` 逐字同）

- 入口只用 `dtseek.tasks.corpus.resolve_corpus_files(CORPUS_GLOB)`（glob 空即抛）；
  **文件级汉字占比 ≥ 0.6 保留 14/18**（丢 code_alpaca .0004 / gsm8k .0585 / coig_math .5418 / qwen3 .5112，
  即 `dev-notes/19` 禁用文件已被排除），**打乱文件序**（SPLIT_SEED=20240930），
  **不依赖 `fs` 顺序、不写 `fs[:N]`**；句级 `ok_sentence`（长 14–44、汉字比 ≥.6、无 ASCII 词/坏字符）；
  `PUNCT_NORM` 归一 → `SENT_SPLIT` 切句 → `match_sentence`（字面数降序、平手取 id 小）。
- **骨架池 = train 出现过的 30 个 id**（与 adv2 同口径）；10 个训练零样本 id 不入集
  （**口径判断**：测「选骨架」必须在已见类内，零样本类三臂构造性为 0，混入只会测"认没见过的类"）。
- **句子互斥**：新集句子 ∩ (train ∪ test ∪ adv1 ∪ adv2) = 0（fail-closed 断言）。
- 袋序按 BAG_SEED=77001 洗牌、`assign = perm.index(slot)`（规则 0：指派独立于袋序）；
  断言 span/bag 一致、GAP_LEN、tokenizer 不截断。

## 2. 三型构造（**可构造性自检先做，逐型如实报 可/不可 + 原因 + 未命中率**）

### A 型｜计数内均衡（主集 `a_bal.jsonl`）
- 各 `(n_slots, skeleton)` 组合**等量 C 行**；桶 = {1,2,3}（n=4 桶唯一骨架是 m_4=#2，被排除后自然消失）；
- **排除 L = {35, 0, 1, 2}**（依据 §0 数学：Q0 要求 Σ_b P(m_b) ≤ 多数类 + 2SE）；
- 单组合可用候选 < **10** 句 ⇒ 该组合判「不可构造」并剔除（如实报）；
  `C = min(40, 各保留组合可用量)`；
- **对照构造 `a_lit.jsonl`（字面口径，含 L）**：同采样流程但**不排 L**，仅作构造性诊断
  （预期按 §0 数学 Q0 不过；**不进 Q1/Q2 判据**，两者的 Q0 都报）。
- 报：每桶骨架分布熵 H(skel|n)（nats + 归一化）、每组合计数、未命中率。

### B 型｜计数不变、骨架变换（最小对 `b_pairs.jsonl`，两类）
- **B1 功能词替换**：取自然句 gold=s（槽文本 g1..gk），把模板中**一段字面**换成孪生骨架 t 的对应字面
  （见 §2.1 孪生表），得到同袋、同 n_slots、gold=t 的新句；
  **验证 fail-closed**：`ok_sentence(variant)` ∧ `match_sentence(variant) == (t, 同样的槽文本, 同序)` ∧ 不与任何已用句重复。
  **未命中率 = 合成句未通过验证的比例**（逐原因分类：错骨架 / 拒绝 / 重复 / 截断）。
- **B2 连词位置交换（因果对 #6↔#7）**：`A，因为B`（#7）↔ `因为A，B`（#6），同一袋、槽序相对连词交换；同上验证。
- 成对入集（原句与变体都进），使「读不出功能词 ⇒ 成对准确率 ≤ 0.5」成立。
- 单组合可用 < 10 对 ⇒ 该对判不可构造。

### C 型｜同槽位数、只差一个功能词（自然句 `c_pairs.jsonl`）
- **孪生表（跑前写死，逐字列出，不事后增补）**——判据：同 n_slots、槽位与字面段数相同、
  **恰有一段字面不同且两段等长**（等长 ⇒ 是"换词"不是"增删"），且两段只含标点+功能词：

| 对 | 骨架 s | 骨架 t | 差异段 |
|---|---|---|---|
| C1 | #6 `因为[1]，[2]` | #11 `如果[1]，[2]` | 因为↔如果 |
| C2 | #6 `因为[1]，[2]` | #26 `为了[1]，[2]` | 因为↔为了 |

## 3. 验收口径（**跑前写死，判据不改**）

SE 口径：acc 行级 SE = `sqrt(0.25/n)`（与 bag_modules 一致）；槽位 SE = 行值样本均值 SE；
配对 Δ 的 SE = 逐行 0/1（或行分数）差的样本 SE；t = Δ / SE_pair；**2 seed = 42/43**。

| # | 判据 | 门槛 |
|---|---|---|
| **Q0（主）** | **泄露消除**：`n_slots→train多数骨架` 在**主集 a_bal** 上 | **≤ 多数类 + 2×SE**；并报 每桶熵 H(skel\|n) + MI（nats）与 NMI |
| **Q1** | **最小对可分性**：B 型 / C 型分别报 | 模型骨架 acc > **盲猜 1/40** + 2×SE（**两 seed 都要过且同号**）；**同时必报更严参照**：B 型 > **成对机会 0.5** + 2SE、C 型 > **子集内均匀 1/K** + 2SE（≈盲猜 ⇒ 模型没在读功能词/顺序） |
| **Q2** | 四臂在干净出口上的排名 | A/U/P/UP × {旧 test, a_bal} × {骨架,槽位,联合} × 2 seed：acc ± SE、Δ=臂−A 配对 ±SE、t、**2 seed 是否同号**；每格附 **卡 − 完备 max_naive** |
| **Q3** | 与旧 `adv2` 的同口径对照 | 三项全报：**泄露量**（免费规则 acc、桶熵、MI）、**难度**（多数类、盲猜、完备 max_naive、四臂 acc）、**规模**（n、文件清单、汉字占比口径） |
| **Q4** | `max_naive` 完备电池必报 | `max(多数类, len_bucket, first_char, last_char, punct_pattern, fw_decision_list, tree_depth2, tree_depth4, **n_slots规则**)`，全部 **fit=train**；逐格报 卡 − 完备 max_naive |
| **Q5** | 规模 / 语言构成 / 可构造性 / 负向对照 | 逐型报 可/不可构造 + 原因 + 未命中率；n、文件清单、汉字占比（文件级 ≥.6 ∧ 句级 ≥.6）；**负向对照：评测期标签打乱（含 mask，跨行 randperm）在 a_bal 上** ⇒ 期望 ≤ 多数类 + 2SE，否则如实报"未落回"并用 `head_only` / A 臂同格诊断 |

**判定（三选一，不许硬选）**
- **存在真实的选骨架能力** = **Q1 过 ∧ Q0 过**；
- **选骨架能力≈0（此前数字基本是计数泄露）** = Q0 过 ∧ Q1 未过（B/C ≈ 盲猜）；
- **证据不足** = Q0 未过（构造没消掉泄露）∨ B/C 至少一型不可构造且另一型未过 ∨ 负向对照未落回且诊断为旁路。
- **不许**把"没测出差异"写成"没有效果"；实测/推断分开标，证据强度标（单 seed / 配对 / 2 seed）。
