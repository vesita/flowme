## 0. 唯一问题与边界（写死）

**唯一问题**：给定 DTSeek 端到端输出 `Y = F(X)`，能否找到输入侧**最小扰动** `X′` 使 `Y′ = F(X′) ≠ Y`，
且 (a) `Y′` 是**真跑出来的**、(b) 这种最小扰动**显著优于同规模随机扰动**。

⚠️ **边界句（必须原样进报告）**：本单元只回答「**反事实是否成立 + 是否特异**」，
**不回答因果机制**（「为什么这个扰动起作用」需要干预实验，本单元不做）。

背景（既有实测，本单元不重跑、不重新论证）：`experiments/skeleton_leak/` 三型最小对上模型 **79~85% 不改变答案**；
`experiments/card_flow/report.md` 真卡 120 句 G1–G4 全 0 违例、拒答率 **70%**、可回溯的胡话；
`experiments/gen_dispatch/results_all.json` generate 通道 **0.2%**、契约违例 0、对抗 14 全 pass；
`experiments/free_rule_floor/` 完备免费地图 test **.8316** / adv2 **.336**（含 `n_slots→train多数`）。
本项目已 **6 次**被「免费规则吃掉增益」⇒ 任何特异性结论**必须**与随机扰动对照（C1/C5）。

## 3. 扰动族（跑前写死；表逐字列出，不事后增补）

全部作用在**输入侧字符串**；每个候选都是**一个**原子操作（换一处 / 移位 / 加删一处）。
**扰动大小 = 字符级 Levenshtein 距离 `lev(X, X′)`**（跨族统一可比，整数）。
族内枚举后按 `(lev, 首个不同位置, X′)` 升序去重（同一 `X′` 只留一个）；断言 `X′ ≠ X`。

**分段**：按标点 `，。！？!?；;、,` 切成「片段 / 标点」交替项（标点原位不动）。

| 族 | 名称 | 构造（写死） |
|---|---|---|
| **F1** | 换功能词 | 表 `FW` 的一处替换（每对每个出现位置各一个候选）：`然而→之前`、`但是→之后`、`虽然→如果`、`如果→虽然`、`而且→然后`、`不过→后来`、`于是→比如`、`同时→但是`、`但是→而且`、`尽管→比如`、`并且→之后`、`却→就`、`否则→比如`、`要么→比如` |
| **F2** | 换槽序 | 片段两两交换（标点留在原位）；候选序按 `lev` 升序，平手按 `(i, j)`；片段相同的交换产生的 `X′==X` 已断言剔除 |
| **F3** | 改否定 | (a) 删一处否定标记 `["没有","不是","不会","不能","不要","不","没"]`（长者优先命中）；(b) 在**每个片段起始**插入 `不` 或 `没` |
| **F4** | 改数量/量词 | 表 `QU` 的一处替换：`全(部)/所有/一切/都/全 →有些`、`总是→有时`、`一直→偶尔`、`一定→也许`、`很多→有点`、`太→有点`、`最→比较`、`一↔两`、`几→一些` |
| **F5** | 换连接词（方向反转） | 表 `SW` 的一处替换：`因为↔所以`、`由于↔因此`、`因为→因此`、`之所以→所以` |

**搜索预算（写死）**：每个 `(样本, 族)` 最多 **K = min(30, 该族候选数)** 个候选，按大小递增逐个真跑，
**第一个使主口径 `Y` 改变的即为该族的最小反事实**，记 `(族, lev, Y, Y′, X′)`；跑满 K 未变 ⇒ 记「未找到」。
（族内候选数 < 30 时如实报「已穷尽」。）

## 4. 特异性对照（同规模随机扰动；写死）

对每个 `(样本, 族)`，取结构化搜索的**完整候选数 K 与其 lev 序列 `s_1..s_K`**（枚举不耗推理，可取全），
再做**同预算、同规模序列**的随机孪生搜索，两种模式各一遍：

- **R1 随机换字符**：在 `X` 上随机换字符 / 插字符，直到 `lev(X, X_rand) == s_i`（拒绝采样，重试上限 400 次/抽）；
- **R2 随机换词**：随机取 1..3 字区域替换成固定词库词（含变长替换），同样以 `lev == s_i` 为接受条件（上限 400）。

两个模式都断言 `X_rand ≠ X`；**抽不到精确同规模 ⇒ 该次记「不可达」并单独计数**（比例 > 20% ⇒ 判定只能落「证据不足」）。
随机孪生的停止规则与结构化**完全一致**：跑满 K 或第一个 `Y` 改变即停。
⇒ **同一样本、同一族、同预算 K、同规模序列，唯一差别是「扰动怎么来的」**。
随机种子 = `SHA1(SEED0=20261007, 样本序号, 族, 模式, 抽次)`，可复现。

## 5. 验证协议（写死，独立进程）

- **阶段一 `run_search.py`**（进程 A，一次加载引擎）：跑基线 + 结构化搜索 + 两个随机孪生，
  产出 `results/search.json`（每条含 `X, X′, Y, Y′, 族, lev, 预算内序号`）。
- **阶段二 `run_verify.py`**（**全新进程 B**，重新加载引擎与权重）：对阶段一记录的
  120 条基线 `(X, Y)` 与**全部已找到的反事实**（结构化 + 随机两种模式）逐条**真跑**，比对。
  - **C0 验证失败率** = `阶段二 F(X′) ≠ 阶段一 Y′` 的条数 / 已验证的反事实条数（**= 编的反事实比率**）。
  - **C3 确定性** = 阶段一与阶段二对同一 `X` 或同一 `X′` 输出不一致的条数（必须 = 0）。
- **绝不允许推断 `Y′`**：`Y′` 一律来自阶段一实测；阶段二再实测一次。任何「按语义推出的新输出」都不入集。

## 6. C0–C5 判据与门槛（跑前写死）

| # | 判据 | 门槛（判死） |
|---|---|---|
| **C0（主）** | 验证失败率 `n_fail / n`（结构化反事实） | **≤ 5% 且 n ≥ 50** 才算「真实」；否则判定只能落「证据不足」。必给绝对数 `n_fail/n` |
| **C1（特异性）** | 同预算配对：`Δ = p_struct − p_rand`（每族每样本的「是否在 K 内找到改变」） | 配对 SE：`Δ=(b−c)/n`，`SE=sqrt((b+c) − (b−c)²/n)/n`（b=仅结构化找到，c=仅随机找到）；**显著 ⇔ Δ > 2SE**。`Δ ≤ 2SE` ⇒ 如实写「**反事实不特异**」 |
| **C2（最小性）** | 每族已找到最小反事实的 `lev` 分布 | 必报 n / 中位 / p25 / p75 / max（另报全局最小的分布） |
| **C3（确定性）** | 同 (X, X′) 两阶段两次跑 | 不一致必须 **= 0**；> 0 ⇒ 判定只能落「证据不足」 |
| **C4（分列）** | 结论改变的四类分列 | 必报：`ok→ok 文本变` / `reject→ok` / `ok→reject` / `reject→reject 拒因变`；另报辅口径（仅通道改变）计数 |
| **C5（`max_naive` 并列）** | 随机扰动概率即**免费规则基线** | 必报 `p_struct` 与 `p_rand` **同表并列**（逐族 + 合计），并写明「随机扰动概率即基线」；**禁止把没测出差异写成没有效果** |

**判定三选一（按上表机械判，不许硬选）**：
1. **反事实真实且特异** ⇔ C0 ≤ 5% ∧ n ≥ 50 ∧ C3 = 0 ∧ C1 `Δ > 2SE`；
2. **真实但不特异** ⇔ C0 ≤ 5% ∧ n ≥ 50 ∧ C3 = 0 ∧ C1 `Δ ≤ 2SE`；
3. **证据不足** ⇔ 其余情形（C0 > 5%、C3 > 0、n < 50、随机不可达 > 20%）。
