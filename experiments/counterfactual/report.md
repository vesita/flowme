## 1. 口径、扰动族与规模（实测）

被解释的输出 = `card_flow` 端到端五段流（只读 import `flow.run_flow` + `proposers.real_propose`）的返回：
主口径 `Y = ok{text} / reject{stage,reason}`，辅口径 = 仅 `ok↔reject` 通道。引擎 `MultiTaskEngine(device="cpu")`
+ 否定卡（挂载成功）⇒ 5 张卡。样本 = `card_flow::load_samples(per_file=60)` ⇒ **120 句**（seed=42，不依赖 `fs` 顺序）。
基线（实测）：**ok 36 / reject 84 ⇒ 拒答率 70.0%**（拒因 `type_inventory` 82、`no_valid_candidate` 2）——与
`card_flow/report.md` 的 36/84、70% 同数（该处在 GPU 上跑，这是第二条同口径证据）。

| 族 | 名称 | 构造 | 适用句/120 | 候选总数 | 入 C1 判定 |
|---|---|---|---:|---:|---|
| F1 | 换功能词 | `FW` 表一处替换（然而↔之前、也↔就、还↔再…，含[修订1]扩充） | 30 | 43 | 是 |
| F2 | 换槽序 | 片段两两交换、标点原位不动（同袋换槽） | 49 | 170 | 是 |
| F3 | 改否定 | 删一处 `没有/不是/不会/不能/不要/不/没` ＋ 片段起始插 `不`/`没` | 120 | 486 | 是 |
| F4 | 改数量/量词 | `QU` 表一处替换（全/都/所有/一切→有些、一↔两、多↔少…） | 41 | 70 | 是 |
| F5 | 换连接词(方向反转) | `SW` 表（因为↔所以、由于↔因此、之前↔之后…） | **2** | 3 | **否（证据不足）** |
| | | **合计** | **242/600 单元格** | **772** | |

- **扰动大小 = 字符级 Levenshtein**（跨族统一）；族内按 `(lev, 首个不同位置, X′)` 升序去重；断言 `X′≠X`。
- **[修订1]**：纯枚举自检（未看任何模型输出）发现旧表覆盖 `F1 3/120、F4 31/120、F5 1/120`，三族几乎不适用
  ⇒ 只扩表不改判据；新旧数字均已列出。**F5 仍是语料限制（因果连接词仅 2/120）⇒ 不入 Δ 统计。**
- **搜索**：每 `(样本,族)` 预算 `K = min(30, 候选数)`（实测 K 全部 = 候选数，**无一触顶**），按大小递增逐个**真跑**，
  **第一个使 `Y` 改变者 = 该族最小反事实**；跑满未变记「未找到」。
- **随机孪生（同规模对照）**：对同一 `(样本,族)` 取结构化的**同 K、同 lev 序列**，做
  **R1 随机换字符** / **R2 随机换词**，拒绝采样打到 `lev` 完全相同（实测**不可达 0 次**），停止规则一致。
  种子 = `SHA1(20261007, 样本, 族, 模式, 抽次)`。
- **验证（阶段二，独立进程重新加载权重）**：复跑 120 条基线 + **全部 426 条已找到反事实**（结构化 131 + R1 156 + R2 139），
  每条连 `X` 与 `X′` 各跑一次；`Y′` 一律来自阶段一实测，**无任何推断成分**。

## 2. 真实反事实样例（7 条，第三进程独立复跑逐字确认；4 条为拒答↔成功切换）

| # | 族/类型 | X → 输出 | X′ → 输出 |
|---|---|---|---|
| 1 | F1 **拒→成** lev1 | `放下他你就更好更好了` → `reject(compose, type_inventory)` | `放下他你也更好更好了` → **`ok「他好。」`** |

| 5 | F3 成→成 lev1 | `死了记得把你家那个送我` → `ok「那个送吗？」` | `不死了记得把你家那个送我` → `ok「不送。」` |

**判定（按 PREREG §6 机械判，不许硬选）：「真实但不特异」。**
机制（判定如何得出）：C0=0.0% ≤5% ∧ n=131 ≥50 ⇒ 真实；C3=0 ⇒ 确定；C1 两个模式 `Δ ≤ 2SE` 且**同为负**⇒ 不特异 ⇒ 落第 2 档（不是第 1 档，也不是「证据不足」：样本量与确定性门槛都过）。
**实测结论**：反事实**成立**（复跑 426 条零失败、两次跑零不一致），但**不特异**——同规模随机扰动改结论的概率**不低于**最小扰动（R1 还显著更高，t=−3.33）。**这是「测出反向差异」，不是「没测出差异」**，故不写成「没有效果」。
证据强度：C0/C3 = 每对 2 次跑 × 426+120 条（单机单 seed，非多 seed）；C1 = 240 个配对单元格。
**推断（不作结论）**：随机换字更常破坏内容词、从而更常改变候选与类型库存——这是机制猜想，需干预实验，本单元**未测**。

## 5. 遗留与不确定

- **实测/推断已分开**：本报告所有表格数字 = 实测；标「推断」的只有 §3 末两句机制猜想。
- **F5 证据不足（实测）**：本语料因果连接词仅 2/120 句 ⇒ F5 的 C0/C1/C2 都只有 n=1–2，**不入判定**；未实现「跨语料补足因果句」的方案（需换样本总体，属另一单元）。
- **未实现（明说）**：① `gen_dispatch` 的 generate/pointer/reject 三通道口径**未纳入**（本单元只解释 `card_flow`
  五段流输出）；② 随机对照只做 R1/R2 两种，没做「随机换标点/随机删字」；③ 扰动是**词表驱动的字符级**，
  没有依存/语义级扰动；④ 没有做任何干预实验 ⇒ 因果机制**留白**（边界句）。
- **口径依赖（推断）**：F1/F4 表经 [修订1] 扩充；若只用首版表，适用单元格仅 204/600，C2/C1 会更稀。
- **不确定**：CPU 与 GPU 前向是否逐位一致**未测**（本单元只在 CPU 上自洽；基线 36/84 与 GPU 版同数是间接旁证）。
