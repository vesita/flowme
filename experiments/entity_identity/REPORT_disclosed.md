# entity_identity — P12c 补测四条披露规则（R-keyword / R-abbr / R-prefix / R-ctxwin）

> 范围：**只实测 PREREG §3 不计入 E0 的四条披露项**；纯 CPU、不训练、不重生成数据、不改 `src/`、未改 PREREG。
> 口径：**实测** = 本目录产物直读；**推断** = 由实测推出。只新增文件，未动 P12a 任何产物。

## 1. 规则定义（PREREG §3）+ 阈值来源 + 给规则最大优势的做法

| 规则 | PREREG §3 定义 | 族内候选（最大优势） | 阈值来源 |
|---|---|---|---|
| R-keyword | 上下文显式同一性词 | 禁词表 + 同义/指代词 + 称谓 + 类别词**四表并集**，计数与命中 0/1 各作候选，两方向 | train 拟合 |
| R-abbr | 手写简称词表：包含 + 后缀 + 去姓 | 任务口径加**取首字 / 取前 2 字 / 取前 3 字 / 去后缀 / 子序列**，两方向 | train 拟合 |
| R-prefix | 两提及紧邻前 2 字是否相同 | **两种读法都进族**：提及串自身前缀 pf1/2/3、后缀 sf1/2/3、提及前上下文 ctxpf1/2/4 | train 拟合 |
| R-ctxwin | 两侧 ±4 字窗口串是否相等 | 宽 k=2/3/4 × 前/后/双侧/任一侧 串相等 + **窗口字符 Jaccard** + 「他提及落在窗内」包含读法，两方向 | train 拟合 |

阈值网格 = train∪test 唯一值中点 ± 哨兵（与 P12a `e0_literal_rules.py` 完全同一网格）；每族取
**max(train 拟合的 test acc, test 族内 oracle)** —— 与 P12a 同口径，本四条的 train 拟合候选与 test oracle 候选**恰好同一条**（无拟合优势差）。

## 2. 主表（test n=1200，SE=1.443pt，门槛 97.114%；逐型 n=300，SE=2.887pt）

|---|---|---|---|---|---|---|---|---|
| R-keyword | 无代词 ⇒ DIFF | 75.000% | **75.000 ± 1.443pt** | 0.0% | 100.0% | 100.0% | 100.0% | < **过** |
| R-abbr | 前 2 字相同 ⇒ DIFF (`ab_f2`) | 98.975% | **99.167 ± 1.443pt** | 100.0% | 100.0% | 100.0% | 96.7% | **≥ 不过** |
| R-prefix | 前 2 字相同 ⇒ DIFF (`pf2`) | 98.975% | **99.167 ± 1.443pt** | 100.0% | 100.0% | 100.0% | 96.7% | **≥ 不过** |
| R-ctxwin | 两侧后窗字符共享 ⇒ DIFF (`cw_ja2`) | 100.000% | **100.000 ± 1.443pt** | 100.0% | 100.0% | 100.0% | 100.0% | **≥ 不过** |

- **G1 专门关注点均命中**：`R-abbr` 对 A 型 = **100.0%**；`R-ctxwin` 对 B 型 = **100.0%**。合并 acc 没有掩盖逐型满分。
- `R-abbr` 与 `R-prefix` 的取胜候选是**同一特征**（`ab_f2 ≡ pf2` = 提及串前 2 字相同）。
- **字面最窄读法的对照（同族内实测）**：R-abbr 只用 PREREG 三件套（包含/后缀/去姓）= **62.5%**；R-prefix 的上下文读法 `ctxpf2` = **50.0%**；R-ctxwin 的字面「±4 串相等」`cw_b4/cw_a4/cw_ba4` = **50.0%**；R-keyword 禁词表本身 `kw_id` = **50.0%**（关键词 0 命中，符合 PREREG §1 禁词断言）。
- 越线来自 PREREG 未覆盖、但任务明示要测的读法：**「取前 2 字」**（R-abbr）与**窗口字符 Jaccard/包含**（R-ctxwin）。

## 3. 泄漏机制（实测核实，0/1200 违例）

1. **R-ctxwin 100% = 模板槽位泄漏（不是窗口字面）**：DIFF 的 m2 固定落在第二子句（后接「是<城市>」）、SAME 的 m2 固定落在尾子句（后接「当年发布…」）；m1 恒后接「是」⇒ 「m2 后窗是否与 m1 后窗共享『是』」**violations = 0/1200**。该规则同时对学习头送分（比字面规则更危险）。
2. **R-abbr/R-prefix 99.167% = C 同形 + D 差异位几乎固定在第 3 字**：`前 2 字相同 ⇒ DIFF` **violations = 10/1200**，全部是 D 型「小明/晓明」对（10 对 D_PAIRS 中仅此 1 对差在第 2 字）；A 型别称一律丢姓/丢首字 ⇒ 前 2 字必不同 ⇒ A 恒判 SAME。

## 4. 判定（三选一）

**构念门不成立** —— 四条披露规则中 **R-abbr = 99.167%、R-prefix = 99.167%、R-ctxwin = 100.000% 均 ≥ 97.114%**（R-keyword 75.0% 低于门槛）。G0 判据「任一条 ≥ ⇒ 报警」触发。

**补救方向（数据构造层，须重生成数据后重跑 P12a 全套 E0 再训练）**：
- **R-ctxwin**：把「目标提及所在的子句槽位」在两标签内**打平/随机化**（SAME 的 m2 也进第二子句、DIFF 的 m2 也进尾子句），使「m2 后是否接『是』」与标签解耦。
- **R-abbr / R-prefix**：(i) D 型差异位**均匀铺到第 1..len 字**（现 D_PAIRS 仅 1/10 对差在第 2 字，其余差在第 3 字）；(ii) A 型加入**前 2 字相同的别称**（机构简称保留前 2 字，如 南京大学↔南京；人名加「姓+名首字」以外的前 2 字型别称）—— C 型同形不可改，只能把 SAME 侧的 pf2 命中率抬到与 DIFF 相当。
- 改后**四条 E0 字面规则 + 本四条披露规则一起重跑**，全部 < 97.114% 才恢复建卡。
