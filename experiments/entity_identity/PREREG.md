## 0. 唯一问题

**给定一段文本与其中两个提及，判定它们是否指同一实体 —— 这件事能不能做对，且是否泛化到未训实体？**
而且它必须先过**构念前置门**：字面（字符串）规则做不了；再赢过一张平凡查表。

**依据（已实测，不重新论证）**：`core_probe/REPORT.md` 身份-回忆 idr 线性读出 98.83 / 免费规则 .7918（+19.6pt、方向近正交、随深度 +28.9pt）⇒ 身份是今晚唯一有真增量的一元；
`syllogism_card/report.md` 必须比较实体同一性的「直链」只有 47.65（≈盲猜）而字符串 `R-chain` 直链 100.00 ⇒ 推理头只会表面查表。
本单元**只回答两件事：① 能否判定同一性；② 是否泛化到未训实体。不回答因果，也不回答「动核会不会更好」**（核全程冻结、未跑动核门禁 ⇒ 那条按未测处理）。

## 1. 数据（程序生成 + 可核对；不读任何语料 ⇒ `dev-notes/19` 的 `fs[:N]` 陷阱不适用）

**标签来源（口径判断，跑前写死）** = 生成器内部的**实体 id 分配表**：每条提及在生成时绑定到某个实体 id，
label = `两提及的实体 id 是否相等`。**该来源独立于任何字面规则**（字面只是实体名的一种渲染）⇒ 满足
`dev-notes/21 §6` 构念效度的「来源独立」一翼。

四型各 **1/4**（主臂 X）：

| 型 | 提及对（字面关系） | 期望 | 生成方式 |
|---|---|---|---|
| **A 正·别称/简称** | 人：`王建国`↔`建国`（**编辑距离 1**）；机构：`南京大学`↔`南大`（距离 2） | 同一 | 同一实体的全名与简称 |
| **B 正·代称/指代** | `王建国`↔`他`、`南京大学`↔`该校`（**零共享字**） | 同一 | 同一实体的全名与代称 |
| **C 负·同形不同实体** | `张伟`↔`张伟`（**距离 0**） | 不同 | 实体表里**故意放两个同名不同人**（不同城市/科室/单位） |
| **D 负·相似但不同** | `王小明`↔`王晓明`、`北京大学`↔`北京大學`（**距离 1**） | 不同 | 近名不同实体 / 简繁异体指向不同机构 |

**关键（E0 的靶子）**：正例字面不同、负例字面相同或极近 ⇒ **「字面相同」「字面不同」都不是答案**。
A 型特意铺**距离 1 的正例**（人名去姓），使距离族规则在两类上重叠 —— 这是构造的核心配平，不是事后调参。

**场景（每条文本都含 2 个实体、3 个名字提及、2 个目标提及；避免「数人头」查表）**：
文本 = 1–2 句场景描述，含 **a)** 两个目标提及，**b)** 一个额外提及（干扰实体或同实体复现），
使**两标签的实体数、提及数、句数、文本长度桶逐分布配平**；**同句/异句在两标签内各半**（结构计数规则失效）。

**证据类型（跑前写死，混用，避免单一窗口查表）**：① 属性一致 vs 冲突（城市/科室/单位）；
② 代词附着（唯一先行词 vs 有竞争先行词）；③ 事件/时间连续；④ 别称包含 + 无冲突属性。
**禁止显式同一性关键词**（`简称/又称/同一人/另一所/两人/即/也就是` 不出现在生成模板里）⇒ 披露项 `R-keyword` 不应满分。

**提及定位（手写规则，跑前写死，对所有臂、所有规则一致）**：
`m1 = s1 的第一次出现`；`m2 = s2 的第一次出现且与 m1 区间不重叠`（`s1 == s2` 时自然取到第二次）；
定位失败（找不到 / 重叠）⇒ 生成期 assert 丢弃并计数。**渲染所需的动词**取「第一个不与两提及重叠的 `是`」，
生成期 assert 每条文本都存在。⇒ 引用层是**手写规则**，判定层是**学习头**（符合 `dev-notes/21 §16.3`：解释 = 手写规则 + 结构指令 + 引用映射）。

**丢弃率必报**：生成期被 assert（定位失败 / 无 `是` / 截断超长 / 模板撞车）丢弃的比例，逐型报。

### 1.1 三臂（唯一变量各自只有一个）

| 臂 | 训练 | 评测 | 唯一变量 |
|---|---|---|---|
| **X** | 均衡 4000（1000/型），实体跨 split 共享 | 同分布 held-out **1200**（300/型） | — |
| **X-ir** | 提及对**零共享字**的均衡 2000 | 零重叠 held-out **1200**（SAME/DIFF 各 600） | 训练集里有没有字面重叠 |
| **X-cross** | 实体集 **EA** 的 4000（1000/型） | **未训实体 EB** 的 1200（300/型） | 实体是否见过（实体级划分，不许 `fs[:N]` 式切分） |

**X-ir 的型构成（跑前声明，避免事后解释）**：`零共享字` 与「C 负·同形」矛盾（同形必然共享字）⇒
X-ir 的正例 = B 型（全名↔代称），负例 = **零重叠变体**：(i) 两个不同实体的异名对；(ii) **代称错配**
（`他` 绑定到 e1，而查询对是 `他`↔e2 的名字 ⇒ 不同）。两者构成**同一表面骨架的最小对照**（都是「代称+名字」，
只有绑定不同）⇒ 该臂测的正是「零字面线索下能否判定」。
**边界（跑前声明）**：X-ir 与 X 的**绝对值不可直接比**（型构成不同），只比「各自 vs 各自 max_naive」。

**E0 前置门在哪个集上判**：**主臂 X 的 test**（三臂 test 都会报出）。

## 2. 卡（核**全程冻结**，只训头 ⇒ 不触发「动核必付老卡」）

核 = `checkpoints/base_encoder.pt::doc_encoder`（hidden 128、1,688,460 参数，`eval()` + `requires_grad=False`）。
**若要动核必须在此写明 + 配 E4 门禁 —— 本单元不写 ⇒ 视为不动核。**

- **取层（跑前写死，不扫）**：`blocks[2]` 输出（`core_probe` 实测 idr 最佳层 b2 = 98.83，随深度 +28.9pt），
  hook 捕获，`enc()` 返回值 = `norm` 输出，二者同一次前向对账。
- **特征（核外私有头的输入）**：`[v1, v2, v1⊙v2, |v1−v2|, w1, w2, g]`，
  `v` = 提及 span 内 masked mean，`w` = 提及两侧各 6 字窗口 masked mean，`g` = 全文 masked mean ⇒ **7×128 = 896 维**。
- **头（核外私有）**：`Linear(896,256) → GELU → Linear(256,2)`；**2 类 = SAME / DIFF**。参数量打印进 meta。
- **训练**（配方跑前写死、跑后不改）：核冻结特征缓存 → AdamW、lr **1e-3**、wd **1e-4**、cosine、clip **1.0**、
  batch **64**、**1000 步**、seed **42 / 43**；`--randlabel` 只对训练标签 `randperm`（保类分布）。

### 2.1 结构化指令与 render 复用（机械层）

判定不是裸标签，而是**结构指令**：`Instruction(skeleton_id, assignment)`，
`assignment = (ref_m1, ref_verb, ref_m2)`，**skeleton_id 承载同一/不同**：

| 判定 | skeleton | pattern | 槽位 | 渲出文本例 |
|---|---|---|---|---|
| 同一 SAME | `S01`（**内置骨架，原样复用**） | `[1][2][3]。` | 名施事 / 动 / 名受事 | `王建国是建国。` |
| 不同 DIFF | `N01`（**本单元新增，走同一套门禁谓词**） | `[1]不[3][2]。` | 名施事 / 动 / 名受事 | `张伟不是张伟。` |

`N01` 只许用**手写闭集内的形式词/逻辑词** ⇒ 进表前跑同一套门禁：`rule_a_problems` + `slot_schema_problems`
（`render.validate_skeleton_table` 要求表与内置 `_SKELETON_LIST` 完全一致，故对 `N01` 单条跑它的**同两条谓词**，
结果打印进 report；表规模 18 ≤ `SKELETON_TABLE_LIMIT=40`）。字面里的逻辑词 `不` 属「否定必须逐字或显式」⇒
用 `Declared(logic=("不",))` **显式声明**（意图卡声明，跑前写死），否则 `word_face_problems` 拒。

**复用的 `render.py` 谓词（原样 import，不改 `src/`）**：
`item_problems`（evidence 逐字 span + 类型/题元在域内 + **零信息新增回溯**）、
`check_structure`（I1：schema + 规则 0/A/B + 词面守卫 + 零信息新增）、
`render`（确定性纯函数）、`check_deref`（I3：ref_map 分区覆盖 + 逐条回溯 span）、
`_record` 的同构记录（`{kind, text, evidence, plan_step_id, instruction, ref_map, reason}`）。
**任一检查不过 ⇒ fail-closed `kind="reject"` ⇒ 该题计 0 分**（`parse_ok` 必报）。
`evidence` 每条 = `{source:"span", ref, text, span, candidate_id}`（内容）或 `{source:"table", unit_id, word, cls}`（功能词）。

## 3. `max_naive` 电池（并列 `max_naive`，报 `卡 − max_naive`）

**计入（4 条字面 + 3 条平凡）**：

| 规则 | 定义（族内阈值**在该臂 train 上取 acc 最高**者，test 上评测） |
|---|---|
| `R-exact` | 字面相同 ⇒ DIFF，否则 SAME |
| `R-edit` | 编辑距离（绝对 / 归一）阈值族 |
| `R-ngram` | 字符 1/2-gram Jaccard 阈值族 |
| `R-lcs` | 最长公共子串（占 maxlen 比 / 包含判定）阈值族 |
| `majority` | train 多数类 |
| `length` | 文本长度桶（`len//8`）→ train 该桶多数类 |
| `structure` | `(同句?, 提及数, 句距桶)` → train 查表多数类 |

**披露项（不计入，单列，沿 `dev-notes/20 更正3` / `R-lexdir` 口径）**：
`R-keyword`（上下文显式同一性词）、`R-abbr`（手写简称词表：包含 + 后缀 `大学/公司/网/社` + 去姓）、
`R-prefix`（两提及紧邻前 2 字是否相同）、`R-ctxwin`（两侧 ±4 字窗口串是否相等）。
**必须报 `卡 − 每条`（含 4 条字面规则逐条）。**

## 4. 判据（**跑前写死**）

test n = **1200** ⇒ `SE = sqrt(0.25/1200) = 1.443pt`，`2×SE = 2.886pt`，`1 − 2SE = 97.114%`。

| # | 判据 | 门槛 |
|---|---|---|
| **E0（前置·构念）** | **四条字面规则上限**（train 拟合阈值的 test acc **与** test 上族内 oracle 上限，取大者） | **全部 < 1 − 2×SE = 97.114%**；**若任一 ≥ ⇒ 停下改数据构造**（本实验生死门）。四条 acc 全部报出 |
| **E1（主）** | X 臂 held-out acc | **> `max_naive` + 2×SE**，**2 seed（42/43）同号**；同时报 X-ir / X-cross 各自 vs 各自 `max_naive` |
| **E2** | **负例（C 同形 / D 相似）不许塌** | **逐型 recall 必报**；C 型与 D 型各自的 acc 均须 > 该型 `max_naive` + 2SE（`n=300 ⇒ SE=2.887pt`） |
| **E3** | 随机标签对照（只 `randperm` 训练标签） | acc ≤ 多数类 + 2×SE |
| **E4** | 老卡 Δ（pronoun 2.83 / sentiment 0.41 / relation 1.39 / person 0.33 pt） | Δ ≥ −各自带 + **sha256 训前 = 训后** + `core_drift = 0` |
| **E5** | 解释可得性 | **零信息新增违例 = 0** + **引用逐字回溯违例 = 0**（`check_deref` + 独立回溯各跑一遍）+ 注入反例全部被抓 |

**判定三选一**：**实体同一性卡有真能力**（E0 ∧ E1 过） / **仍是表面可解**（E0 不过 ⇒ 按 PREREG 停下改数据构造后重跑，仍不过才判此） / **证据不足**（其余）。**不许硬选。**

**注入反例（必须故意做，且必须被抓到）**：
- **C1 篡改引用**：把 `ref_map` 的 span 改成越界/非子串 ⇒ `check_deref` 必须报违例；
- **C2 袋 span 非输入逐字子串** ⇒ `item_problems` 必须报「evidence 不齐备」；
- **C3 零信息新增**：`screened=False` / `candidate_id=""` ⇒ `item_problems` 必须报「零信息新增违规」；
- **C4 指令与判定不一致**：把 skeleton 改成 `N01` 而标签仍 SAME ⇒ 本单元一致性检查必须报违例。

**边界句（必须写进 `report.md`）**：
