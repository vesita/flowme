# 对抗集路由验证（task-9 · 对抗性验证子代理）

**唯一问题**：在对抗集上，路由（复刻 E4 的线性探针）是否还有本事？

> 本文件的 §4 判据在跑探针**之前**写死（预注册），事后不改；结果填在 §5–§7。
> 「实测」= 本目录跑出来的数字；「推断」= 由数字推出的判断；「口径判断」= 构造时人为规定的标签归属。

---

## 1. 对抗集构造方法（5 类 × 45 条 = 225 条）

脚本：`build_adversarial.py`（seed=20240927 固定，fail-closed 逐条校验，产物 `adversarial.jsonl`）。
每条含 `id / category / surface_card(表面像的卡A) / true_label(真该路由的类B) / text / rule / known_answer / evidence`，可逐条追溯。

| 类别 | 表面像 A | 真标签 B | 自动校验（不满足即整条丢弃） |
|---|---|---|---|
| C1 多代词·主任务情绪 | pronoun | sentiment | 人称代词出现 ≥3 次 + 含词表情绪词 + 不含 不/没/未/非 |
| C2 两成语·非词表对 | relation | neutral | 句中 ≥2 成语 ∈（idiom 卡词表 ∪ 11 条补充成语）+ 任意两成语不构成词表近/反义词对 + 全句无任何完整词表词对共现（生成池另限定成语 ∈ IDIOMS−VOCAB，词表外） |
| C3 真实人名·普通陈述 | person | neutral | 恰 1 个人名库专名 + 无代词 + 无情绪词 + 不含 不/没/未/非/别 |
| C4 否定词·整体积极 | (negation 字面) | sentiment | 含否定标记（不/没/未/非，在积极情绪词之外） + 含积极(类1)情绪词 + 情绪词左侧不紧邻 不/没/未/无 + 无类2/3情绪词 |
| C5 中性句·含情绪词字面 | sentiment | neutral | 含情绪词字面 + 代词 ≤2 + 人工保证整体中性（引述/元语言/A-not-A/无关陈述） |

- 词表现取自 `src/dtseek/tasks/builtin/`（relation 的 SYN/ANT 539 对、idiom 2214 条、sentiment 199 词、person 48 专名、pronoun 代词表）；
  **例外**：C2 另含 11 条人工补充的公认成语（守株待兔 / 画蛇添足 / 掩耳盗铃 等 —— 语料频次不足未入 idiom 卡词表，但确为成语），清单见 `build_adversarial.py` 的 `HAND_IDIOMS`。
- **标签口径（构造期预注册的判断，非事后）**：
  - 探针标签空间 = E4 的 5 类 `{pronoun, sentiment, relation, person, neutral}`（复刻 E4 口径，不扩类）。
  - 已注册但**不在** E4 空间的卡（idiom / negation / ownership）：C2 归 `neutral`（「不属四卡」；若纳入 idiom 卡，其正确路由是 idiom —— 已在 §8 局限中列明）。
  - C1/C4 判 sentiment：以「主任务语义」为准（Lead 指定口径）；C4 句中必含积极情绪词以消除 sentiment/neutral 歧义。
  - 多数类基线（跑前算死）：neutral 135/225 = **M0 = 60.0%**；5 类均衡基线 20%。
- **已知答案对照**：`known_answer=true` 共 **15 条**（每类 3 条），构造时逐条人工复核、跑探针前定稿。
- 构造实测：耗时 2.0s；fail-closed 仅淘汰 2 条（pronouns_lt3 ×1、has_negation ×1）；对抗集与 E4 各卡数据**零重复**（逐文本精确匹配，实测 0 条，`results.json.meta.dup_with_e4_data`）。

## 2. 探针口径（复刻 E4，`run_probe.py` / `probe_e4_style.py`）

- 冻结基座 `checkpoints/base_encoder.pt` → `NanoDocEncoder`，有效 token `doc_memory` mask-mean-pool，D=128。
- 单层逻辑回归（零初始化，AdamW lr=0.05，weight_decay=1e-4，200 epoch，batch 64），seed 42/43/44 三档。
- 训练/测试分布与 E4 逐项一致：4 卡各 600 训 + 200 测，中性池 600 训 + 200 测（5 类）；训练集不接触对抗集。
- 同一个探针分别评 ① 原始分布测试集 ② 对抗集（对抗集文本固定，与 seed 无关）。

## 3. 指标（逐项报，不合成）

| 指标 | 定义 |
|---|---|
| `route_acc` | 预测类 == true_label 的准确率（原始测试集 / 对抗集各报一次） |
| `route_bg_fp` | true_label=neutral 的样本被分到 4 张卡的比例（背景被强行派活） |
| `route_macro` | 每类召回的宏平均（原始集 5 类；对抗集覆盖到的类，如实标注） |
| 对抗集准确率 | = 对抗集 `route_acc`，另附每类 45 条的分项与「预测成表面卡 A」比例 |

## 4. 判据（**跑前写死，事后不改**）

设 `P0` = 本次复刻 5 类探针在**原始分布测试集**上的 3-seed 平均准确率（E4 参考值 98.73%），
`adv` = 同一探针在**对抗集**上的 3-seed 平均准确率，`M0 = 60.0%`（对抗集经验多数类基线）：

1. `adv < P0 − 20pt` **或** `|adv − M0| ≤ 5pt` ⇒ 判 **「路由主要靠语体捷径」** ⇒ 阶段三跳过路由、直接做组合算子；
2. `adv ≥ P0 − 10pt` ⇒ 判 **「路由有真本事」**；
3. 其余（落在中间地带）⇒ **「证据不足、需扩样本」**，不强行二选一。

已知答案对照的用法：15 条先于结论单独出数（`known_answer_acc`）。若其标注经复核有错则修标注并留痕；
探针在其上出错**不**改判据，只在结论里说明错误性质（标注问题 vs 探针问题）。

## 5. 对照（有效性先说清）

| 对照 | 做法 | 有效性声明 |
|---|---|---|
| 打乱标签 | 训练标签 randperm 后重训同一探针 | **有效**：直接破坏 X–Y 对应；但逐 seed 噪声大（见 §6.4），只作方向性证据 |
| 随机高斯特征 | 特征整体换成 N(0,1)，标签不变 | **有效且独立**：剥离全部语言结构；两套实现均稳定贴 20% |
| 正交阵随机投影 | **不用** | dev-notes/11 教训：精确保持余弦 ⇒ 不构成独立证据；本实验明确弃用 |
| 多数类基线 | 原始集 20%（5 类）/ 对抗集 60.0%（M0） | 无条件成立 |
| 已知答案 15 条 | 构造期人工复核，先于结论出数 | 标注质量对照 |

## 6. 实测结果（2026-09-28 跑完；**两套独立实现，主臂数字逐位一致**）

| 实现 | 脚本 / 产物 | 命令与耗时（GPU，裸 `uv run python`） |
|---|---|---|
| A（复核方） | `probe_e4_style.py` / `probe_results.json` | `uv run python experiments/adversarial_routing/probe_e4_style.py --seeds 42,43,44 --out experiments/adversarial_routing/probe_results.json`（3-seed ≈2 分钟，未单独计时） |
| B（验证方） | `run_probe.py` / `results.json` | `uv run python experiments/adversarial_routing/build_adversarial.py`（实测 **2.0s**）+ `uv run python experiments/adversarial_routing/run_probe.py`（实测 **61.7s**，单 seed ≈19s）；`bash experiments/adversarial_routing/run.sh` 一键复现 |

两套代码独立编写、同一对抗集、同一 E4 口径：原始集 98.60 / 99.00 / 98.90、对抗集 12.00 / 9.33 / 6.22、
`route_bg_fp` = 100%、已知答案 3/2/2、五类分项与陷阱率 —— **全部逐位相同**（确定性管线）⇒ 主臂结论经独立复现。
对照臂因 RNG 洗牌/抽样路径不同而数值不同（见 §6.4），两套都落在随机水平。

**复刻核对**：原始分布测试集 3-seed 平均 P0 = **98.83%**（E4 参考值 98.73%，差 0.10pt）⇒ 口径对齐通过。

### 6.1 原始分布 vs 对抗集（3 seed，均值 ± 极差；A/B 一致）

| 指标 | 原始测试集 n=1000（5 类，多数类 20%） | 对抗集 n=225（M0 = 60.0%） |
|---|---|---|
| `route_acc` | **98.83% ± 0.40pt**（98.60 / 99.00 / 98.90） | **9.19% ± 5.78pt**（12.00 / 9.33 / 6.22） |
| `route_bg_fp` | 0.00% ± 0.00pt（3 seed 全 0） | **100.00% ± 0.00pt**（135 条 neutral 全被派卡） |
| `route_macro` | 98.83% ± 0.40pt | 11.48% ± 7.22pt（覆盖类 = {sentiment, neutral}） |
| 预测成表面卡 A 比例 | — | **46.85% ± 3.33pt**（48.33 / 47.22 / 45.00；分母 180，c4 的 A=negation ∉ 五类标签空间故 n/a） |

补充（实测）：3 seed × 225 条对抗样本里，预测为 `neutral` 的次数 = **0**。

### 6.2 对抗集分项（每类 45 条，3-seed 均值；A/B 一致）

| 类别 | 表面 A → 真标签 | route_acc | 预测成 A 比例 |
|---|---|---|---|
| c1 多代词·情绪 | pronoun → sentiment | 4.4% | 57.0% |
| c2 两成语·词表外 | relation → neutral | 0.0% | 83.0% |
| c3 真实人名·陈述 | person → neutral | 0.0% | 9.6% |
| c4 否定词·整体积极 | (negation) → sentiment | 41.5% | n/a（A 不在标签空间） |
| c5 中性句·含情绪词 | sentiment → neutral | 0.0% | 37.8% |

### 6.3 已知答案 15 条（先于结论出数）

`known_answer_acc` = **15.56% ± 6.67pt**（3/15、2/15、2/15）。
- 答对的全部是 c4 的 3 条：共 7/9 次正确（c4-02、c4-03 三 seed 全对，c4-01 仅 seed42 对）；c1/c2/c3/c5 的 12 条在 3 seed 共 36 次预测中**全错**。
- 12 条错误预测**全部落在 4 张卡类**（relation / pronoun / person / sentiment），零次落 neutral。
- 15 条原文逐条人工复看：标签与 §1 口径一致（c1 情绪主任务、c2 词表外归 neutral、c3 普通陈述、c4 积极满足、c5 元语言引述）⇒ 判定为**探针问题（走表层），非标注问题**；判据不改。

### 6.4 空洞对照（有效性先声明；A/B 两套实现各自出数）

| 对照 | 原始测试集 acc（均值 ± 极差） | 对抗集 acc（均值 ± 极差） | 有效性 |
|---|---|---|---|
| 打乱标签 · A | 16.43% ± 15.40pt（7.7 / 18.5 / 23.1） | 17.33% ± 27.11pt（7.6 / 34.7 / 9.8） | **有效**（破坏 X–Y 对应，落在 20% 机会水平附近）；逐 seed 噪声大 |
| 打乱标签 · B | 24.60% ± 20.90pt（18.7 / 17.1 / 38.0） | 7.85% ± 10.22pt（11.6 / 10.7 / 1.3） | 同上；两实现逐 seed 值不同（洗牌路径不同），该臂只作方向性证据 |
| 随机高斯特征 · A | 19.27% ± 1.50pt（18.5 / 19.3 / 20.0） | 22.52% ± 1.78pt（21.3 / 23.1 / 23.1） | **有效且独立**：剥离全部语言结构，稳定贴机会水平 |
| 随机高斯特征 · B | 19.30% ± 1.10pt（19.0 / 20.0 / 18.9） | 22.67% ± 4.89pt（23.1 / 20.0 / 24.9） | 同上；与 A 一致 |
| 正交阵随机投影 | 未采用 | 未采用 | **明确弃用**：dev-notes/11 / §5——精确保持余弦，不构成独立证据；本实验不用它充数 |
| 多数类基线 | 20% | M0 = 60.0% | 无条件成立 |

两条对照都是独立证据（分别破坏标签对应 / 剥离语言结构），结论不依赖被弃用的正交阵对照。
真臂在对抗集上的 9.19% **没有超过任何一条空洞对照**（A：17.33 / 22.52；B：7.85 / 22.67），全部未过 ≈20% 的机会水平 ⇒
对抗集上**不存在可用信号**；再结合分项里预测**稳定落在表层卡 A 一侧**（c2→relation 83.0%、c1→pronoun 57.0%）⇒ 不是随机乱猜，而是按表层特征系统性答错。

## 7. 判定

`P0 = 98.83%`，`adv = 9.19%`，`M0 = 60.0%`（A/B 两套独立实现得出相同数字）：
- `adv < P0 − 20pt`：Δ = **89.65pt ≫ 20pt** ⇒ **规则 1 触发**；
- `|adv − M0| = 50.8pt > 5pt`：第二触发条件**未**命中（如实记录）；
- 结论按 §4 预注册判据 = **「路由主要靠语体捷径」** ⇒ 阶段三跳过路由、直接做组合算子。

## 8. 局限与不确定项

- **实测**：上述全部数字；3 seed × 两套独立实现；探针为线性 + mean-pool，复刻 E4 口径。
- **推断（未实测分离）**：对抗文本是手写短句（长度 8–28，均值 17.1，实测），与卡样本分布不同域（sentiment 均值 9 / pronoun 27 / relation 30 / person 40），故「表层特征捷径」与「一般性域漂移」未被完全分离；分项里 c2 直接复用 relation 训练原帧（同语体）仍 83% 中招、c4 情绪词 100% 覆盖仍只有 41.5% 对，支持前者，但非决定性。
- **单标签口径**：c1 这类句子 pronoun 卡也会合法命中，按 Lead 口径「主任务=情绪」记分；若允许一文多卡，c1 的「错」会部分变成「漏选」。但 c2/c3/c5 单标签无争议且 0% / 0% / 0%，判定不依赖 c1。
- **对照臂噪声**：打乱标签臂逐 seed 波动大（A 与 B 的原始集分别 7.7–23.1%、17.1–38.0%），只作方向性证据；主判定用的是真臂 vs 判据，不依赖该臂。随机特征臂两套实现均稳定 ≈20%。
- **口径限制**：结论只对「冻结基座表征上的线性探针」成立，不等于 5 卡路由模型端到端行为（推断）。`multitask_v2_dtseek.pt` / `arm_neg5_seed42.pt` 是一体 ckpt，`read_base` 拒载（实测 ArtifactError），未拆分后复测。
- **标签口径**：c2 归 neutral 是 §1 的口径判断（若纳入 idiom 卡则正确路由是 idiom）；c4 的 A 不在五类空间，A 比例对其不适用。
- **样本量**：对抗集 225 条、每类 45 条、已知答案仅 15 条；分项单类 45 条的置信区间较宽（单 seed 比例分辨率约 ±7pt，已用 3-seed 降噪）。
