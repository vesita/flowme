## 0. 唯一问题与假设

**用「真实输入 + 卡片提议 + 可核对筛选」造出来的数据，能不能训出一张比注入式合成数据更好的卡？**

- 靶子是 `experiments/anchored_select`：注入式合成 ⇒ 标签**恰好等于朴素规则 100%**
  （正例=逐字片段、负例=保证不在上下文）⇒ 模型只能学注入痕迹（dev-notes/16 §5.5）。
- 假设（本实验证伪的）：把候选换成**真实输入上的指针式区间**、把标签换成**可核对谓词**的判定，
  训出的卡在**自然用句 held-out 集**上显著高于注入式对照。
- 若 D3 或 D4 不过 ⇒ 如实判「**该数据生成模式在当前口径下产不出可用数据**」；
  **不调参刷过、不改判据**。

## 1. 三步管线的口径（构造时写死）

### 1.1 第一步 · 候选生成（**不是注入**）

输入 = 语料真实句子（14–44 字、中文占比 ≥60%、无结构标记污染），语料入口只用
`src/dtseek/tasks/corpus.py::resolve_corpus_files`（glob 空即抛错，**不自己 glob**）。
候选 = `(区间, 类别)` + 该区间的文本；**区间必须是该句的真实区间**。四种来源（逐行记 `source`/`kind`）：

| source | 是什么 | 说明 |
|---|---|---|
| `neural_card` | **现有神经指针卡** `checkpoints/cards/{pronoun,sentiment}.pt` 在该句上的发射（区间+类别） | 真·卡片提议；发射可能错 ⇒ 天然负例 |
| `rule_card` | 卡的**真值源探测器**在该句上的输出（`extract_negation_spans` / `extract_emotion_spans` / `extract_all_spans`） | 手写、可审计的确定性指针输出 |
| `variant` | 同一句上的**竞争装配**：区间仍是真区间、类别仍是 spec 里出现过的名字，但与真值源不符 | 见 §1.2 各谓词 |

**负例也必须是真实区间的竞争装配**（绝不「从别处搬一个片段来」）——
这样「候选是不是原文的逐字子串」这条 anchored_select 的朴素规则在本数据上**恒为真**，
在 1:1 平衡集上准确率 = **50%**（= 多数类），而它在 anchored_select 上是 100%。

⚠ **诚实声明**：`variant` 一支是**构造出来的竞争提议**，不是任何卡的确定性输出；
它仍然全部是「真实输入上的指针式区间」（文本 100% 回溯到原文）。逐来源的判定与接受率分开报（D1）。
⚠ **诚实声明 2**：本轮的「现有指针卡」用的是**神经卡权重**（pronoun/sentiment）与**真值源探测器**（规则版指针发射）；
`negation` 无对应卡权重 ⇒ 只有规则版提议。神经卡提议在**CPU**上生成（实测 ~1000 句/s，不占 GPU）。

### 1.2 第二步 · 投机解析块筛选（**只用可核对谓词**）

| 谓词 | 判什么 | 可核对性 | 在本管线里的角色 |
|---|---|---|---|
| **P1 锚定** | `0 ≤ s < e ≤ len(输入)` 且 `输入[s:e] == 候选文本` | 纯字符串比对 | **准入**：不满足 ⇒ 从提议池**丢弃**（不进数据、不算负例） |
| **P2 可回溯/闭合** | 候选非空、≥1 汉字、**不以标点起止**、中文占比 ≥60% | 纯字符串比对 | **打标** |
| **P3 规范类别名** | 类别 ∈ 三卡 `TaskSpec.classes[].name`（`class.label` 展示名 / `spec.label` 任务名 **不算**） | 与 spec 快照比对 | **打标** |
| **P4 不跨分句** | 候选区间内**不含任何标点** | 纯字符串比对 | **打标** |
| **P5 与真值源一致** | `(类别, s, e)` ∈ 该句该卡真值源输出集合 | 手写真值源（可审计、确定性） | **打标** |

- **标签 = P2 ∧ P3 ∧ P4 ∧ P5**（在通过 P1 准入的候选上）；
- **P1–P4 是「纯可核对」**：不依赖任何口径，任何人都能重算；
- **P5 依赖手写真值源**（词表 + 例外规则），它的**内容**是口径判断，但**判定本身**确定性可复现；
- 全程**不出现学出来的分数**（§7.2：能用谓词判的就不许交给学出来的分数）。

**版式（两臂完全一致）**：`原文：{完整句}|候选：{候选文本}|类：{类别}`
—— 不把区间序列化进文本：区间已经由「候选文本必须锚定在原文上」这件事本身表达，
序列化成 `@s-e` 会把任务变成位置算术（`dev-notes/16` §5.5 实测锚定发射在冻结核下不学）。

### 1.3 第三步 · 重整（**只做非内容编辑**）

对**每一行**（不分标签）把语料片段拼成完整句，只允许三种编辑：

1. **标点**：补/去句末终止标点（`。！？`），不动句内内容字；
2. **连词**：在分句边界插入**一个连词**，且该连词的每个字都**不得出现在原句里**（否则无法无歧义回溯）；
3. **调序**：交换前两个分句（仅当该句有 ≥2 个分句）。

**内容上锁（fail-closed）**：把已插入的连词从输出里删掉、再剥掉标点后，
**字符多重集必须与原句逐字相等**；且**真值源在完整句上必须给出与原句逐位映射一致的输出**
（否则退到更弱的编辑方案，直到通过为止，最弱也必须通过）。
候选区间在完整句里按分句映射重定位，**重定位后重算谓词、标签必须与原句一致**，否则丢弃该行（计数上报）。
于是 §7.4 的不变量成立：**每个内容词都能回溯到原文（因而回溯到被筛为有效的候选）**。
任一断言失败 ⇒ 直接抛错，绝不静默降级。

## 2. 卡与训练口径

- 卡 `cand_validity`（候选有效性）：classes = (`无效`, `有效`)，`max_steps=1`、`max_len=96`、
  `emission=single`、`segment_policy=sentence`、`cls_weight_bg=1.0`（`max_steps=1` 时背景类不被稀释）。
- **只训头**：冻结核 `checkpoints/base_encoder.pt`（requires_grad 实测全 False，否则本步作废）+ `RobustARSliceDecoder`。
- 配方：epochs 12 × steps_per_epoch 150 = 1800 步、batch 64、lr_head 1e-3、cosine、AdamW wd 1e-4、
  grad clip 1.0、seed **42 / 43**、`--samples 8000`（与数据文件条数不符直接拒绝）。
- **随机标签对照（必做）**：train 的 `label` 整体 randperm（计数不变）后同配方重训，seed 42/43
  （shuf-seed = seed×1000+7）。
- 评测 `eval_card.py`：四集（train / test / adversarial / natural）× 主指标 + 附报 + 基线 + 与
  `evaluate_task` 逐数对账，不一致直接退出。
- **静默截断守卫**（`dev-notes/16` §5.5 踩过的坑）：逐样本实际编码长度 ≤ `max_len`，否则报错退出；
  同时报丢弃条数（必须为 0）。

### 2.1 指标口径（跑前写死）

- **acc（主指标，D4 用它）** = 逐样本**类**判对的比例 = 第 0 步 argmax 类别 == 真值类。
  `max_steps=1` 时 rollout 至多发射一条切片，故它与「判有效 ⇒ 发射恰一条且 label=1；判无效 ⇒ 不发射」
  逐样本等价；与 `evaluate_task` 的 `cls_acc`/`bg_fp` 可逐数对账（不一致直接退出）。
- **exact（附报，不过线）** = 类 + 区间逐位一致（无效要求不发射）。
- 附报 `span_hit`、`bg_fp`、逐类召回、逐来源/逐规则 acc、预测分布。

## 3. 集合与规模（构造时写死）

| 集合 | 规模 | 正:负 | 源句池 |
|---|---|---|---|
| train（提案臂） | 8000 | 4000 : 4000 | 12000 句 |
| test（提案臂） | 1600 | 800 : 800 | 3000 句 |
| **对抗集**（提案臂） | 1200 | 600 : 600 | 2500 句，**不进训练** |
| train / test / adv（**注入对照臂**） | 8000 / 1600 / 1200 | 1:1 | 4000 / 800 / 600 句（**独立池，与提案池也不相交**） |
| **natural（自然 held-out）** | 200 | 100 : 100 | **手写自然用句**，不经任何生成管线 |

- **四池两两不相交**（按源句切分），构建后**实测**行文本 / 输入句 两两重叠，任一非 0 ⇒ 抛错。
- **候选文本（词表词）跨集合复用**：正例候选是词表词（否定标记 / 代词 / 情绪词，闭集约 230 词），
  若强行要求它跨集合不相交，test 就只能考没见过的词 ⇒ 变成记忆测试。
  ⇒ **按 PREREG 要求逐维报出重叠**，`候选文本重叠` 单列并说明它是**词表共享**而非样本泄漏
  （行文本与输入句重叠才是泄漏口径，必须为 0）。
- **负例分层配额**（提案臂 train/test，可得量不足即抛错）：

  | 分层 | 占负例 | 失败哪个谓词 |
  |---|---|---|
  | `neural_err` 神经卡发射且与真值源不符 | 40% | P5 |
  | `crosscat` 真区间 + **别卡**的规范类别 | 25% | P5 |
  | `boundary` 区间 ±1 字 | 15% | P5 |
  | `alias` 真区间 + 该卡**展示名/任务名**（`积极/喜悦`、`否定标记`…） | 10% | **P3** |
  | `punct_edge` 区间咬到标点 | 10% | **P2 / P4** |

- **对抗集负例 50% `crosscat` + 50% `samecat`**（同卡错类，如 `我→第三人称`）：
  全部锚定、全部是词表词、类别全部规范 ⇒ **一切表层规则在对抗集上都退化到多数类**，
  只剩「类别与区间是否匹配真值源」一条信息。
- 正例 = 真值源输出（其中与神经卡发射重合的那部分归到 `neural_card` 来源）。
- **自然 held-out 集的候选全部锚定**：指针式候选在真实用法里必然是原文区间，
  所以任何**锚定型捷径在该集上恒等于多数类基线** —— 这是「指针式数据天生可核对」的直接后果，
  不是为打压对照臂而设的机关；两分布是否可比由 §4.1 的长度/语体统计说话。

## 5. 判据（**跑前写死**，事后不改）

设自然集 n = 200、多数类 M = 50.00%，**SE_M = sqrt(M×(1−M)/n) = 3.54pt**，
故 D4(a) 门槛 = **M + 2×SE_M = 57.07%**。

| # | 判据 | 门槛（跑前写死） |
|---|---|---|
| **D1** | 筛选的**可核对性** | 提案臂 train/test/adv 的标签 **100% 由谓词实现**；**必须分开报**：① 纯可核对谓词（P1–P4）各自的通过/拒绝/判否条数 ② 依赖手写真值源的判定（P5）条数 ③ **非谓词判定**（自然集人工标签、配额下采样这类**抽样决定**）单列。凡标签不是谓词判定的必须出现在 ③ |
| **D2** | **接受率非退化** | **原始提议池**（未下采样）的**有效性接受率** = 判有效数 / 通过 P1 准入的候选数，须落在 **[0.15, 0.85]**。理由：p=0.15 时标签熵 H = 0.423 nats = 最大熵的 **61%**（>60%），且两类各占 ≥15% ⇒ 过滤器既不是橡皮图章（p→1）也不是全拒（p→0），标签仍有信息。**另报 P1 准入率**（锚定过滤的丢弃量） |
| **D3** | **无免费捷径** | 提案臂 **train** 上「朴素规则」最高准确率 **< 90%**；**≥90% ⇒ 判该轮数据无效**并如实报。**朴素规则的定义（跑前写死）**：不复刻真值源、只用表层统计的零训练规则 —— 逐字子串 / 类别是否规范名 / 是否词表词 / 是否含标点 / 长度 / 候选在输入中的位置 / 类别名字符串集合，每条取 `max(该规则, 该规则取反)` 的最优方向。**真值源重实现单列**（它是任务定义本身，不作 D3 判据 —— 否则本项目任何规则标注的数据集都不可能过 D3），但仍必须报出 |
| **D4(a)** | **自然 held-out 增益** | 提案臂在 **natural** 上 acc ≥ **57.07%**，**两 seed 各自满足**（2 seed 同号） |
| **D4(b)** | **对照（D4 的实质）** | 同卡配方、同版式、同规模的**注入式对照臂**（复刻 anchored_select 构造与标签口径）在同一 natural 集上评测；**提案臂 − 注入臂 ≥ 2×SE_diff**（SE_diff = sqrt(p₁(1−p₁)/n + p₂(1−p₂)/n)），**两 seed 各自为正** |
| **D5** | 不伤老卡 | **本轮不走联合训练**（只训头、只加新卡）⇒ **N/A**，如实报「不适用」，不伪造数字 |
| **D6** | **多样性不塌** | 报 4 项：类别熵 H（nats）、distinct 候选文本/样本、distinct 输入/样本、每输入候选数。门槛：提案臂 train 的 **H ≥ 0.9×注入臂 H**、**distinct 候选率 ≥ 0.9×注入臂**、**distinct 输入率 ≥ 0.9×注入臂**；并与原始提议池同口径对照 |
| **V-bonus** | 随机标签对照（空测自检项） | shuf 臂在 natural 上 acc ≤ **57.07%**，且在自己 test 上 ≤ 50% + 3pt（两 seed）。若 shuf 也过 D4 ⇒ 判据恒真、整轮作废 |

- **结论三分（跑前写死）**：
  - **① 可用且优于注入式** = D1 ∧ D2 ∧ D3 ∧ D4(a) ∧ D4(b) ∧ D6 ∧ V-bonus 全过（2 seed）；
  - **② 可用但不优于注入式** = D1 ∧ D2 ∧ D3 ∧ D4(a) ∧ D6 ∧ V-bonus 过，但 **D4(b) 不过**；
  - **③ 该数据生成模式在当前口径下产不出可用数据** = **D3 或 D4(a) 不过**（或 D1/D2/D6/V-bonus 任一不过）。
- **不调参刷到过为止**：判 ③ 就如实报；换配方必须另开 PREREG。
