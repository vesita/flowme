# 锚定候选打标（experiments/anchored_select）—— 预注册判据

> **本文在首次训练之前写死**（mtime 必须早于任何 `train` 进程启动时刻），跑完不改；
> 结果填进 `results.md`。口径同 `experiments/input_type/README.md`：
> 「实测」= 本目录跑出来的数字；「推断」= 由数字推出；「口径判断」= 构造时人为规定的标签归属。

## 0. 唯一问题与假设

**一张卡能否学会「锚定候选打标」**：给定 (证据上下文, 候选片段)，判定候选**有没有证据支持**（二分类）。

- 为什么要问：投机式对话路径（生成候选 → 指针卡选择 → 重整）把零幻觉的保证放在**选择**这一步，
  而本项目已知最弱的一环正是选择（`reply_pick` 20.00% / `cloze_fill` 19.06%，与盲猜不可区分，
  dev-notes/13 §9）。若锚定二分类也学不会，这条路与 `reply_pick` 同因失败，**不该再往下建生成卡**。
- 假设（本实验要证伪的）：测崩的是「从候选里**选最优**」（需要跨候选语义偏好），
  而这里是「**逐候选判有没有证据**」（tagging，现有卡的长项）—— 两者难度不同，必须实测区分。

## 1. 标签口径（口径判断，构造时写死）

**支持 (label=1) ⟺ 候选在原文上下文里存在等价锚点**，等价锚点 = ① 逐字片段，或 ② 该片段的同义改写。
**不支持 (label=0) ⟺ 无等价锚点**（换词 / 反义 / 无关片段 / 同词表换位置）。

- 判据是**对文本的忠实性**，不是世界知识真假 —— 这与「指针卡要给出可回溯锚点」的用途一致。
- 实现为现有卡的 `span+class` 契约：正例发射候选区间（锚点 = 右侧候选字段的位置），负例 = 背景（不发射）。
- 残余标注噪声（推断，构造后人工抽检 20 条量化）：同词表换位置若恰好语义等价 ⇒ 标成 0 有争议。

## 2. 数据（合成，`build_data.py`，fail-closed）

- 语料入口 **只用** `src/dtseek/tasks/corpus.py` 的 `resolve_corpus_files(CORPUS_GLOB)`（glob 空即抛错，不绕过）。
- 输入布局：`原文：{context}｜候选：{candidate}`（正负例布局逐字相同，不泄漏标签）。
- 三个集合**按源句池两两切分**，构造后实测重叠（文本重叠与源句重叠都要报，**必须为 0**）：

| 集合 | 规模 | 正:负 | 正例 | 负例 |
|---|---|---|---|---|
| train | 8000 | 4000:4000 | 逐字片段 | ①换词 1334 / ②反义 1333 / ③无关片段 1333 |
| test | 1600 | 800:800 | 逐字片段 | ①267 / ②267 / ③266 |
| adversarial | 600 | 300:300 | **同义改写**（词表≠上下文） | **同词表换位置**（词表=上下文，位置重排） |

- **多数类/盲猜基线 = 50.0%**（三集均 1:1，跑前算死；构建期断言正负各半）。
- 对抗集**不进训练**：训练里没有任何换位置/改写样本 ⇒ 它考的是「忠实性」这一概念能否零样本迁移，
  专门考是否靠表层词汇线索作弊（逐字子串规则在对抗集上预期 ≈0%）。

## 3. 训练口径（现有卡机制）

- **主臂 = 只训头**：`training/train_task_card.py` 原方（冻结核 + `RobustARSliceDecoder` 头），
  经 `run_card.py` 包装注册本卡；epochs 12 × steps_per_epoch 150 = 1800 步、batch 64、
  lr_head 1e-3、cosine、base=`checkpoints/base_encoder.pt`（冻结、eval）、**seed 42 / 43**。
- 卡声明：`anchored_sel`，classes = (背景, 支持)，`max_steps=1`，`max_len=96`，
  **`cls_weight_bg=1.0`**（写死：`max_steps=1` 时每个样本恰一个监督信号，背景类不被稀释，
  默认 1.3 是给多切片任务用的，这里反而会引入偏向背景的先验）；其余损失权重用默认。
- **随机标签对照（P3 必做）**：把 train 标签整体 randperm（保持 1:1）后同配方重训，同 seed 两份。
- **P4 用的温启动联合臂**（`train_joint.py`，克隆 `cumulative_add` 的 `control` 口径）：
  核可训、四张老卡头冻结、新卡头可训，1344 步、lr_base 3e-4 / lr_head 1e-3、batch 64、
  起点 = `checkpoints/base_encoder.pt` + `experiments/capability_map/cards/{卡}_frozen_s{seed}.pt`，
  起点/末态都评四张老卡，Δ = 末态 − 起点（与噪声带比）。
- 自检（每次训练必打印）：真实可训参数量与冻结实况、正负比与多数类基线、随机标签对照真实执行。

## 4. 判据（跑前写死，两 seed 同号才下结论）

设 `test` = 测试集二分类准确率，`adv` = 对抗集二分类准确率，`M = 50.0%`（多数类/盲猜，跑前算死）。
**δ = max(2.0pt, 该判据所用集合上主臂两 seed 的极差 |s42 − s43|)**（逐集合各算，不共用）。

| # | 判据 | 门槛 |
|---|---|---|
| **P1** | 测试集二分类准确率 vs 多数类基线 | ≥ M + δ（两 seed 各自满足） |
| **P2** | **对抗集**上不塌回多数类 | ≥ M + δ（两 seed 同号） |
| **P3** | 必然对照：报**盲猜/多数类**基线 + **随机标签对照** | 随机标签对照 test acc ≤ M + 3pt（两 seed） |
| **P4** | 加这张卡不伤老卡（联合臂） | 老卡 Δ ≥ −**各自**噪声带：pronoun 2.83 / sentiment 0.41 / relation 1.39 / person 0.33 pt（两 seed） |
| **P5** | 报代价与样本量 | 数值：步时 / 峰值显存 / 可训参数 / 各集样本量 |

- 二分类准确率 = 逐样本「支持/不支持」判对的比例（正例：发射非空即判支持；负例：判背景即判对）；
  同时**附报**更严的 `exact_match`（判对且锚点区间逐位命中）与 `cls_acc`/`bg_fp`，不用于过线。
- **判定三选一**：
  **① 能学** = P1∧P2∧P3 在两 seed 全过（P4 另判「能不能加卡」，不过则判「能学但不能加」）；
  **② 不能学（锚定选择能力在当前核上不存在）** = P1 或 P2 在两 seed **都**不过；
  **③ 证据不足** = 其余（某判据只在一个 seed 过）。
- **不调参刷到过为止**：判 ② 就如实报；若要换配方，另开 PREREG。

### 附：必然对照与判别力对照（P3 明细）

| 对照 | 做法 | 期望 |
|---|---|---|
| 盲猜 / 多数类 | 三集各 50.0%（跑前算死，构建期断言 1:1） | 无条件成立 |
| 随机标签对照 | train 标签 randperm 后重训同配方 | test ≤ 53% |
| 逐字子串规则（零训练基线） | `candidate ∈ context` 即判支持 | train/test ≈ 100%，**对抗集 ≈ 0%**（它就是被对抗集针对的表层捷径） |
