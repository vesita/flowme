## 0. 唯一问题

**一条「句 → 命题结构 → 结论结构 → 前提引用」的三段推导链，能不能做对题 + 能不能泛化到换说法？
而且它必须先赢过一张平凡查表**（本项目「免费规则吃掉增益」已实测 6 次：锚定逐字 1.00 / 价值卡词表 1.00 /

## 1. 数据（程序生成、受控；不读任何语料 ⇒ `dev-notes/19` 的 `fs[:N]` 陷阱不适用）

四型各 **1/4**，两个出口各一套：

| 型 | 子类（8 个子类，均分） | 期望 |
|---|---|---|
| **valid_chain 有效·直链** | `A⊆B, B⊆C` | 结论 `A⊆C`（IMP / ALL） |
| **valid_variant 有效·变体** | **v_neg 否定**：`A⊆B, B∩C=∅` ⇒ `A∩C=∅`；**v_quant 量词**：`有的A⊆B, 所有B⊆C` ⇒ `有的A⊆C`；**v_contra 逆否**：`A⊆B, 所有¬C⊆¬B`（前提以逆否式给出）⇒ `A⊆C` | 合法结论 |
| **fallacy 谬误** | **affirm 否定后件误用=肯定后件**：`A⊆B, B 成立` ⟹ `A`；**negaff 否定前件**：`A⊆B, B 不成立`；**undist 中项不周延**：`A⊆B, C⊆B` | **无有效结论 ⇒ 必须拒答** |
| **distractor 干扰** | 前提不连通：`A⊆B, C⊆D` | **无结论 ⇒ 必须拒答** |

**语义（写死）**：`是 / 属于` = ⊆（子集）；`不是 / 分离` = ∩=∅（全异）；`成立` = 单前提真值；
蕴含链可传递；**否定结论 = 前项∩后项=∅**。

### 1.1 两个出口（**无共享表面串**，代码断言）

| | **tmpl 模板化出口** | **para 自然语言改写出口** |
|---|---|---|
| 量词 | `所有`(ALL) / `有的`(SOME) | `每个`(ALL) / `某些`(SOME) |
| 肯定关系 | `是` | `属于`（正序）/ `包含`（倒序，受事在前） |
| 否定关系 | `不是` | `并非属于` |
| 单前提 | `成立` / `不成立` | `有效` / `无效` |
| 前提连接 | `。` | `，` |
| 逆否标记 | `逆否` | `倒装` |
| 实体词表 | 集合 `E_T`（字符集 `C_T`） | 集合 `E_P`（字符集 `C_P`），**`C_T ∩ C_P = ∅`** |
| 语序 | 恒 `量词+主+谓+宾`；前提恒 `p1 在前` | **每个子类内再对半**：正序 / **倒序（宾在前）** + **前提顺序随机交换** |

**断言（生成器内 assert，不满足即报错退出）**：
1. `set(全部 tmpl 字符) ∩ set(全部 para 字符) = ∅`（含标点）⇒ **任意长度的表面串交集 = ∅**；
2. 模板签名集合交集 = ∅；量词/关系/连接词词表交集 = ∅；完整前提句交集 = ∅；
3. 生成后实测报出：共享字符数、共享字符 n-gram（n=2..6）数 —— **必须全为 0**。

> **边界（跑前声明，避免事后解释）**：字符零重叠 ⇒ **臂 T 在改写集上是「跨词表迁移」**，
> 其 L1 的 Δ 里同时含「不会换说法」与「词表零重叠」两份贡献，**本单元不拆分 ⇒ 该归因标为不确定**。

### 1.2 逐型必报

每型 × 每出口报：**n**、**未命中/丢弃率**（生成期被 assert/筛选丢掉的比例）、
**表面规则可解率**（= `R-chain` 在该型该出口的准确率，见 §4）。

## 2. 三卡（共享核**全程冻结**）

核 = `checkpoints/base_encoder.pt::doc_encoder`（hidden 128、1,688,460 参数），**核外私有**的只有三张头 + 一个私有适配层。
**不动核** ⇒ 不触发「动核必付老卡」；L5 仍逐卡实测（见 §6）。若要动核必须在此写明 + 配 L5 门禁 —— **本项目不写 ⇒ 视为不动核**。

- **识别卡（头 I，字符级序列标注）**：句 → 每字标签 `{ENT_S 第一位名称段, ENT_O 第二位名称段,
  REL_P 肯定关系, REL_NEG 否定关系, O 其余}`（**5 类**）⇒ 组出**命题结构**（每前提：量词前缀 + 极性 + 两个名称段）。
  - **角色按表面顺序**：第一个名称段 = 施事位、第二个 = 受事位；**方向不由识别卡猜**，
    而由关系词（`是/属于` vs `包含`）承载，交给推理头（这样 `render()` 的规范化文本与表面同向、语义自洽）。
  - **实体 id 归一（接口约定，对所有臂与所有规则一致）**：实体词恒 2 字 ⇒ 名称段取**最后 2 字**为实体词
    （前缀 = 2 字量词 / 2 字逆否标记）；实体 id = 全输入**首次出现序 0..3**。
  - **结构指令复用 `src/dtseek/tasks/render.py`**：把识别出的结构填成 `Instruction{skeleton_id, assignment}`
    （二元前提用内置 `S01 "[1][2][3]。"`（名施/动/名受），单前提用 `S04 "[1][2]。"`（名施/动）），
    袋 `BagItem` 的 `text/span/pos/theta` 全部来自识别结果，`candidate_id` 用识别卡自身 id、`screened=True`；
  - **两道检查原样复用**：`check_structure()`（I1：schema + 规则 0/A/B + 词面守卫 + 零信息新增）与
    `render()` 内部的 `check_deref()`（I3：ref_map 分区覆盖 + 逐条回溯 span）；
    **任一不过 ⇒ fail-closed，该题下游一律按拒答**（`kind="reject"`）。
  - 渲染出的**规范化文本**（确定性纯函数）作为推理头的输入。
- **推理头（头 II，核外私有）**：规范化命题结构 → **结论结构**。
  标签 = `REJECT` ∪ `(form ∈ {IMP, NEG} × quant ∈ {ALL, SOME} × arg1 ∈ {0..3} × arg2 ∈ {0..3})` = **65 类**。
  `arg` = 实体 id（**按在输入中首次出现的顺序 0..3**）。**规范形（口径判断，跑前写死）**：
  结论取**最强量词**（能 ALL 不 SOME）；否定结论的前项取 `p1` 链端、后项取 `p2` 链端；
  **逻辑等价但非规范形的输出按错计**。
- **归因卡（头 III，核外私有）**：结论 ↦ 前提引用。
  标签 = `(ref1, ref2)`，`ref ∈ {0..5}`（**mention 序号：全输入从左到右第几个实体提及**）∪ `NONE`（拒答时）⇒ **37 类**。
  **引用映射形状**：`{"arg": 0|1, "ref": int, "unit_id": "ref:<n>", "span": (s,e), "text": str}` —— 每条都能经
  `ref_map` 回溯到**输入原文 span**（L3 的「恰好铺满」= 有结论时恰好 2 条、arg 0 与 arg 1 各一条、span 均可解析）。

**训练（两阶段，均核冻结 `eval()`、读缓存/live 编码逐位同）**：
- 阶段 1：训识别卡（字符级 CE）；
- 阶段 2：**冻结识别卡**，用其**预测结构**过两道检查 → 渲染规范化文本 → 编码 → 训推理头 + 归因头（共享阶段 2 的 backbone）。
  识别卡过不了两道检查的题，规范化文本置为空串、`parse_ok=0` ⇒ 阶段 2 的正确答案是 `REJECT/NONE`。

## 4. `max_naive` 电池（**逐出口**；并列 `max_naive`，报 `卡 − rule`）

| 规则 | 定义 | 是否计入 `max_naive` |
|---|---|---|
| **R-chain** | **纯字符串**：按 `。/，` 切前提 → 丢已知量词 → 首段=主、末段=宾、中段=关系 → `p1.宾 == p2.主` 才连链 → 否则拒答（**模板出口的表面协议**，「符号层可解」的上界） | **计入** |
| **R-keyword** | 关键词/词重叠：两前提实体词重叠集大小 + 否定词是否出现 ⇒ 连链/拒答 | **计入** |
| **majority** | 训练集多数类（按出口分别算） | **计入** |
| **length** | 前提长度桶 → 训练集该桶多数类 | **计入** |
| **extreme** | 总是输出某个固定标签（取训练集最高频标签） | **计入** |
| **n_slots** | 按「每前提槽位数 + 是否含否定」查训练集标签分布（`dev-notes/21` 裁定 1：并入） | **计入** |
| **R-lexdir**（披露项） | **带两出口完整关系方向词表**的链规则（含量词传播，**不含逆否转换**） | **不计入**，**单列披露**（沿 `select_rerank` 不把同义词表规则计入 `max_naive` 的既有口径，`dev-notes/20 更正3`），但必须报 `卡 − R-lexdir` |

`max_naive(exit)` = 上表**计入**项在该出口的最高准确率；`卡 − rule` 逐出口报。

## 5. 判据（**跑前写死**）

测试集 n：`tmpl_test` / `para_test` 各 **1200**（300/型）⇒ **SE = sqrt(0.25/1200) = 1.443pt，2×SE = 2.886pt**。

| # | 判据 | 门槛 |
|---|---|---|
| **L0（主）** | **改写集上的有效性判别**（标签 = `REJECT` vs 结论结构 **完全正确**；含谬误/干扰必须拒答） | **> `max_naive(para_test)` + 2×SE**，**2 seed 同号**。**主判据取臂 T**（训练未见改写 = 真泛化）；**同时逐臂报 T+A / A**，写明 T+A 见过改写 ⇒ 其过 L0 只证明「能做对」，不证明「能换说法」 |
| **L1** | 模板集 vs 改写集的差 | 报臂 T 的 `Δ = acc(tmpl) − acc(para)`；**若改写 ≈50% ⇒ 如实写「表内记忆、换说法崩」** |
| **L2** | 谬误型 / 干扰型必须拒答 | **逐型报拒答率**；**正例（该有结论）却不拒答的判 0 分**的条数必须为 0（否则该格作废）；判据 = 谬误型/干扰型的 **拒答率 > `max_naive(该型拒答率)` + 2×SE** |
| **L3** | 归因可判 | 引用映射**恰好铺满**（有结论 ⇒ 2 条、span 全可解析、`ref` 指向的 mention 文本与结论参数一致）；报**违例数**（必须 0） |
| **L4** | 随机标签对照 | 只把训练标签 `randperm`（保持类分布）后重跑两阶段，**改写集与模板集都掉到 ≤ 多数类 + 2×SE** |
| **L5** | 老卡 Δ | 四张老卡（pronoun 2.83 / sentiment 0.41 / relation 1.39 / person 0.33 pt）Δ ≥ **−各自带**；核冻结 ⇒ 预期 Δ=0，**仍逐卡实测报**（对账 `select_semantic_joint/results/r4_baseline_s{S}.json`） |
| **L6** | `max_naive`（含 R-chain / R-keyword） | 逐出口报 `rule` + **卡 − rule**；另报 `卡 − R-lexdir` |

**判定三选一**：**逻辑推导卡有真能力**（L0 过） / **只在表内可用**（L0 不过 ∧ L1 显示改写崩） / **证据不足**（其余）。**不许硬选。**

**注入的反例（必须故意做，且必须被抓到）**：
- **C1 篡改引用**：把归因 `ref` 改成一个不存在的 mention / 改成别的实体 span ⇒ L3 的回溯检查必须报违例；
- **C2 跳过谬误拒答**：把谬误型的输出强制改成「有结论」 ⇒ L2 的「正例不拒答/误答」计数必须 > 0 并被抓出；
- **C3 换掉 render 的输入**：给 `check_structure` 一个 span 不是输入逐字子串的袋 ⇒ 必须被 `item_problems` 拒。

**边界句（必须写进 `report.md`）**：
