## 1. 数据与「零共享表面串」断言（实测，`data.json`）

生成 8400 题（train 6000 / test 2400；每出口 test n=1200，四型各 ≈1/4：298/313/302/287）。
丢弃 1 条（para/negaff 撞句），无其它 miss。
断言全 `True`：**字符集交集 = ∅**（tmpl 48 字 / para 46 字，公共 0）；
**n-gram 交集 (n=2,3,4,6) = 0**；**整句交集 = 0**；**功能词表交集 = ∅**；**实体字交集 = ∅**。
⇒ 两出口任意长度的表面串交集 = ∅（由字符集不相交可判定）。

## 2. 结构（实测打印）

核 `base_encoder` **1,688,460 参数，`eval()`、`trainable=0`**；核外私有头 **272,779 参数（占核 16.16%）**。

## 7. 端到端样例（臂 T，seed 42，test，实测原样）

1. 模板/直链 ✔ 输入 `所有瀚石是银岛`｜`所有银岛是紫桐` → 规范文本 `所有瀚石是银岛。所有银岛是紫桐。` → `IMP/ALL(e0,e2)`（=gold）→ 归因 `[(0,0,4,"所有瀚石"), (1,5,7,"紫桐")]`
2. 模板/直链 ✘ 输入 `所有雪原是青田`｜`所有青田是铜岭` → 规范文本同上 → **gold `IMP/ALL(e0,e2)`，卡 REJECT（误拒）**
3. 模板/干扰 ✘ 输入 `所有基岛是斐兰`｜`所有白壁是黄湾` → **gold REJECT，卡 `IMP/ALL(e0,e2)`（误结论）** → 归因 `[(0,0,4,"所有基岛"), (1,5,7,"黄湾")]`
4. 模板/逆否 ✔ 输入 `所有基沙是岚滩`｜`所有逆否岚岭是逆否岚滩` → `IMP/ALL(e0,e2)`（=gold）→ 归因 `[(0,0,4,"所有基沙"), (1,0,6,"所有逆否岚岭")]`
5. 改写/直链 ✘ 输入 `每个鲲貅属于睚武`｜`每个椒图属于鲲貅`（前提已随机换序）→ 规范文本 `每个鲲貅属于睚武。每个椒图属于鲲貅。` → **gold `IMP/ALL(e2,e1)`，卡 `IMP/ALL(e0,e2)`（方向错）**
6. 改写/否定 ✔ 输入 `每个鹫餮属于麟鹏`｜`每个麟鹏并非属于蛟吻` → `NEG/ALL(e0,e2)`（=gold）→ 归因 `[(0,0,4,"每个鹫餮"), (1,5,10,"非属于蛟吻")]`
7. 改写/逆否 解析失败 输入 `每个睚吻属于毕眦`｜`每个倒装鲲鹏属于倒装毕眦` → 识别字准 0.7292 → **双门不过 ⇒ fail-closed REJECT**（gold `IMP/ALL(e0,e2)`）

## 8. 实测 / 推断 分野

- **实测**：§1 断言、§2 参数量、§3–§5 全部数值、§6 注入反例、§7 样例、老卡 Δ=0 与 sha256 相等。
- **推断**：§5 末「学到表面形式而非链规则」（由逐型准确率差 + R-chain 对照推出）。
- **口径判断**：结论规范形（最强量词、非规范但逻辑等价的输出判错）、实体 id 取首次出现序、theta 按表面顺序。
- **不可分解（PREREG 已声明）**：两出口字符集零重叠 ⇒ L1 的 Δ 同时含「不能换说法」与「零词表重叠」，**归因标为不确定**；
  另：改写出口识别卡字准 83.69 / 82.13、解析通过 71.42 / 58.25，链路前段已掉分，**后段失败与前段失败未分离**。
