## 4. 识别卡实现（复用 `render.py` 谓词）

**核冻结**：`load_base_encoder` 后逐参数断言 `requires_grad=False`（打印 26 个冻结张量），编码在 `no_grad` 下做；**只训 83,593 个头参数**（trunk 128→256→128 + mode 头 + BIO 头）。**输出＝结构化指令** `{"mode_id":"M03","assignment":[0]}` + `evidence` + `ref_map` + `plan_step_id`，形状与 `render._record` 同构。

复用点：**遮蔽集 = `render.PUNCT`**；触发词校验走 **`render.item_problems(BagItem(...))`**（span 越界 / 逐字子串 / `screened`+`candidate_id` 零信息新增）；**`render.is_content_word` 断言触发词不得是实义词**（规则 A 同立场）。

自写 `check_mode_structure`（封闭模式表 + 封闭触发词表）与 `check_mode_deref`（`ref_map.out` **恰好铺满**、内容条目 `span` 回溯原文），语义逐条对齐 `check_structure`/`check_deref`，不过 ⇒ `kind="reject"`（fail-closed）。`selfcheck.py`：**正例 4 + 故意注入反例 9 ⇒ PASS 13 / FAIL 0**（越界 span、实义词当触发词、表外触发词、表外模式 id、`ref_map` 不铺满、span 非逐字、reject 记录走 deref、未遮蔽输入断言）。

## 6. M0–M6 逐条实测 + 判定

| # | 实测 | 结论 |
|---|---|---|
| **M0** | `R-punct(E_mask) ≡ majority .4560`（断言）；落差 simple −.2665 / full −.3032 | **过** |
| **M1** | MASK 臂遮蔽出口 `.5923/.5898` vs 地板 `.6968`：Δ−2SE = **−.1172/−.1197**，**两 seed 同号（同为负）** | **未过** |

| **M3** | `max_naive(mask) .6968 < 1−2SE .9882` ⇒ **形式过**；但来源独立性**只在标点分界成立**，特指/反问两处标签由词表定义、与 `R-particle` **同源** | **形式过 + 两处不独立** |

**收敛性（PREREG rev.B，单列、事后）**：8000 步 `train mode acc = .9159/.9141`（MASK）→ 遮蔽出口 `.5763/.5842`（Δ −.1205/−.1126）；KEEP 臂 train `.9480` → keep 出口 `.7420`（Δ −.2580）⇒ **收敛后仍未超地板，M1 的失败不是「没训够」**（800 步 train 仅 .615 时 mask 已 .592，同量级）。

**机制（实测 / 推断分开）**
- **实测**：卡 `.5923` 高于多数类与 `R-punct`（+.1363）、`R-final-char`（+.0328），**低于** `R-particle`（−.0884）与 `R-labeldef`（−.1045）；逐类 recall（MASK s42@mask）**陈述 .299/.394、是非 .488/.491、特指 .863/1.000、祈使 .000/.709、感叹 .163/.320、反问 .000/1.000**（卡/R6）—— 卡在六类中**五类低于 R6**。
- **实测**：KEEP 臂去掉标点掉 **24.25pt**（2 seed 一致）⇒ 卡本身重度依赖标点。
- **推断**：遮蔽后 陈述/是非/感叹 的分界只存在于被删的标点里（例：`祝你们幸福！`→`祝你们幸福` 与陈述 `祝你们幸福。`→`祝你们幸福` **逐字相同**）⇒ **不可约误差**；`R6` 更高是因为它**用词表逼近标注函数**，不是因为输入含更多信息。
- **推断（弱）**：祈使 n=55 / 反问 n=31，recall=0 的 SE 很大，**不能**断言「卡完全读不出这两类」。

**先比平凡查表**（`dev-notes/21` 免费规则纪律 + 更正 C「`rule<1−2SE` 且来源独立」）：本单元按此判，不按「卡比自己好」判。

**判定（PREREG 三选一，不许硬选）＝「只靠标点（遮蔽后崩）」** —— 依据：M0 过 ∧ M1 未过 ∧ `max_naive` 落差 `.3032 ≥ .30`（M0=T M1=F M3=T M4=T M5=T）。**边界**：这**不等于**「输入侧无信号」——卡在遮蔽出口比多数类高 **13.6pt**（2 seed 同号、配对 SE 1.53pt），也高于 `R-punct`/`R-final-char`；准确表述是 **「卡读出了词序/语气词信号，但没超过一张手写粒子查表，且收益里标点占大头」**。
