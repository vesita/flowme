## 3. R2 配方的一处**事前**微调（披露，理由与影响面）

| | PREREG_TRAIN §2 原写 | 本澄清改为 |
|---|---|---|
| R2 | `--samples 32000 --epochs 16 --steps-per-epoch 300`（4800 步） | `--samples 32000 --epochs 40 --steps-per-epoch 150`（**6000 步**） |

- **理由**：R1 = 6000 步 / 8000 样本；原 R2 在**加数据的同时少训 20% 步**，两个变量一起动、归因不干净。
  改成**步数与 R1 完全相同、只把数据量 8000 → 32000** ⇒ 单变量（数据多样性）。
- **影响面**：只改 R2 的两个数字；**F0–F5 判据、停止规则、选卡规则一字未改**；
  本改动发生在 **R2 启动之前**，R1 已按原配方跑完并已实测（.9779/.9764）。
- **停止规则不变**：R2（seed 42 卡）两个 eval seed 仍有一 < .98 ⇒ **F1 不达标 ⇒ 判「无法修复」**，
  **不再加配方、不再调参**（头规格 2 层 / lr 1e-3 / batch 64 全程不动）。

## 4. 已经排除的解释（实测，不是推断）

- **不是「没训够」**：R1 = 6000 步（R1 前的现有卡是 1200 步 / 1800 步），loss 单调下降 7.15 → 2.39。
- **不是「头太小」**：三张参照卡头规格完全相同（`num_layers=2, num_heads=4, hidden=128`，629,764 参数）。
- **不是「截断」**：R1 余错全在短句（`别怕 / 请勿对号入座 / 莫名的罪行`），`max_len=64` 不是瓶颈；
  错法 = 漏检（s42 9 例 / s43 9 例，集中在 `别`、`莫` 这类**同形/虚化**形态）+ 误报 6/1 例。
