(a) 某候选源的标签文件读不出来或定义方式无法确定（既不能证 1.0 也不能证 <1.0）；

## 3. 「定义方式」的判定标准（写死）

逐源回答：**标签是不是"由词表 / 规则 / 模板生成器直接算出来的"**？

- **构造性（rule 按定义 = 1.0）**：标签 = `f(词表, 规则, 模板)` 的输出；
  此时 `rule` 是**定义**而不是方法，probe 分数不构成任何构念证据。
- **非构造性（候选可用）**：标签来自**独立于该规则的来源**（外部数据集的人工标注、
  众包、模型之外的真值），且用同一条规则去预测它时 **`rule < 1.0 − 2SE`**。
- **推断来源必须点名**：写清是「读代码确认」还是「从数据反推」，证据强度标出。

## 4. Q3 的复核口径（写死）

  逐 split 统计 **test 行中「文本在 train 里出现过」的行比例**（行级、不去重）。
- 阈值：与 `core_probe/REPORT.md` 的 **27.7%（emo）** 相对差 ≤ 1pt 视为**复核一致**；
  skel/logic/idr 应为 **0%**，任一不为 0 即如实报。
- **额外（低成本、可选口径）**：在 emo 上重跑 P1 同口径 probe（2 seed、核冻结、5 层），
  **把 test 按「重复 / 不重复」拆开分别报 acc** —— 这是回答「78.64% 意味着什么」的
  直接证据；若成本超预算则只报行级重复率 + 推断，并标明是推断。
