# PREREG_PARSER —— L3-m3：**parser 卡 t**（语言解析卡）与"模因在输出衔接处涌现"

**本文件在跑之前写死；判据不因结果调整。** 用户 2026-10-11 下午的方案。

## 0. 要回答什么

用户："加入这个 parser 卡后，在**输入侧**是否会表现出**模因的涌现**"——
即：**一张共享的 parser 卡能不能把两种语言解析成同一个内容码**（而不是靠牺牲重构去硬拉相似度）。

三条已知事实（L3-m1/m2 实测）决定了本试验的设计：
1. **输入卡自己学不出跨语言内容码**：只训 AaBb（重构）时跨语言 Δ ≈ 0（AUROC 0.499/0.503）；
2. **"映射即耦合"有效但代价来自权重**：加 AbBa 后 Δ 0→+0.19，α 降到 0.5 可六门全过；
3. 因此**把"解析/对齐"这件事交给一张专门的卡**，是与"降权折中"并列的另一条路。

## 1. 卡片与映射（用户写法 Ata Btb Atb Bta）

```
中入 A ─┐                    ┌─ 中出 a
        ├─▶ parser 卡 t ─────┤
英入 B ─┘   （两语言共用一张）   └─ 英出 b
```
| 映射 | 组成 | 含义 |
|---|---|---|
| **Ata** | 中入 → t → 中出 | 重构（中） |
| **Btb** | 英入 → t → 英出 | 重构（英） |
| **Atb** | 中入 → t → 英出 | 翻译（中→英） |
| **Bta** | 英入 → t → 中出 | 翻译（英→中） |

**parser 卡规格（写死）**：`[16,128] → [16,128]`，卡内 = **自注意力 + 逐位置 FFN**（`MEME_FRAMEWORK §5.1`），
**容量瓶颈** `d_mid = 64 < 128`（`§13.2`：强制路由必须配瓶颈，否则 t 退化成恒等），
输出 = **残差 + LayerNorm**（t 是"改写"模因）；参数量 116,800。

## 3. 判据（写死）

| # | 判据 | 门槛 |
|---|---|---|
| **P1 涌现（核心）** ★ | **衔接处** Δ池化 与 Δ长度匹配 | 各 `≥ 臂 II（无 parser）+ 2×SE` 且 **2 seed 同号** |
| **P2 重构不掉** | Ata 中→中 / Btb 英→英 的 teacher-forced 字准 | 各 `≥ 臂 II − 5pp` |
| **P3 翻译不掉** | Atb 中→英 / Bta 英→中 | 各 `≥ 臂 II − 5pp` |
| **P4 自由生成不掉** | 贪心 EM 中→中 / 英→英 | 各 `≥ 臂 II − 5pp` |
| 辅助（必报） | **输入侧 Δ**（对照：证明冻结侧没动）· 阈值/AUROC · CKA/线性映射 · 繁简子集 · parser 参数占比 | — |

**判决**：**P1∧P2∧P3∧P4 全过** ⇒ 「**共享 parser 卡能让两种语言在衔接处涌现出同一内容码，且不以牺牲重构/翻译为代价**」；
否则按卡住的那条报读数。★ 臂 III **只作读**（n=1）：`Δ输入≈0` 时 `Δ衔接>0` 即为"parser 从零造出对齐"的定性证据。
