## 0. 要回答的问题（以及**不**回答的）

**问**：同一段中文句子，经**文本输入卡**与**视觉输入卡**（把该句渲染成图）编码后，在**固定 16 槽瓶颈**下，
两个模因是否**相似** —— 即模因是否承载内容且跨模态一致？并给出一个可用的**数值阈值**。

**不回答**：模因是否优于文本中介（那是 `§8` 阶段 1 的 T vs M）· 思维卡/路由卡 · 动态加载 · 对话能力。

★ **为什么必须有瓶颈**（`§13.2` / §29.1）：若模因容量 ≥ 输入熵，两张卡都能把输入原样编码进模因
⇒ 同句必然相似 ⇒ **检验必然通过、零信息量**。⇒ 本试验的瓶颈 = **固定 `n=16` 槽**。

## 3. 三张卡与模因形状

**模因** = `[16, 128]`，**n=16 固定**（本试验的容量瓶颈）；**不池化**；槽位有序；
位置由 **16 个可学查询槽位**承载；仍携带 `[b*4, 16, 16]` 加性 mask（本试验全零，保持与框架形状约定一致）。

**结构 = DETR 式**（用户 2026-10-11 建议）：`主干 → Transformer encoder（全注意力）→ 16 个可学 query 的 decoder`。
两张输入卡**同构**（层数/宽度/注意力形状逐字相同）⇒ **模态差异只来自前端**（char 嵌入 vs CNN），不来自卡的结构。
★ 只借 DETR 的**架构**，**不借它的集合匹配损失**（我们每个槽没有独立目标，监督来自共享输出卡的重构；`§11` 说明槽序口径）。

| 卡 | 输入 | 输出 | 结构（都从零初始化） |
|---|---|---|---|
| **`T_in`**（文本入） | char ids `[b, L]` | meme `[b,16,128]` | `emb(8192,128) + 正弦 PE` → 2 × `TransformerEncoderLayer`（全注意力，pad 掩码）→ **2 × `TransformerDecoderLayer`**，`tgt` = 16 个可学 query（query 自注意力 + 对编码器输出的交叉注意力）→ `LayerNorm` |
| **`V_in`**（图片入） | 灰度图 `[b,1,128,584]`（**订正 4 后**） | meme `[b,16,128]` | CNN 主干（Conv 1→32→64→128，stride 2/2/2，GELU + GroupNorm）+ 正弦 2D PE → 2 × `TransformerEncoderLayer`（全注意力）→ **16 槽头（两档可切换）**：`detr` = 16 个可学 query 的 query-decoder（自注意力 + 交叉注意力）；`yolo` = 池化到 **4×4 空间网格**，每格一个槽 → `LayerNorm`（两档都先过 encoder，见订正 9②；进 encoder 前先池化 2×，见订正 8） |

★ **图片卡槽头的两档**（`detr` / `yolo`）由命令行 `--vision-arch` 切换，**主档待用户定**：
`detr` 与文本卡同构（模态差异纯净）；`yolo` 带空间序先验（更对口"读一行字"）但与文本卡**不同构** ⇒
逐槽对齐更难，容易把"结构不同"误读成"模因不同"。**两档都不改任何判据**（M1′ 只看 Δ 与正控）。

★ **主干刻意保持小**（3 个卷积块、非 ResNet-50）：从头训 2 万句，主干深度不是本试验要测的东西；本试验测的是**瓶颈 + query 结构**。
| **`Out`**（共享文本出） | meme `[b,16,128]` | logits `[b,L,8192]` | 16 槽作 memory → 2 × `TransformerDecoderLayer(d=128, ff=512, nhead=4)` + `Linear(128,8192)`；**teacher forcing**，输入 = `<bos>`+目标前缀，因果掩码 |

**边界**：`T_in` 与 `Out` 的 char 嵌入**不共享**（保持"三张卡"的边界）；
`Out` **两张输入卡共用** —— 这是本试验的**耦合**（见 §9 已知混杂）。参数量目标 ≤ 8M。

## 4. 损失与臂

```
L = CE_T + CE_V + λ · D
  CE_T = CE( Out(T_in(x)),   x )      # 文本路重构
  CE_V = CE( Out(V_in(render(x))), x )  # 图片路重构，同一个目标 x
  D    = 1 − (1/16) Σ_p cos( m_T[p], m_I[p] )   # 逐槽、不池化，与形状规范一致
```

| 臂 | λ | 角色 |
|---|---|---|
| **A** | **0**（无跨模态项） | **对照**：只有"两条路各自重构 + 共享出口"的压力 |
| **B** | **0.5** | **主臂**（用户方案："模因差异加权"） |
| **C** | **2.0** | 对齐强度阶梯的第三个点 |

- 优化器 `AdamW(lr=1e-3, weight_decay=0.01)`；batch **32**；`grad_clip=1.0`；dropout **0.1**
- **每臂 2 seed（1234 / 5678）⇒ 共 6 run；单卡串行、不并发**
- 设备：GPU（`HSA_OVERRIDE_GFX_VERSION=10.3.0`）优先；被占用则 CPU，**报告写明实际设备**

## 5. 训练与收敛口径（跑前写死）

- **快照**：每 **1000** 步（**订正 9③**：预算所限由 500 提到 1000；判据不依赖快照粒度）在 held-out 上算 `CE_T / CE_V / 字级准确率 / 逐句精确率 / Δ`（一次跑出，不重跑）
- **收敛判据**：held-out `CE_T + CE_V` 连续 **2** 次快照相对改善 < **1%** ⇒ 停；**上限 20000 步**
- 未达收敛 ⇒ 结论按 R35 标 ⚠**未饱和**，只报方向、不下增益

## 7. 前置门 `G-read`（不过 ⇒ **不进**相似性检验）

**图片路 held-out 字级准确率必须同时满足**：

1. `≥ 0.90 × 文本路 held-out 字级准确率`
2. `≥ 0.50`（绝对下限）

- 不过 ⇒ 判「**本实现下没学会读图**」，**不是**"模因假设不成立"；
- 允许最多 **2 轮**订正（放大字号/加容量/加步数），**旧新读数都报、留痕**；
- 两轮后仍不过 ⇒ **停下报告、由用户决定**（**不得改判据放行**）。

## 8. 主判据（held-out 2000 句；每臂每 seed）

**口径（写死，三口径全报，主口径加粗）**：

- **主口径 `sim` = mean-pool 余弦**（16 槽池化到 1 个 128 维向量后算余弦）
- 并列：(i) **逐槽 cos 均值** · (ii) **线性核 CKA** · (iii) **线性映射 W**（train 折拟合、held-out 折评估）后的余弦
- 对照：**随机配对** = 相似度矩阵 `C[i,j]` 的**非对角全矩阵**（同 seed、同一批 held-out 句）
- `Δ_i = C[i,i] − mean_{j≠i} C[i,j]`；报 `Δ` 均值 ± **配对 SE**

| # | 判据 | 门槛 |
|---|---|---|
| **M1′** ★ | **跨模态一致性（主）** | `Δ ≥ 2×SE` **且 `Δ ≥ 0.01`**（**订正 3**：SE→0 时会平凡过）且 **2 seed 同号** ⇒ **过**；`|Δ| ≤ 1×SE` ⇒ **未测出差异**；`1SE < |Δ| < 2SE` ⇒ **不可判** |
| **M2′** ★ | **正控（度量有区分度）** | 同模态、**异内容**（文本模因 × 文本模因的异句配对）必须比同内容跨模态**低 ≥ 2SE**；否则**判决作废** |
| **M3** ★ | **顺序敏感自检** | **只在逐槽口径 (i) 上判**（主口径 mean-pool 对槽置换**恒等**，实测 `max\|Δ\|=4.1e-8`，**不得**用于判 M3 —— **订正 5**）；把 16 槽随机置换（两路用不同置换）后逐槽 `Δ` 的**掉幅 ≥ max(2SE, 0.01)** |
| **M4** | **地板（必报）** | ① 随机模因 ② 词袋 bag-of-chars 余弦 ③ 恒等中介（输入 char 嵌入平均当模因） |
| **M5** | **可用性（**不**循环的证据）** | 两路 held-out 字级准确率 / 逐句精确率；并列一个内容探针（从模因线性预测 句长 / 是否含数字 / 首字），**只作参考** |
| **M6** ★ | **失败出口** | `G-read` 过了而 M1′ 不过（`|Δ| ≤ 1SE` 或 AUROC 的 95%CI 含 **0.5**）⇒ **模因假设在本实现下不成立** ⇒ **停下报告、由用户决定**（`§10.1` / `§27.3 S1-e`） |
| **M7** | 与 S26 对照（**参考，非判据**） | 报本试验 Δ 与 S26 `lang` 族 `+0.0524` 的相对大小；**口径不同（语料/架构/模因定义都不同）⇒ 不作判据** |

★ **依赖假设 A**（`§0.1`）：本试验的"模因承载内容"整条线依赖它；假设被推翻时本试验结论一并在受影响清单里。
★ `§10.1` 存续条件：本试验**只**回答跨模态一致性；**显著劣于**某条外部基线不构成放弃理由，**无显著差别 ⇒ 坚持**。

## 9. 阈值怎么给（你要的"数值阈值"）

- 在 held-out 上给 `sim` 与 `Δ` 的**完整分布** + **AUROC** + **最优阈值（Youden）及其 TPR/FPR**；
- ★ **口径警告（写死）**：**原始余弦不可当阈值** —— S26 实测**随机配对余弦本身就有 0.905–0.918**；
  阈值必须给在 **`Δ`** 或 **CKA / 线性映射**口径上，并**同时给正控**（S26 `THINKING_CARD_DESIGN §想法B`）；
- 阈值**只在同一 MV**（本试验的三卡权重 + 本文件 §2/§3 的规格）下有效；换字体/字号/槽数/语料即失效。

## 10. 判决（**5 档 + 固定顺序**；实现 = `stages/86_meme_anchor.py::verdict()`，本节只留判据，数字口径不在此复述）

**顺序（订正 10）：① 读数完备性 → ② 仪器有效性（M2′ 正控 / M3 口径）→ ③ 训练充分性（饱和）→ ④ 前置门（G-read 含 M9）→ ⑤ 结论**

| 档 | 观测 | 判词 |
|---|---|---|
| **0（读数不完整）** | 主档不足 3 臂×2 seed，或数据画布 ≠ `[128,584]` | **不许出判词** |
| **0b（判决作废）** | M2′ 正控不过（同模态异内容没显著低于跨模态同内容） | **判决作废**（度量无区分度） |
| **3（判据口径缺陷）** | M3 逐槽掉幅不过 | 属**判据缺陷**，**不进 M6** |
| **4（未饱和）** | 有臂未收敛（末**两次**间隔改善均 ≥1%） | 按 R35 **只报方向**；★ **此档下 G-read 未过不得读成「学不会读图」** |
| **0（前置门未过 · 已饱和）** | 没有臂过 G-read（含 M9 置零消融） | 本实现『没学会读图 / 解码器自补』⇒ **不构成对模因假设的判决** |
| **3b（与表面统计不可区分）** | `Δ_模因` 未超过计数类地板 + max(2SE,0.01) | 只能写「与表面统计不可区分」，**不得**写"模因锚定" |
| **1（强）** | 臂 **A（λ=0）自己**过 G-read + M1′ + M8 + 正控 | **模因自然锚定**（在 §11「共享出口」耦合下） |
| **2（中）** | 仅 λ>0 的臂过（且该臂自己过 G-read） | **对齐可训练、模因空间可被拉齐** |
| **5a/5b/5c/5d** | 其余 | 5a `\|Δ\|≤1SE` = **未测出差异**；5b M1′ 过而 **M8 不过** = **与句长不可区分**；5c 明确不过 = **本实现未达成**；5d 中间带 = **不可判**。★ **5 类都不是『模因假设被证伪』**（`§10.1` 需 T vs M 对照，本试验没有） |

## 11. 已知混杂（必须与结论一起读）

1. **共享输出卡本身就是耦合**：两条路的模因都必须能被**同一个出口**解码 ⇒ 臂 A 的"自然锚定"准确说是
   「**仅靠共享出口压力**下的锚定」；要分离它需要「各自私有出口」的第 4 臂 —— **本次不做**，写在这里备查。
2. **V1 测的是"读图"**（把同一句渲染成图），**不是**"画面的语义接地"。
3. **固定 16 槽**是本试验强加的瓶颈；换 `n`/`d` 必须重跑（`§29.1`）。
4. 全部读数只在**单一语料 + 单一字体 + 单一渲染规格**上成立，不可外推为"中文都行"。

## 订正留痕

> 纪律：**跑前**改动只留痕；**跑后**改判据必须旧新两个数字都报。以下全部发生在**首跑之前**。

**订正 1（2026-10-11 01:1x，用户建议"DETR"）—— §3 图片入卡的结构**
- 旧：`CNN → 正弦 2D PE → 16 个可学 query 做一次交叉注意力`
- 新：**DETR 式**——`CNN → 2 × TransformerEncoderLayer（全注意力）→ 2 × TransformerDecoderLayer 的 query-decoder（query 自注意力 + 交叉注意力）`；
  同时**文本入卡改成同构结构**（`char emb + PE → 2 × encoder → 同一个 query-decoder`）。
- 理由：DETR 的「固定 N 个可学 query + 解码器」正是"固定 16 槽瓶颈"的原生形态；两卡同构后**模态差异只来自前端**。
- 判据**未改**（形状、损失、M1′–M7 全部不动）。

**订正 2（2026-10-11 01:1x，用户补充"或者参考 YOLO"）—— §3 图片卡槽头可切换**
- 旧：只有 DETR 式一种槽头。
- 新：`--vision-arch detr|yolo` 两档；`yolo` = 特征图自适应池到 **4×4 = 16 空间网格**（空间序、无 query）。
- 理由：不替用户拍板；两档共用同一模因接口，切换不改任何判据。
- ★ **主档待用户定**；跑正式 6 run 前必须把主档写进本节（否则不许跑）。
  **→ 已定（2026-10-11 01:5x）**：**主档 = `detr`**（与文本卡同构 ⇒ 模态差异纯净）；`yolo` 留作可选第二档，
  只有在时间允许时才作为**附加臂**跑，且**不参与主判词**。

**订正 3（2026-10-11 01:4x，40 步探跑暴露的判据缺陷）—— M1′ 加**绝对效应量下限****
- 旧：`Δ ≥ 2×SE` 即判过。
- 新：**`Δ ≥ 2×SE` 且 `Δ ≥ 0.01`** 才判过（`0.01` = S26 跨语言效应 `+0.0524` 的 **1/5**）。
- 依据：探跑实测打印 **`Δ=+0.0000±0.0000` 却「2SE=过」** —— 当 `SE→0`（模因尚未分化、相似度矩阵近常数）时
  `Δ≥2SE` 会**平凡成立**，把"还没分化"读成"跨模态一致"。加绝对下限**只会更严、不会更松**。
  ⇒ 新判据**只能让原本"过"的变"不过"**，不可能救活任何结果；`|Δ| ≤ 1SE` 的"未测出差异"档不变。
- 同时新增**仪器读数**（不改判据）：每次快照报 **模因分化度** `spread`，用于区分
  「Δ 小是因为没分化」与「Δ 小是因为确实不一致」。

**订正 7（新增两条门 + 地板升门 + 判决扩为 5 档）—— 堵住"假阳性"与"误判"两条通道**
- **M8（新门 · 堵 P1-4 假阳性）**：**同长度、异内容**的配对 Δ 必须过（`≥2SE` 且 `≥0.01`）。
  理由（实测）：图片由同一句渲染 ⇒ 墨迹占比随句长单调（**0.0268→0.2019**，长度 8→60）、行数直接暴露长度桶

- **M9（新门，并入 G-read · 堵 P1-5 空门）**：**模因置零**后图片路字准必须**掉 ≥20pp**。
  理由：输出卡是 **teacher forcing**（看得到目标前缀）⇒ 解码器可能"自己把句子补出来"，
  若置零后仍高分 ⇒ G-read 是空门。
- **地板升门（R7/R9）**：`Δ_meme ≥ Δ_计数类地板 + max(2SE, 0.01)`（`surface_gate`）；
  否则判词只能写「**与表面统计不可区分**」，不得写"模因锚定"。
- **§10 判决扩为 5 档**（原 3 档缺"前置/口径/饱和"三条分支，会把欠训与判据错误记成假设错）：
