# H2：把「走错之后怎么恢复」当训练目标 —— **有效，但不大**

> 判据跑前写死在 [`PREREG_GENOBJ.md`](PREREG_GENOBJ.md)。这里只报结论与读数。
> 读数：`logs/genobj_reeval.json` · 判据表：`stages/86m_genobj_verdict.py --from-reeval <该文件>` · 实现：`stages/86g_zh_en.py --obj {tf,roll}`。

## 结论

**训练时让模型用自己刚生成的内容接着往下算（不再永远喂金标），自由生成的翻译准确率提升 0.73 个百分点。**

| 问 | 答 |
|---|---|
| 有效吗 | 有效，幅度小：自由生成宏平均 EM **82.64% → 83.36%**（配对 +0.73pp） |
| 可信吗 | 可信：4 个种子方向全一致（+0.95 / +0.65 / +0.80 / +0.50），配对标准误 0.10pp ⇒ 效应是噪声的 **7.5 倍** |
| 代价 | 训练时间 **+85%**（10.0 → 18.5 分钟 / 8000 步） |
| 伤到别的吗 | 没伤：重构 中→中 +0.18pp、英→英 −0.02pp；跨语言对齐 Δ −0.008、AUROC 不变 |
| 能当定论吗 | 只能当**方向**：8000 步时损失仍在下降（未饱和）⇒ **0.73pp 是下界**；且只试了一个权重（0.5）、一种 rollout 形态、单语料 |

## 做法（单变量）

两臂唯一差别是输出卡的训练目标，其余逐字相同（冻结 α0.5 输入卡、适配卡 mid=64、衔接处 infonce λ=0.3、8000 步）。

- **T 臂**：现状 —— 4 项 teacher-forced CE。
- **R 臂**：同样的 loss，**再加** 0.5 ×（用模型自己的 argmax 拼出后续输入后算的 CE；这一段不回传梯度）。

两臂梯度步数与数据量相同，R 只多一次不产生更新的前向 ⇒ 不是"算力更多所以更好"。

## 这个结论怎么用

- **要不要进 v0 配方**由用户定：v0 是锚定基线，改了要重记版本。
- 边界：单语料（Tatoeba 日常短句）· 输入卡冻结 ⇒ 只在 v0 形状下成立 · 未饱和 ⇒ 量级取下界 ·
  不含 T vs M 对照（**不涉 `MEME_FRAMEWORK §10.1`**）· 不主张模因信息完整性（**不依赖假设 A**）。
