## 裁决：**BLOCKED**

**不是设计被否** —— 单变量纪律（四臂唯一变量 = 思维卡，`--slots` 是臂间共用的第二根轴且已标"描述性"）、主指标沿用 v2（TF 翻译 char 逐样本宏平均）、
seed n=4 起跑、Δ_min/δ_eq 公式、N1–N8 沿用 + N9/N10 新增、四臂参数量、成本估算 —— **都站得住**。

**BLOCKED 的理由（三条，都会改写结论或损坏既有产物）**：

1. **判据有两份家、且结论相反**（错法⑩ + ⑥）：`§0` 的**反向预测**（`|C64−A| ≤ δ_eq` ⇒「接口瓶颈也不是机制来源」）与 `§4` **档八**（无分辨力 ⇒「**不许**写档二、**不许**写'瓶颈不必'」）
   在 `0 < |Δ| ≤ min(δ_eq, 2SE)` 的整段区间**同时命中且结论相反** —— 而 L3-t1 **实测就落在这个区间**（|Δ| ≤ 0.03pp，2×SE = 0.16pp，δ_eq = 1pp）。
2. **把一个已被自己判为误的条款原样带进第二轮**：`REPORT_THINKCARD §4` 明写档八的「四臂全距 < 2×SE」分支**会在干净的零结果上触发**（它把"不显著"当成"无分辨力"），
   并给出下次的改法；`PREREG_SLOTN §4` 却「**全部沿用** v2 §4（含档八）」。⇒ 结合第 1 条，`§0` 的反向预测**永远落不了地**（⑥ 逻辑真空）。
3. **写死 ≠ 接上了线 + 没有"瓶颈真的形成"的门**（错法⑦/⑧）：`runs_v0_inputs.sh` 的产物路径**写死无 `_n{n}`**（会让 v0′ 与 n=16 的 v0 同名静默覆盖，或核验必失败），
   `runs_thinkcard.sh` 的 **N4 断言清单只含 bridge/mid/ff/seed、不含 n 维**；而复核时点 `86g` **无 `--slots`**、`tests/test_slots_config.py` **不存在**、`86p run_paths()` **无 n 维** ——
   这三项是 §2 N9 与 §7 的依赖，却**不在 §1 的「★ 前置」里**。同时**没有任何一条检查"n=4 真的压掉了信息"**（预测 1 被标成"不作判据"）。

**解锁条件**：必改 **1–12** 全部落盘（改法都写成了可直接抄的措辞）+ `runs_thinkcard.sh` / `runs_v0_inputs.sh` 的 **N4（含 n 维）与 N9 预检实跑一次**、输出贴进 §2。
满足后**不必重开复核**；若只落了必改 1–5 而未动 6–7，仍按 BLOCKED。

## 这份预注册答不了的问题（诚实列）

1. **`§13.2` 的机制本身**：本轮压的是**接口 n（四臂共用）**，`§13.2` 的瓶颈是**卡内 `d_mid`（臂间差）**；
   无论结果如何都答不了"强制路由是否必须配瓶颈"，只能答"接口收窄时卡的边际贡献变没变"。
2. **λ 与卡谁的功劳**：`C64−A` 是联合效应（v2 §1/§5 已声明），无 `--loss none` 对照 ⇒ 拆不开（v2 已记"本轮不做"）。
3. **纯容量 vs 机制**：无"固定 n=16、提高任务难度"的对照 ⇒ "任务变难 ⇒ 卡更有用"这一最朴素解释无法排除。
4. **交互项（差之差）**：n=16 格已判档八 + 三档三套输入卡 ⇒ **不可识别**（含 §4 明记"不做"的第四角）。

6. **假设 A 的边界**：若预测 1 失败（n=4 没掉分），"n=16 本来就没存下这些信息"是未排除解释 ⇒ 该结论**依赖假设 A**（`§0.1`），本轮不验证。
7. **饱和 × n 的交互**：8000 步在 n=16 已"未严格饱和"（R35 只判方向）；n=4 更难 ⇒ 更可能未饱和，方向可能随步数翻转；本轮**不预注册**饱和后复核的触发条件（沿用 v2 §5）。
8. **seed 分布**：n=4 只给"四次运行"的复现性，给不了 seed 分布置信区间；若 δ_seed 实测 >1pp，预测 2 大概率落"带内"且**按 v2 档五不许再补 seed** ⇒ 该预测可能永远停在"未测出差异"。

  > 另外**单侧门在 A 臂垫底时会"必过"** ⇒ 若 A 臂读数 ≤ 地板+2SE，该门须标「**无分辨力，不作为通过证据**」（现档八只兜"贴顶"这一侧，不兜这一侧）。

**`step-0` / D 臂 / 地板在 n=4 下的总判断**：D 臂三档**判据本身与 n 无关，仍成立**（只空转了"补 seed"那一档，必改 9）；
地板的**分列规则**沿用正确，`floor_random` 形状随 n 由 N10 兜住；`step-0` 是唯一一个"**已知退化还照报**"的条目，必须带注。

### (b) **预测 2 的可证伪性** —— **当前不可证伪；中间漏了 4 段解释**

`n=4` 上 `C64 − A ≥ δ_eq` 这个预测，要支撑"`§13.2` 的机制（含接口瓶颈这种形态）成立"，中间的推理链是：
**接口被压窄 ⇒ 卡成为唯一能重组受限信息的计算位点 ⇒ 所以卡有边际收益 ⇒ 这就是 `§13.2`**。
这条链在**四处断裂**，且每一处都有**同样能解释读数**的替代原因：

1. **任务变难 ⇒ 卡更有用（纯容量/难度效应）** —— 你（和我）最该防的就是这条：n=4 让任务更难，**任何**额外可训参数的边际价值都会上升，
   这个预测**不需要 `§13.2` 就能写出同样的方向**。缺的对照 = **固定 `n=16`、把任务变难**（加长句对/加约束），看 `C64−A` 是否同样上升。
2. **λ 的联合效应** —— `C64−A` = 卡 + **活的 λ**（A 臂 λ 对冻结输入零梯度、完全惰性，v2 §1/§5 已写死）；
   n 越小、跨槽对齐越挤 ⇒ **λ 的贡献本身是 n 的函数**，与"卡"无关。缺的对照 = `--loss none` 臂（v2 记"本轮不做"）。
3. **输出卡对模因不敏感** —— `REPORT §2.3` 实测：约 **48pp 与模因内容无关**、"输出卡对收到哪种模因不敏感" ⇒
   即使卡真的改写了模因，**读数也可能不动**（L3-t1 的四臂 0.03pp 就是这么来的）。缺的仪表 = **N12 模因置零/打乱探针**（必改 11）。
4. **交互项不可识别** —— "边际贡献**随接口收窄而上升**"是差之差，需两格都可判；**n=16 格已判档八（不可判）**，且三档三套输入卡 ⇒ 原则上识别不了（必改 12）。

**结论**：预测 2 现在**既不能证实 `§13.2`、也不能证伪它**（不成立时也可能是输出卡读不出，或 λ 抵消）。
按必改 11 + 12 的措辞降级后，它降为一个**可证伪但更弱**的命题：「**在本任务、本 λ 配置下，接口收窄时"卡+λ"的联合边际贡献上升**」——
这个弱命题**是可证伪的**（反向预测 + 档八′效应上界 + N12 前提都能拦住它），但**它不是 `§13.2`**。
另外要记住：**`§13.2` 的瓶颈在卡内 `d_mid`，n 是接口槽**（已读确认第 3 条①），二者并列不等同 ⇒ 论文式表述里必须写"**接口侧的一种容量瓶颈**"。

### (c) **扩展规则 E-n8 / E-卡收益：会不会变成"事后加臂"？写死的触发条件够不够死？**

**判断：结构上不是事后加臂（这点过关），但"够死"不达标 —— 三条缺陷。**

**为什么不算事后加臂**：`PREREG_TEMPLATE §4` 的原文禁令是「带内 ⇒ 按预注册的**扩展规则**（如补 2 seed 到 n=6）再判，**不许事后加别的臂**」；
`experiments/free_rule_floor/PREREG.md` 立下的判例是「**跑前声明的对照臂 = 预注册对照，不是事后调参**」。
E-n8 / E-卡收益 都写在 `§4`、**触发条件（档八 / 档一或档三）在见数据之前写死**、跑的还是**同一套四臂**（不是新增一种 `mid/ff/loss` 配置）⇒ **符合"预注册扩展规则"的形态** ✓。
同理，`§4` 末行把第四角 `(mid=128, ≈117k)` 明确标为"**不做，须另预注册**" —— 这一条**做得对**，是"不事后加臂"的正面证据 ✓。

**但"够不够死"——不够，三条**：

1. **触发条件与档八定义不一致**（`§4` 写"贴地/贴顶**或无分辨力**"，v2 档八是两条分支）⇒ 两处定义、可各取所需（必改 3）。
2. **`n` 的可选集没写死 + "找那一档再判"留下多重比较出口**：可跑的只有 `{4, 8, 16}`，而 **n=16 已判档八**；
   若 n=4、n=8 都触发档八 ⇒ **无档可找**，规则无出口；反过来若只报能判的那一档 ⇒ 就是挑结果（必改 3 的②③④）。
3. **E-卡收益 的"单调 ⇒ 强证据"在 n=16 不可判的事实下恒真**：实际只剩 `{8,4}` **两点**，任意两个数都单调 ⇒ **空判据**；
   且三档三套输入卡，剂量-反应只能是描述性（必改 4）。

**够死的写法**（已在必改 3/4 给出，可直接抄）：触发 = "`verdict()` 的返回档位"（不是文字描述）· `n ∈ {4,8,16}` 写死不可新增 ·
三档全档八 ⇒ 记"不可判"不再加档 · 最终判词并列报全部已跑档 · 单调须 ≥3 个可判档才叫"强证据" · 扩展规则进 `86p --selfcheck`（R48）。
