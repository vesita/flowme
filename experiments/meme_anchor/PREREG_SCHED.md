## 3. 判据（写死；配对口径）

**主口径**：逐 token 配对 `ΔCE = mean(ce_A1 − ce_A0)`（teacher forcing、`ignore_index=PAD`、reduction=none）。

**SE 按样本聚类稳健**（★ 必须）：同句内 token 强相关，不许当独立样本。做法 = 先在**样本内**取 token 均值，
再在**样本之间**算 SE（独立单元 = 句子）。测试集句长 8..54 不等（实测 47 种），聚类不是可选项。
实现 = `stages/87_sched_verdict.py::cluster_delta`。

| # | 判据 | 门槛 |
|---|---|---|
| **主** | 配对 ΔCE，两臂同 seed 配对 | `ΔCE < −2×SE_cluster` 且 **2/2 seed 同号** |
| **非劣门** | `exact_t`（EM）不许崩 | 掉 ≤ `max(地板, 2×SE)` —— 不许拍死常数 |
| **读数完备** | 每个 run 必须出 `[RUN-FINAL]` 且 4 个逐 token 产物齐 | 缺任一 ⇒ **判词作废** |
| **Δ_min** | 报 `Δ_min = 2×SE_cluster`；`\|Δ\| < Δ_min` | 只许写"**该口径下未测出差异**" |
| **地板** | `max_naive`（含计数类）；机会级与捷径级**分开列** | 必报 |
| **饱和（R35）** | 两臂在 `S/2 → S` 的增量 | 未饱和 ⇒ 读数标【下界】，主判据只判方向 |
| **A/A 地板** | 同臂同 seed 跑两次的配对 ΔCE | **必须并列报**：它是"轨迹噪声"的量级，不是效应 |

**预测值**：`ΔCE ≈ −0.01 ~ −0.03`（§0）⇒ 跑完与实测并列报"差多少"。

## 3b. ★ 跑后补记：A/A 地板判死了原设计的"配对"前提（2026-10-14，判据不变）

**首轮 A/A 实测**（同臂 `const`、同 seed、各 3000 步，各跑两次）：

| seed | 配对 ΔCE | SE_cluster | EM 两次 | 最终**训练** CE |
|---|---|---|---|---|
| 1234 | **+8.223e-03** | 1.463e-03 | 0.6285 / 0.6310 | **0.16686 / 0.11863** |
| 5678 | **+8.691e-03** | 1.466e-03 | 0.6315 / 0.6365 | — |

- `rng_after_1` 逐位相同（=True），但**最终训练 CE 差 0.048**（相对 29%）⇒ 不是评测噪声，是**训练轨迹真的分叉**。
  根因与 `AGENTS.md` 记录一致：`nn.Embedding` 反向的 `index_add` **原子累加顺序不定**；逐位承诺只覆盖"同进程同批"。
- **后果（必须写在任何结论旁边）**：同配置两次运行的"效应"已达 **+8e-3**，与我 §0 登记的**预测效应量（−1e-2 ~ −3e-2）同量级**
  ⇒ 即便主判据落"一 成立/四 有害"，也可能是**运行噪声**而非调度效应。
- ⇒ **本实验的判词按"该口径下"读**：判据**不作废**（A/A 是并列读数、不是判据的一部分），
  但 **§4 的档位必须与 A/A 地板一起报**；落在"一 成立"时要额外说明"未超过 A/A 地板"。
- ★ **判据本身未改**（`|Δ|≤1SE` = 未测出 · 带内 = 不可判），改的是**对结论强度的说明**。
- 可救路径（本轮未执行）：同进程配对（`--aa-inproc`，AGENTS.md 承诺逐位只覆盖同进程同批）；
  或把主判据换成**不依赖逐 token 配对**的口径（逐样本 EM 的 McNemar）。

## 6. 成本

- 单 run 步时**实测**（不许套用别的脚本）：`--smoke` 实测 `0.240 s/step`（含首次编译）；
  A/A 200 步实测 `0.047~0.090 s/step` ⇒ 3000 步约 **2.5–4.5 min/run**。

- 长跑用 `systemd-run --user --unit=s87-sched --collect`。
