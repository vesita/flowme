# 预注册：方案 A —— 候选槽位嵌入（task-11 表征实验，reply_pick）

> **本文件在任何一次训练启动之前写死；跑完不改。** 判据与判定规则全部见下。
> 唯一假设：`128 字扁平窗口 + 单查询解码` 下，类别头（说出候选编号）与指针头（指向该候选区间）
> 建立不了「哪个区间属于哪个候选」的绑定；给每个候选区间的 token 加一个**可学的候选编号嵌入**后，
> 绑定应当变容易。

## 1. 输入构造与候选嵌入

- `cand_idx ∈ {0,1,2,3,4}`，逐**字符（= 逐 token）**定义：
  - `0` = 问句部分（`问：` + 问句正文）与 tokenizer 填充位；
  - `n (1..4)` = 第 n 个候选的**标号段 `|n）` + 该候选正文**的全部字符。
- **分隔符归档：`|n）` 归它所引入的那个候选（n 档），不归 0 档。** 理由：
  1. 标号段与正文首尾相接，归 n 档后每个候选区间是**连续的**（整个候选列表被切成 4 段无缝分区），
     不会把「标号里的数字 n」和「候选 n 的正文」拆到两个档位；
  2. 标号里的数字字面就是 n，让 `cand_idx = n` 的区间自带一个指向类别 n 的字面锚点，
     正是「类别头 ↔ 指针头」要对齐的那个东西；
  3. 填充位必须归 0（否则 padding 参与绑定）。
- **锚点不受影响**：`cand_idx` 只改 encoder 输出，不改标签；金标区间仍是候选**正文**（0-based 半开），与
  `spans` 契约一致。
- 加法位置：`doc_memory = NanoDocEncoder(input_ids, mask) + cand_emb(cand_ids)`，
  `cand_emb = nn.Embedding(5, hidden_dim)`，`init.normal_(0, 0.02)`（与基座词嵌入同一量级，
  起点近似于基线的微扰）。**基座与解码器不动一个字节**；`src/`、`tests/`、`training/` 全部不改。

## 2. 臂与配置（8 跑 = 2 档 × 2 臂 × 2 seed）

| 维度 | 取值 | 说明 |
|---|---|---|
| 档 | `frozen`：基座冻结，只训解码器（+嵌入）；`joint`：基座 lr 3e-4 与头一起训 | dev-notes/12 §12.5：冻结拖累新卡，两档都要 |
| 臂 | `cand`（加嵌入） / `nocand`（同配置不加嵌入） | **唯一有效对照** |
| seed | 42 / 43 | 两 seed 报均值 + 原值 |
| 数据 | 训练折 6000 条（`seed=DEFAULT_SEED`，与 §9 同一份）、评测折 1500 条（`split="eval", seed=4242`） | 评测折与训练折逐条不相交 |
| 训练 | batch 64、lr_head 1e-3、wd 1e-4、cosine；frozen 12 ep × 150 步 = 1800 步，joint 16 ep × 150 步 = 2400 步 | 档内两臂逐字相同 |
| 对照纪律 | `nocand` 臂**照样构造** `cand_emb`（同一 RNG 消耗点、同一初始化），只是**不接入计算图、不进优化器** | 保证两臂初始化与数据顺序逐位一致，唯一变量就是「加不加」 |

## 3. 指标口径

全部用与训练**同一套**前向（`NanoDocEncoder` →（+候选嵌入）→ `RobustARSliceDecoder`），
在**训练不重合的评测折**上算；`_rollout` / `_truth_of` 直接复用 `dtseek.tasks.runtime`（不重写）。
- **测量自检（跑前定）**：`nocand` 臂下，我的评测函数必须与 `runtime.evaluate_task` 在同一批样本上
  **逐项相等**（`--parity` 检查，n=200）。不等 ⇒ 先修测量，不报指标。
- **盲猜基线 = 1/5 = 20%**（5 类，含「无合适候选」）。注：这是 `cls_acc` 的盲猜；
  `exact_match` 还要求区间也对，其盲猜值远低于 20%。

## 4. 判据（P1–P3，跑前写死）

| 编号 | 判据 | 阈值 |
|---|---|---|
| **P1** | 评测折 `exact_match`（整句类别+区间+拒答三对才算对） | **≥ 0.60** |
| **P2** | 评测折 `bg_fp`（无合适候选样本被误开火的比例） | **≤ 10%** |
| **P3** | 评测折**锚点完全命中率** = 有正解样本上「预测区间 == 金标区间」的比例（不看类别，口径 = `runtime.evaluate_task` 的 `span_hit`） | **≥ 95%** |

三条**全过**才算「选择族在当前表示下可成立」；只过 P1 不算。
附带必报（不设阈值）：`cls_acc`、条件锚点命中率（类别判对样本中的区间全对率）、按位置准确率、预测类别分布。

## 5. 判定规则（跑前写死）

- **假设成立** 当且仅当：`cand` 臂在**两个 seed 上各自** P1–P3 全过，**且**相对同配置 `nocand` 基线
  两 seed 的 `Δexact_match` **同号**、均值 **≥ +0.10**。
- **假设不成立**：`cand` 臂任一 seed 未过 P1–P3，或相对基线无正向增益 ⇒ **如实报**，并给机制分析
  （训练集 exact 是否仍近 100%、训练/评测差距是否缩小、损失曲线是否仍在记训练集）。
- 证据不足（两 seed 方向不一致）⇒ 只报原值，不下结论。
- 单 seed 不下结论；不拿 dev-notes/13 §9 的旧数字当对照（配置不同），只作背景引用。

## 6. 代价（必报）

训练墙钟、峰值显存、步数、每步秒、候选嵌入参数量与总参数量。
