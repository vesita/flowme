## 3. 判据（P1–P6，逐条对照，跑前不改）

| 编号 | 指标（定义冻结） | 判据 |
|---|---|---|
| P1a | **按候选位置的准确率**：E1 正解样本按 `answer_pos∈{1..4}` 分组的类别准确率 | max − min ≤ **10pt** |
| P1b | **打乱序 vs 固定序**：`acc(E1 正解)` 与 `acc(E2 正解)` 之差 | \|Δ\| ≤ **5pt** |
| P2a | **拒答误触发**：E1 正解样本里被判成「无合适候选」的比例 | ≤ **5%** |
| P2b | **拒答召回**：E1/E3/E4 无合适样本里判成「无合适候选」的比例 | 只报数（dev-notes 无阈值） |
| P3 | **换帧探针**：`run_probe` 的 `class_acc` 与 `span_acc` **分开报**（探针问句/句式手写，与训练不重合，单测钉住不重合） | 只报数（旧账：句级 97.9% → 换帧 25.4%） |
| P4a | **整句级**：E1（及 E3）上的 `exact_match` / `slice_precision` / `slice_recall` | 只报数 |
| P4b | **只留高难负例的类别准确率**：E3 正解（对照 E4 纯跑题） | 单独报，用来分辨「真会选」还是「只会排跑题」 |
| P5 | **锚点完全命中率**：E1 正解中**类别判对**的样本里，指针区间 `[start, end-1]` 逐字等于被选中候选的比例 | ≥ **95%**（另报类别+锚点联合命中率） |
| P6 | **代价**：训练墙钟 `train_sec`、峰值显存 `peak_mem_mb`、单步 `sec_per_step` | 只报数 |

补充必报（任务书点名）：预测类别分布（看模型是否恒选某个槽位）、E1 全量类别准确率 vs 盲猜 20%。

## 4. 推理口径

- 指标用 `MultiTaskEngine.predict`（部署口径：`window` 整段解码）逐条算；
- 另用批量前向复算 E1 的前 200 条，**两条路径一致率必须 100%**，否则先修口径再谈数字；
- 样本长度已卡在 `max_len − 8`，`window` 不会切段（切段 = 候选结构被标点破坏）。

## 5. 数据构造的 fail-closed 校验点（构造期抛错即视为构建失败）

1. 标记符号词表校验（单 token、无 UNK、无 id 碰撞）—— `frame.validate_markers()`；
2. 内容不含 `|` `）` `_`；整段 ≤ `max_len − 8`；
3. 每样本 ≤ 1 切片；锚点区间逐字等于被选中候选；数据集内文本不重复；
4. 问句/句子训练折与评测折不相交；
5. cloze：`score(正解) ≥ 4 且 ≥ 3 × max(score(干扰项))`；无合适样本 4 个候选 `score < 4`；
   干扰项同词类、同字长、词频落在 `[f/3, 3f+2]`；
6. cloze 空位配额：句首 ≥15%、句末 ≥15%、与标点相邻 ≤70%。
