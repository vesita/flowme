# struct_supervision —— 整句 loss vs 槽位监督 三臂对照 + 未训句式对抗集（预注册）

> **本文在首次训练之前写死**（mtime 必须早于任何 train 进程启动时刻），跑完不改；结果填 `REPORT.md`。
> 口径：「实测」= 本目录跑出的数字；「推断」= 由数字推出；「口径判断」= 构造时人为规定的归属。

## 0. 唯一问题

**同一模型、同一数据、同步数、同 seed，只把监督形式换掉：整句交叉熵（A）、槽位标签（B）、两者相加（C）
—— 谁更能把「骨架 + 槽位指派」学出来，尤其在训练集未出现的句式上？**

- **核 1,688,460 全程冻结 + `eval()`，只训头**（`load_base_encoder` 置 `requires_grad=False`，每跑再钉一次并断言）。
  除非本文写了别的，否则冻结口径与 `experiments/two_channel_head` 完全一致。
- **只允许写** `experiments/struct_supervision/`、`logs/`、`/tmp`；`two_channel_head/` 与 `src/` **只读**。

## 1. 三臂（同一模型类、同一输入、同一构造顺序与初始化）

| 臂 | 监督形式（唯一变量） | loss | 可训参数 |
|---|---|---|---|
| **A** | **整句 loss**：对金句做 teacher-forced 字级交叉熵 | `L_sent` | trunk + 整句头 |
| **B** | **槽位监督**（= 现有口径）：骨架 id 多分类 + 逐槽指派多分类 | `L_gen = CE_skel + CE_assign` | trunk + 结构头 |
| **C** | **两者相加** | `L_gen + L_sent`（λ=1，写死不调） | trunk + 结构头 + 整句头 |

- **输入三臂逐位相同**：生成特征 `[v_sent; v_bag; v_sent⊙v_bag; |v_sent−v_bag|]`（512）→ **同一 Trunk**（`Linear(512→256)→GELU→Linear(256→128)→GELU`，164,224）→ `h(128)`。
  - 结构头（与 `two_channel_head` **逐项同构同宽**）：骨架 `Linear(128→40)` + 指派 `MLP([h;v_item])→64 ⊗ 可学槽位嵌入`。
  - **整句头（新）**：`Embedding(V→64)`；每步输入 `[emb(前一字); h; att]`(320) → `GRU(320→128)` → `Linear(128→V)`；
    `att` = 以 `emb(前一字)` 为 query 对**同一组池化袋向量**做加权和（128）。
    ⇒ **A 看到的张量与 B/C 完全相同（h + 池化袋向量），不含句的逐字状态** ⇒ 杜绝「复述输入再解析」这条恒等捷径
    （那条捷径 = 标注函数的逆，`two_channel_head` 已把它单列为 `annotation_inverse` 作弊项）。
- **初始化逐位相同**：固定构造顺序 `(trunk, 占位 Linear(128→1), gen, sent)` + `manual_seed(seed)`
  （占位层只为对齐 `two_channel_head` 的 RNG 序列）⇒ **本实验 trunk/gen 初值 == `two_channel_head` 同 seed 初值**（selfcheck 断言）。
- **三臂输入、数据行、batch 序列、步数、优化器全同**；差异只可能来自监督形式。
- **步数 1800、batch 64、AdamW lr 1e-3 / wd 1e-4、cosine、grad clip 1.0、seed 42/43**（与 `two_channel_head` 同配方）。
  DataLoader `generator=manual_seed(seed)` ⇒ **本实验 B 臂应复现 `two_channel_head` B 的 0.6396/0.6424（骨架）**，
  复现不上即报「同口径校验失败」并如实记入遗留（不改配方去凑）。
- **A 的结构出口（写死）**：A 没有结构头梯度 ⇒ 其骨架/槽位/联合**只能**由
  **自由解码（greedy，BOS 起，EOS 或 64 字止）→ `match_sentence` 解析 → 槽位按袋内文本还原**给出；
  **解析不出 ⇒ 该行骨架/槽位/联合全错**（fail-closed，不降到任何兜底）。
- **C 的结构指标**由其结构头给出（主），其整句头的句子指标作辅助列一并报。

## 2. 数据（跑前写死）

- **训练/测试只读复用** `experiments/two_channel_head/data/{train,test}.jsonl`（8000 / 2500，不改、不重建）；
  冻结核向量也只读复用其 `cache/gen_*_L64_M4.pt`（键 = 句面 + bag_span 的 md5，命中即用）。
- **语料过滤（与训练数据同口径，且满足 `dev-notes/19` 的硬要求）**：
  语料入口只用 `dtseek.tasks.corpus.resolve_corpus_files`；**文件级汉字占比 ≥0.6**
  （**严于** `dev-notes/19` 的 ≥50% 下限，为与训练数据同口径；被丢文件与比例全列），
  **打乱文件序**（`SPLIT_SEED`），**不许 `fs[:N]`、不许按返回顺序取前若干**；句级汉字比 ≥0.6、句长 14–44、去角色前缀、半角归一、剔 ASCII 词。
- **对抗集两子集（都必须是训练集未出现的句式；与 train/test 句子零重叠，断言）**：

| 子集 | 构造（写死） | 骨架 gold | 判据用途 |
|---|---|---|---|
| **adv1 零样本骨架** | 骨架 id ∈ **训练零样本的 10 个 id** `{16,21,24,27,28,29,30,32,33,34}`（模板 `[1]，然而[2]` / `[1]，要不[2]` / `[1]之前，[2]` / `[1]把[2]` / `[1]把[2]了` / `[1]被[2]` / `[1]被[2]了` / `[1]从[2]到[3]` / `[1]让[2]` / `[1]比[2]`）；句面经 `match_sentence` **只命中这些 id**（= 训练集从未出现的句式） | 在输出层宽度内、**训练零样本类** ⇒ 骨架命中对三臂都是**训练零样本**（单列披露，骨架列不入 S3 主判） | **槽位迁移**（S3 主判据） |
| **adv2 组合槽型** | 骨架 ∈ 训练 30 类；**槽型签名**（**按句序**逐槽取类：疑问>否定>数字>时间>其他，首个命中；train 行的 bag 是洗牌的，统一按 span 排回句序再算）在该骨架的 train 中**未出现过**，且签名里每一类在该骨架 train 中都出现过（**纯组合新颖**，非新类） | 训练类 | **骨架 + 槽位**的组合泛化（S3 骨架判据 + S1 对抗集列） |

  - 目标规模每子集 ≥800 句（不足则报实际并说明）；报每个子集的 n、样例 3 句、命中骨架分布。
  - adv2 降级顺序（写死，按序尝试并**记录实际用到的级别**）：
    L1 每类在该骨架 train 中 ≥1 且签名未见 → L2 放宽为「签名未见 + 各类在**全局** train 中 ≥1」→ L3 仅「签名未见」。
  - **（跑前实测修订，mtime 仍早于首次训练）原计划的第三子集「adv3 表外多槽新骨架」已删**：
    实测 120,000 句中 `match_sentence` 未命中率 19.7%，**未命中的几乎全是无标点单小句**；
    含逗号且槽长合规的句子会被 `[1]，[2]` 这类 catch-all 命中，而中部虚词字面又被规则 A′
    （虚词须被标点或句界锚定）禁止 ⇒ **「表外 + 多槽」的新骨架在本口径下不可构造**（可构造的只有单槽模板，
    其指派恒为 `[0]`、槽位指标平凡为 1，无判据价值）。故对抗集 = adv1 + adv2 两个子集。
- **词表（写死）**：A/C 的输出字母表 = **train∪test∪adv1∪adv2 全部句面字符** + `PAD/BOS/EOS`，
  跑前落 `data/vocab.json`（**只含字符身份，不含标签、不含顺序**）—— 目的是让 A 在对抗集上不因 OOV 被结构性判死。
- **随机标签对照（门禁）**：`--randlabel`
  - **B-rand**：train 骨架 randperm + 每行指派值行内 randperm（同 `two_channel_head` 写法），test/adv 仍用真标签；
  - **A-rand**：train **目标句**按行 randperm（输入不动），评测仍用真金句；
  - 跑前打印 randperm 前后计数。

## 3. 评测指标（分开报，不合成一个数）

- **结构三指标**（A 由解码+解析给出，B/C 由结构头给出）：**骨架 acc / 槽位 acc（逐行槽位命中率的均值）/ 联合 acc**；
  另报 **题元**：本数据口径**没有题元标签** ⇒ 题元**未测**（如实写，不拿槽位冒充题元）。
- **A 的三个诊断（必报，用于区分「监督没学会」与「解码接口不可达」）**：
  `tf_char_acc`（teacher-forced 字准确率，不含 PAD）、`sent_exact`（自由解码逐字复现率）、`parseable`（可解析率）。
  C 的整句头同法附报。
- **SE**：骨架/联合 = `sqrt(0.25/n)`；槽位 = 逐行命中率的样本标准差 / sqrt(n)；
  **臂间差用配对 SE** = 同一批样本逐条 0/1 之差的 `sd(d)/sqrt(n)`（同 `two_channel_head` W1 口径）。

## 4. 判据（跑前写死）

| # | 判据 | 门槛 |
|---|---|---|
| **S1** | **槽位准确率**（B/C，test + 对抗集各子集与合计） | `(acc − 盲猜 0.4231) > 2×SE`，**两 seed 同号**；骨架另报 `(acc − max_naive 0.5329) > 2×SE`；**报 SE** |
| **S2** | **主指标 = test 骨架 acc，Δ = B − A**（配对 SE） | 两 seed **同号** 且 `Δ > 2×SE` ⇒ 过；两 seed **均** `|Δ| ≤ 2×SE` ⇒ **无差异**；其余（不同号 / 一过一不过）⇒ **证据不足**。次指标（槽位、联合）与 C−A 同法**附报，不改判** |
| **S3** | **未训句式迁移**：对抗集（adv1+adv2 合计）槽位 acc，Δ = B − A / C − A（配对 SE） | 两 seed 同号且 `Δ > 2×SE` ⇒ 过；**若 B/C 的对抗集槽位与盲猜之差 ≤ 2×SE ⇒ 如实报「背句式而非学填槽」**；adv2 骨架差附报；adv1 骨架 = 训练零样本类（三臂皆不可能命中，构造所致）单列不入判 |
| **门禁** | **随机标签对照** | B-rand：骨架 ≤ 多数类 0.4169+2SE、槽位 ≤ 盲猜 0.4231+2SE；A-rand：解析出的骨架 ≤ 盲猜 0.025+2SE。**真执行**（打印 randperm 前后计数）。任一不过 ⇒ **证据不足** |
| **必报** | **`max_naive`** | 数值 + 各臂骨架 acc − `max_naive`（test 用 0.5329；adv2 上**重算**朴素电池，fit=train）；**若卡低于它，如实写「未超过免费规则」** |

**判定三选一（写死，不许硬选、≥2 seed、不许调参刷过；seed 只有 42/43、步数固定 1800）**：

1. **结构化监督更好** = S2 过 ∧ **S1 过（B 与 C 的槽位在 test、adv1、adv2、adv 合计四个格子上均 `(acc−盲猜) > 2SE`，两 seed 同号为正）** ∧ S3 过 ∧ 门禁过；
2. **与整句 loss 无差异** = S2 主指标两 seed 均 `|Δ| ≤ 2×SE`，且门禁过、S1 过；
3. **证据不足** = 门禁不过 / 两 seed 不同号 / S2 一过一不过 / S1 或 S3 关键格子缺数 /
   **S2 过但 S3 不过**（只能报「域内优势」，不足以判「更好」，因 S3 是背句式 vs 学填槽的唯一判据）。

**机制解读（写死，防事后找补）**：A 的结构出口要过「自由解码 + 解析」，故 S2 的差可能来自
**监督本身**或**解码接口**。用三个诊断区分（结论里必须二选一并给依据）：

- `tf_char_acc` ≈ 语言模型先验（与 A-rand 同档）且 `sent_exact` ≈ 0 ⇒ **整句 loss 没把输入对齐进表示**（监督本身）；
- `tf_char_acc` 明显高而 `sent_exact` ≈ 0 ⇒ **误差累积 / 逐字复现不可达**（解码接口）。

**范围限定（写死）**：任何结论只在「**核冻结、只训头、同一池化接口、1800 步、seed 42/43**」口径下成立，
不外推为「结构化监督在任意设定下更好」。

## 5. 自检（开训前必须打印，`model.py --selfcheck`）

1. 核 `requires_grad` 全 False + `training=False`（实测打印），可训参数只有头；
2. 三臂可训参数**逐项**（trunk / gen.skel / gen.assign / sent.*）；
3. **同口径校验**：本实验 trunk、gen 初值 == `two_channel_head` 同 seed 初值（逐位 `torch.equal`）；
4. **解析往返**：train 全部 8000 行 金句 → `match_sentence` → 还原 (skel_id, assign) == 标签（应 100%）；
5. **对抗集断言**：与 train/test 句子零重叠；adv1 的骨架 id 训练零样本（train 计数 = 0）；adv2 签名未见且级别已记录；
6. **词表覆盖**：全部句子（train/test/adv*）字符 ∈ 词表（0 个 OOV）；
7. 随机标签对照真执行（打印 randperm 前后计数）。
