# 结构化监督 vs 整句 loss：三臂对照 + 未训句式对抗集（实测）

**判定：结构化监督更好**（S1 ∧ S2 ∧ S3 ∧ 门禁全过，两 seed 同号）。
判据在 `PREREG.md`：mtime **03:33:59**，早于首次训练 **03:39:43**（冒烟）/ 03:41 全量；
**开训前修订过 3 次**（删 adv3、补判定边界槽、签名统一句序），**跑后未改**。核 1,688,460 全程
`requires_grad=False` + `eval()`，只训头；seed 42/43；1800 步；未调参。
口径：「实测」= 本目录数字；「推断」= 由数字推出；「口径判断」= 构造时人为规定。

## 3. S1 / S2 / S3 逐条 + 门禁 + 判定

- **S1 槽位（test+对抗集，两 seed）：过** — B/C 四个格子 t = +143.7 ~ +247.7（全 > 2SE，同号为正）：
  test +245.3/+243.9（B）、+247.7/+236.5（C）；adv1 +161.6/+154.3；adv2 +147.7/+143.7；adv 合计 +217.7/+210.0。
  骨架附报：test `0.6396/0.6424 − max_naive 0.5329 = +0.1067/+0.1095`，t=+11.11/+11.42（C：+0.1143/+0.1111，t=+11.96/+11.60）。
  **题元未测**：本数据口径没有题元标签 ⇒ S1 的题元半条**缺数**，不拿槽位冒充。
- **S2 主指标（test 骨架，Δ=B−A，配对 SE）：过** — Δ=+0.6396/+0.6424，SE=0.0096，**Δ/SE = +66.6 / +67.0，两 seed 同号**；
  次指标附报：槽位 +436.4/+434.0，联合 +62.4/+63.1；**C−A** 骨架 +67.7/+67.2（同样过）。
  附报 **C−B = +0.0076(t=1.97) / +0.0016(t=0.41)** ⇒ **相加不改变结构头（两 seed 均 ≤2SE）**。
- **S3 未训句式迁移（对抗集槽位，Δ=B−A）：过** — **+0.9682/+0.9666，Δ/SE = +415.0 / +400.9，两 seed 同号**；
  C−A +414.2/+404.7；adv1 单列 +330.0/+315.9，adv2 +260.0/+253.1，**adv2 骨架** B−A **+17.3/+17.7**。
  **迁移不是背句式**：B/C 在 adv1/adv2 的槽位相对盲猜 t = +143.7 ~ +161.6 ≫ 2SE（两 seed）⇒ **未见句式上仍会填槽**；
  骨架在 adv2 只剩 0.231~0.239（test 是 0.64）⇒ **骨架识别确实掉了 41pt，但没掉到盲猜/多数类**。
- **门禁（随机标签对照）：过** — A-rand 骨架/槽位 0/0（≤ 0.0450 / 0.4231）；B-rand 骨架 0.3780/0.3676（≤ 0.4369）、
  槽位 0.3357/0.4381（≤ 0.4373/0.4389，**s43 险过 0.0008**）；randperm 前后计数已打印。
- **max_naive 必报**：test 0.5329 → B **+0.1067/+0.1095**、C **+0.1143/+0.1111**（超过免费规则）；
  adv2 0.182 → B +0.049/+0.057、C +0.057/+0.053（超过）；**A 三处全部低于 max_naive ⇒ 如实写「A 未超过免费规则」**；
  adv1 的 max_naive = 0（训练零样本类，朴素规则也 0）⇒ 该格子构造性持平，不作判据。
- **判定（三选一，PREREG §4 原文执行）：「结构化监督更好」** = S2 过 ∧ S1 过 ∧ S3 过 ∧ 门禁过，全部两 seed 同号。
- **机制（按 PREREG 分支二选一，给依据）：主因 = 监督本身**。A 的 TF 字准确率 0.1861/0.1877 vs A-rand 先验 0.1483/0.1575
  ⇒ 只前进 **+3.78 / +3.02 pt**，占「先验→完美」缺口的 **4.4% / 3.5%** ⇒ 按写死的分支判为**「与先验同档」**
  = **整句 loss 没把输入对齐进表示**；叠加次因**解码接口**（可解析 0%，TF 本身也远不足以逐字复现）。
  **非容量问题**：A 可训参数是 B 的 6.4 倍仍全 0。**范围限定**：只在「核冻结、只训头、同一池化接口、1800 步、seed 42/43」下成立。

## 5. 遗留与不确定

1. **实测**：adv1 骨架列全 0 是**构造所致**（训练零样本类 + 输出层无梯度），故 S3 的骨架判据只有 adv2 一格；adv1 的 id32 只有 9 句。
2. **实测**：A 的结构出口是 fail-closed 解析，**可解析率 0%** ⇒ 其三列全 0；S2 的差在本口径下代表「整句 loss 不可用」，
   **不可外推**到可训核 / 带复制机制的自由生成（PREREG 范围限定已写死）。
3. **实测**：B-rand s43 槽位 0.4381 vs 门槛 0.4389 **险过 0.0008**（与 `two_channel_head` W3 的临界同型）；按 PREREG 字面记为过。
4. **实测未测**：题元标签不存在 ⇒ S1 题元半条缺数；解引用/渲染层（`dev-notes/16` §7.9）不在本实验范围。
5. **推断**：adv1 槽位 0.9776 ≈ test 0.9658，推断「指派是位置匹配任务，可跨句式迁移」；**未测**其是否依赖 `v_sent` 中的位置泄露
   （若去掉 `v_sent` 只给袋，槽位会掉多少 —— 未跑）。
6. **口径判断**：adv2 全部取 L1（纯组合新颖），未动用 L2/L3；槽型 5 类规则（疑>否>数>时>他）是人为规定的，不是学出来的。
