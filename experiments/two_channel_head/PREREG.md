# 同核双通道头（two_channel_head）—— 预注册判据

> **本文在首次训练之前写死**（mtime 必须早于任何 train 进程启动时刻），跑完不改；结果填进 `REPORT.md`。
> 口径：「实测」= 本目录跑出来的数字；「推断」= 由数字推出；「口径判断」= 构造时人为规定的标签/规则归属。

## 0. 唯一问题

**一张卡的头同时带「指针通道 + 生成通道」（共用主干），两通道会互相干扰多少？
以及「共用主干」相比「两个完整头」到底省了多少参数与前向时间？**

- **核 1,688,460 全程冻结 + `eval()`，只训头**（`load_base_encoder` 置 `requires_grad=False`，
  每跑再钉一次并断言）；不发射锚点、候选身份=下标（`experiments/select_rerank/REPORT.md` 口径）。
- 重整层输出 = **骨架 id + 槽位指派**（**不发字**，`dev-notes/16` §7.7）；生成型输出必须带引用（§7.9）——
  本实验只测**结构层**（骨架 id + 指派），解引用不在范围内，但每个槽位都带 **span**（`bag_span`）可回溯原文。

## 1. 四臂（同数据、同步数、同 seed 42/43、**同初始化**）

| 臂 | 头结构 | 可训参数 |
|---|---|---|
| **A** | **只有指针分支**：`[ctx;cand;ctx⊙cand;\|ctx−cand\|]`(512) → 主干 → 1 logit，softmax over K=2 | 主干 + 指针输出层 |
| **B** | **只有生成分支**：512 维生成特征 → 主干 → 骨架多分类 + 每槽指派 | 主干 + 生成输出层 |
| **C** | **共享主干 + 两个分支**（用户方案） | **一个**主干 + 两个输出层 |
| **D** | **两个完整独立头**（对照） | 主干×2 + 两个输出层 = A + B |

- **主干（Trunk）** = `Linear(512→256) → GELU → Linear(256→128) → GELU`（164,224）；
  指针输出层 `Linear(128→1)`（129）⇒ **A = 164,353，与 `select_rerank` 的打分头逐项相同**（可比）。
- **生成特征**（与指针同几何、同宽 512）：`[v_sent; v_bag; v_sent⊙v_bag; |v_sent−v_bag|]`，
  `v_bag` = 洗牌袋各槽 span 向量的均值（袋序不变量 ⇒ 骨架预测与洗牌无关）。
- **生成输出层**：骨架 `Linear(128→40)`；指派 = `MLP([h; v_item])→64` 与**可学槽位嵌入**内积
  → `[槽, 项]` 多分类（**每槽一次 softmax over n 项**），padding 用 mask 屏蔽。
- **生成损失** `L_gen = CE(骨架) + CE(指派)`；**指针损失** `L_ptr = CE(K=2)`。
- **C / D 的总损失 = `L_ptr + L_gen`（λ=1，跑前写死，不调）**；C 与 D 唯一差别 = **参数是否分开**。
- **四臂初始化逐位相同**：固定顺序 `(trunk, ptr_out, gen)` 构造一次，`deepcopy` 分发 ⇒
  A/B/C/D 的主干与两个输出层**初值逐位相同**，差异只能来自训练梯度。

## 2. 数据（跑前写死）

- **指针分支：只读复用** `experiments/select_rerank/data/clean/{train,test,adv}.jsonl`
  （**不改、不重建**），其冻结核向量缓存 `experiments/select_rerank/cache/clean_*_ctx64_cand32.pt`
  也**只读复用**（键 = 数据 md5 + SPEC，两处不漂移）。
  指针指标 = **test(n=2500, SE=1.00pt)** 为主，adv(n=2500) 与其 `ctype` 拆分（各 1250, SE=1.41pt）附报。
- **生成分支：本目录自建**（`build_gen_data.py` → `data/`，先落盘再开训）：
  - 语料入口只用 `dtseek.tasks.corpus.resolve_corpus_files`（glob 空即抛）；
    **文件级 + 句级汉字占比 ≥0.6 过滤**（不依赖文件顺序，board m_151），打乱文件序后取句。
  - **骨架表 ≤40 个手写骨架**（`[n]` 占位、槽位与字面严格交替 ⇒ 切分唯一）；
    匹配优先级 = **字面字符数降序 → id 升序**；虚词字面必须被**标点或句界锚定**（规则 A′）；
    命中数 <30 的骨架剔除（孤类学不会）。规模 **train 8000 / test 2500**，两集合骨架集合相同、句子零重叠。
  - 袋 = 各槽 span 文本，**按 `BAG_SEED` 均匀洗牌**（含恒等）；指派标签 = 槽 j 在洗牌袋中的下标。
  - **W4 必报 `max_naive`**：多数类 / 长度桶 / 首字 / 尾字 / 标点型 / 形式虚词决策表 /
    深度 2 与深度 4 决策树，在 **train** 上取最大值，**必须 < 90%**；
    指派通道另报 identity / 逐槽多数下标 / 盲猜；`annotation_inverse`（匹配器自复现 + 按位置排序还原）
    **单列披露**、不计入 `max_naive`（口径判断：它是标注函数的逆运算，与任何模板数据集同构，
    同 `select_rerank` 不把同义词表规则计入 `max_naive` 的既有做法）。

## 3. 训练与计时口径（写死）

- **1800 步**（= `select_rerank` 同量）、batch 64、AdamW lr 1e-3 / wd 1e-4、cosine、grad clip 1.0、
  seed **42 / 43**；A 吃 1800 个指针 batch，B 吃 1800 个生成 batch，
  **C/D 每步各吃 1 个指针 batch + 1 个生成 batch**（两条 DataLoader 各自用 seed 播种
  ⇒ **A 与 C 的指针 batch 序列逐位相同、B 与 C 的生成 batch 序列逐位相同**，差异只可能来自共享梯度）。
- **前向计时必须在真实前向内量**：用**与训练完全相同的 forward、相同真实 batch、相同设备**，
  warmup 20 次后计 N=200 次（`torch.cuda.synchronize()` + `perf_counter`），报 mean/p50/p95；
  同时记录**训练逐步墙钟**（含 fwd+bwd+opt）；**单跑对账**用独立 `--timing-only` 再跑一次。
  对账口径：`前向 ≤ 逐步墙钟` 且两者比值逐臂报出（本项目吃过「探针自己制造画像」的亏）。
- **每卡前向时间报 A / C / D**（C/D = 指针路径 + 生成路径各一次；两通道输入几何不同 ⇒ 主干各调一次）。

## 4. 判据（跑前写死，W1–W5）

| # | 判据 | 门槛 |
|---|---|---|
| **W1** | **两通道干扰可接受** | C 中每通道相对其单通道的下降 **Δ ≤ 2×SE**（**配对 SE**：同一批 test 样本逐条 0/1 之差 `sd(d)/√n`），**两 seed 同号口径**同时报出；否则如实报「干扰显著」 |
| **W2** | **共享主干的节省** | 报 **C vs D 的可训参数逐项**与**前向时间差**；**若 C 不比 D 省，如实报** |
| **W3** | **随机标签对照**（两通道各一） | A-`randlabel` 掉回**盲猜 50%**；B-`randlabel` 掉回**多数类 / 盲猜**（骨架 ≈ 多数类 41.7%、指派 ≈ 盲猜）。**真执行**（打印 randperm 前后计数） |
| **W4** | **生成分支数据无捷径** | 朴素规则在 **train** 上 **`max_naive < 90%`**（≥90% ⇒ 该数据集无效，如实报并停）；**必报 `max_naive`** |
| **W5** | **老卡零损伤** | 核冻结 ⇒ **预期 Δ=0**；实测 pronoun / sentiment / relation / person 四卡 **Δ**，与**各自**噪声带（2.83 / 0.41 / 1.39 / 0.33 pt）并列；另报 `base_encoder.pt` 与四张卡文件的 sha256 训前=训后 |

**附加的证据强度门（写在前面，避免「地板上比地板」的假通过）**：

- **G1**：B 的骨架 test acc 必须 **> `max_naive` + 2×SE**（否则写「生成通道未超过免费规则」，该通道的干扰测量判**证据不足**）；
- **G2**：C 的任一通道若掉到 **盲猜 + 2×SE** 以下 ⇒ 该通道干扰不可测 ⇒ 判**证据不足**（不许把「掉到地板」写成「无干扰」）。

**判定三选一**（不许硬选、≥2 seed、不许调参刷过）：

1. **同核双通道可行** = W1 过（两通道、两 seed 均 Δ≤2SE）∧ W3 ∧ W4 ∧ W5 过；
2. **必须分头（或加私有适配层）** = W1 不过（任一通道 **两 seed 同号** 且 Δ>2SE）；
3. **证据不足** = W3/W4 不过，或 G1/G2 触发，或两 seed 不同号。

## 5. 两条硬要求（本轮的结构约束）

- **开关手写（规则/谓词，不训 gate）**——规则原文（同时会原样写进 `REPORT.md`）：

  > **走指针通道，当且仅当** `len(candidates) >= 2` 且**每个候选都是给定输入的独立字符串**
  > （候选身份 = 下标，**不发射锚点**）：`route = "pointer" if isinstance(candidates, (list, tuple)) and len(candidates) >= 2 else ...`
  > **走生成通道，当且仅当** 输入**没有候选列表**、但带**一个可匹配的骨架模板**：
  > `route = "gen" if candidates is None and match_sentence(text) is not None else "reject"`
  > **匹配器不命中 ⇒ fail-closed 拒答**（不落到另一个通道、不训 gate）。
  > 两分支**各自只在自己的样本上算 loss**（另一分支对本样本无输出）。

- **两通道验收分开报**：指标、日志、判据**逐通道**给，**不许合成一个数**。

## 6. 空测试自检（开训前必须打印）

1. 核 `requires_grad` 全 False + `training=False`（**实测打印**），可训参数 = 只有头；
2. 四臂可训参数**逐项**（trunk / ptr_out / gen.skel / gen.assign）；
3. **C 臂共用主干证据**：`named_parameters()` 中 trunk 只出现一次；
   `model.trunk_ptr is model.gen_trunk` → True（D 为 False）；只回传单通道 loss 时主干梯度非零两条独立路径；
4. 多数类 / 盲猜基线（从 `data/stats.json` 读）；
5. 随机标签对照**真执行**（打印 randperm 前后标签计数）；
6. 候选等变性（交换两候选 ⇒ logit 同步交换）与生成特征**袋序不变量**（洗牌不改变骨架输入）。
