# 同核双通道头：指针通道 + 生成通道的干扰与代价（实测）

**唯一问题**：一张卡的头同时带「指针通道 + 生成通道」（共用主干）互扰多少？共用主干比两个完整头省多少参数与前向时间？
判据在 `PREREG.md`（mtime 01:32:40，早于首次训练 01:52），跑后未改。核 1,688,460 全程 `requires_grad=False` + `eval()`，只训头；seed 42/43。

## 1. 四臂结构与参数（实测，`logs/selfcheck.json`）

| 臂 | 结构 | trunk_ptr | trunk_gen | ptr_out | gen_skel | gen_assign | 头可训合计 |
|---|---|---|---|---|---|---|---|
| A | 只指针分支 | 164224 | 0 | 129 | 0 | 0 | **164353** |
| B | 只生成分支 | 0 | 164224 | 0 | 5160 | 16704 | **186088** |
| C | **共享**主干 + 两分支 | 164224 | 164224 | 129 | 5160 | 16704 | **186217** |
| D | 两个完整独立头 | 164224 | 164224 | 129 | 5160 | 16704 | **350441** |

- 主干 `Linear(512→256)+GELU+Linear(256→128)+GELU`=164224；A = 164353 与 `select_rerank` 打分头**逐项相同**（其 test 94.48% ↔ 本实验 A 94.68/94.16%，口径对上）。
- 特征同宽 512：指针 `[ctx;cand;ctx⊙cand;|ctx−cand|]`，生成 `[v_sent;v_bag;v_sent⊙v_bag;|v_sent−v_bag|]`（`v_bag`=槽位 span 向量均值 ⇒ 骨架输入对袋序不变，已断言）。
- 生成输出 = 骨架 `Linear(128→40)` + 指派 `MLP([h;v_item])→64 ⊗ 可学槽位嵌入`（每槽一次 softmax over n 项）；`L_gen = CE_skel + CE_assign`，C/D `loss = L_ptr + L_gen`（λ=1 写死）。
- **冻结实况（实测打印）**：`encoder_params=1688460, encoder_trainable=0, encoder_training=False`；四臂初始化逐位相同（`trunk A==B==C==D.ptr / ptr_out A==C==D / gen B==C==D` 全 True）。
- **C 臂共享证据**：`trunk_ptr is trunk_gen` = **True**（D = False）；`named_parameters()` 里 trunk 只出现 4 个张量（`trunk_ptr.net.*`）；两通道各自单独回传时**同一主干**梯度均非零且互不相同；`C = D − 一个主干` = True。
- **D = A ⊕ B 的对照（实测）**：D 两头的 loss 首/末/均值与指标与 A、B **完全相同**（逐头 clip，无交叉耦合）⇒ C 与 D 的一切差异只可能来自**参数共享**，不是优化噪声。

**开关规则原文（手写谓词，不训 gate；PREREG §5）**：
> 走指针通道当且仅当 `len(candidates) >= 2` 且每个候选都是给定输入的独立字符串（候选身份=下标，不发射锚点）；走生成通道当且仅当**无候选列表**且 `match_sentence(text)` 命中骨架模板；都不满足 ⇒ **fail-closed 拒答**（不落到另一通道、不训 gate）；两分支各自只在自己的样本上算 loss。

## 2. 生成分支数据（实测，`data/stats.json`）

- 语料：`resolve_corpus_files()` 18 文件 → **文件级汉字比 ≥0.6 保留 14**（弃 code_alpaca 0.000 / gsm8k 0.059 / coig_math 0.542 / qwen3_235b 0.511），打乱文件序不依赖顺序；句长 14–44、句级汉字比 ≥0.6；取 50500 句 → 命中 **41596（82.37%）**。
- 骨架表 40 个手写模板（槽位/字面严格交替、虚词字面须被标点或句界锚定、间隙 2–30 字），匹配优先级 = 字面字符数降序→id 升序；**命中 <30 的 8 个骨架剔除**（effective 32，命中它们的 223 句按无匹配丢弃，累计 drop 8904）。
- 规模 **train 8000 / test 2500**，骨架集合完全相同（30 类）、句子重叠 0；majority 0.4169、盲猜 0.025；槽位分布 {1:121,2:4407,3:2309,4:1165}；**截断丢弃 trunc_dropped = 0**。
- **W4 `max_naive(train) = 0.5329 < 0.90 ⇒ 过**（majority .4169 / 长度桶 .4700 / 首字 .4411 / 尾字 .4285 / 标点型 .4531 / 虚词决策表 .4176 / 决策树 d2 .4909 / d4 .5329；test max 0.5208）。

## 4. W1–W5 逐条

**W1 干扰量（Δ = 单通道 − C，配对 SE = sd(d)/√n，同批样本逐条 0/1 之差）**

| 通道 | 指标 | seed42 Δ (SE) | Δ/SE | seed43 Δ (SE) | Δ/SE |
|---|---|---|---|---|---|
| 指针 | test（主指标） | +0.88pt (0.36) | **+2.43** | +0.04pt (0.34) | +0.12 |
| 指针 | adv 合计 | +0.16pt (0.55) | +0.29 | +2.60pt (0.58) | **+4.49** |
| 指针 | shifted_pos | −0.24pt (0.58) | −0.41 | +0.72pt (0.59) | +1.21 |
| 指针 | heldout_pair | +0.56pt (0.94) | +0.59 | +4.48pt (0.99) | **+4.52** |
| 生成 | 骨架（主指标） | +0.72pt (0.51) | +1.41 | −0.04pt (0.50) | −0.08 |
| 生成 | 指派 | +0.05pt (0.12) | +0.43 | +0.04pt (0.10) | +0.45 |
| 生成 | 联合 | +0.36pt (0.52) | +0.70 | +0.20pt (0.50) | +0.40 |

- **生成通道：两 seed 全部 Δ ≤ 2SE（骨架 ≤1.41、指派 ≤0.45）⇒ 无可测干扰**。
- **指针通道：seed42 主指标 +0.88pt = 2.43SE ⇒ 超 W1 门槛；seed43 主指标 +0.04pt（0.12SE）不超**；两 seed Δ 同号（都为正 = 单通道不差于共享），但量级差 20 倍；adv/seed43 出现 4.5SE 的下降而 seed42 无 ⇒ **W1 指针按「两 seed 都 ≤2SE」的字面门槛未过**。

**W2 共用主干的节省（轮转交错计时 n=60、p50、真实前向；噪声地板 = A vs A2 同模型同输入 = 0.0029 ms，同步开销 0.0026 ms；对照：初始权重下 A/C/D 指针前向**逐位相同**、max_abs 差 = 0.0）**

| 量（p50, ms） | A | C | D | C/D | D/A |
|---|---|---|---|---|---|
| 每卡前向合计 | 0.1472 | 0.3849 | 0.3833 | **0.99** | **2.57** |
| 整步 fwd+bwd+opt（含 H2D，与训练同构） | 0.7749 | 1.7224 | 1.7893 | 0.963 | 2.31 |

- 参数：C 186217 vs D 350441 → **省 164224 个 = 46.86%**（恰好一个主干）。
- **前向时间 C/D = 0.99 ⇒ 共享主干几乎不省时间**（两通道输入几何不同 ⇒ 主干各调一次；共享只省参数不省 FLOPs）；**D/A = 2.57 ⇒ 两个完整头不是"接近翻倍"而是 2.6 倍**（生成路径还带指派头，gen/ptr = 1.51）。
- 对账：训练逐步墙钟 p50 A 1.32 / B 2.19 / C 3.15 / D 3.25 ms（warm-skip 50 步）vs 探针（含 H2D）0.77 / — / 1.72 / 1.79 ms，差额 0.54（A）与 1.39–1.43 ms（C/D，两条 DataLoader）= 数据管道与 collate；探针本身不跑数据管道 ⇒ 绝对值以训练逐步为准、臂间比值以交错探针为准（两处 C/D、D/A 比值一致到 5% 内）。

**W3 随机标签对照（真执行，打印 randperm 前后计数）**：指针 `0.5092` vs 盲猜 0.5000（2SE=0.02）⇒ **过**；生成骨架 `0.3780` vs 多数类 0.4169 / 盲猜 0.0250，指派 `0.3357` vs 盲猜 0.4231 / identity 0.4010 ⇒ **两者都塌到平凡基线"以下"，未落在字面 `≈基线 ±2SE` 门槛内（差 3.9pt / 8.7pt）**：无信号（塌幅 26.2pt）但字面门槛未达，如实记为**临界**。

**W4**：`max_naive(train)=0.5329 < 0.90` ⇒ **过**（§2）。**W5 老卡**：pronoun 0.921667→0.921667、sentiment 0.752812→0.752812、relation 0.730556→0.730556、person 0.318333→0.318333，**Δ 全部 = 0.000000**（各自噪声带 2.83/0.41/1.39/0.33 pt，带内），**指标 dict 逐位同、`base_encoder.pt` 与四张卡 sha256 训前=训后** ⇒ **过（预期 0，实测 0）**。
**附加门**：G1 B 骨架 0.6396/0.6424 > max_naive+2SE=0.5529 ⇒ 过；G2 C 三通道均高于盲猜+2SE ⇒ 过。

**判定：证据不足**（PREREG 三选一，不硬选）。理由：① 指针主指标 seed42 = 2.43SE 超门槛、seed43 不超 ⇒ 不满足「可行」的两 seed 都 ≤2SE；② 也不满足「必须分头」（要求同号且 Δ>2SE，seed43 仅 0.12SE）；③ W3 生成对照按字面门槛未达。**方向性结论（2 seed，实测）**：生成通道共享几乎无代价，指针通道共享代价 ≤0.9pt(clean)但不稳定、在 heldout_pair 上单 seed 达 4.5pt。

**机制（推断，非实测）**：C 中指针损失首/末 0.6939/0.0179，A 为 0.6939/0.0011（D 与 A 逐位同）⇒ **共享主干让指针收敛更慢**，与 Δ 为正一致；两通道 loss 量级差约 20 倍（ptr 均值 0.0995 vs gen 1.3033，C 内），且两通道激活分布不同（`[ctx;cand]` vs `[sent;bag]`），共用同一组 512→128 权重时梯度方向相互牵制；生成通道因输入几何不同且自身余量大（骨架 0.64 vs 规则 0.53）而几乎不受影响。

## 6. 遗留与不确定

1. **实测**：W1 指针两 seed 量级不一致（2.43 vs 0.12 SE）、adv 仅 seed43 出现 4.5SE；2 seed 不足以在「可行」与「必须分头」间定论 ⇒ 建议同配方补 seed 44/45 再判（**本次未做，避免事后挑 seed 刷过**）。
2. **实测**：W3 生成随机标签落平凡基线**以下**而非其上，判据字面（≈基线 ±2SE）未满足；其对照意图（不得学到信号）成立 —— 按 PREREG 字面记为临界，未改判据。
3. **口径判断**：`annotation_inverse 0.9994` 不计入 `max_naive`（同 select_rerank 排除同义词表规则）；标签约束于标注函数本身，报告已单列。
4. **实测**：探针不跑数据管道，绝对耗时低于训练逐步（差 0.54–1.43 ms = DataLoader/collate）；臂间比值两处一致。
5. **推断未测**：加私有适配层（每通道一层不共享）预计压住指针侧干扰，参数省幅将从 46.9% 降到约 1–3%；生成分支本实验只到「骨架 id + 槽位指派」，**未测解引用与渲染**（`dev-notes/16` §7.9）。
6. 冒烟跑 `results/*_steps30|60.json` 未进入分析；训练含 `.item()` 逐步同步，已计入逐步墙钟。
