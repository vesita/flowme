## 4. 结论（判据 = PREREG §3，跑前写死）

**① 主判据（方向，§3A）：实际更新由老任务决定 —— 3/3 取值点同时满足，不需硬选。**
`cos(Δθ_both, Δθ_old)` = 0.970/0.996/1.000 **全部 >** `cos(Δθ_both, Δθ_sel)` = 0.046/0.791/0.787；
`rel(both,old)` = 0.242/0.091/0.0095 **全部 <** `rel(both,sel)` = 1.352/0.678/0.622。
抹掉老任务当前梯度，实际更新变 62~135%；抹掉 select 当前梯度，只变 0.95~24%（且单调缩小）。

**② 必须同时报的交叉（§3A 允许的交叉情形）：量级口径是「同量级」，不是「被淹没」。**
`‖Δθ_sel‖/‖Δθ_old‖` = 0.976 / 1.086 / 0.865，`‖m/√v‖` 比值 = 0.973 / 1.085 / 0.865，
reset 口径 0.976 / 0.968 / 0.942 —— 全部 ∈ [0.33, 3]。分歧来源（实测）：
两支进 Adam 前已被 clip 压到同一 2-范数，随后逐坐标归一化把残余量级差也抹掉；
**决定方向的是梯度方向与共享的动量历史，而两者都由老任务主导**（`‖g_old‖/‖g_sel‖` = 534×/74×/283×）。

**③ 「被淹没」能否外推到实际更新 —— 判据 §3B：不能（3/3 点 R ≥ 0.33）。**
原始 2-范数的 500×/74×/283× 差距**不能**外推到 AdamW 的实际更新量级；
能外推的只有"select 对实际更新的**净改变量**小且递减"（0.24 → 0.09 → 0.0095），
但这是**方向/效应**结论，不是量级结论。cos 口径同样不能外推：原始 `cos(g_sel,g_old)≈0`
（−0.015~+0.015）在更新口径下变成 0.78~0.79（共享动量历史所致），仅在无历史的 step1 保持 −0.007。

**④ 对「机制归因 = 中」：维持中**（不升级为强，也不降级）。
- 升级侧（实测）：grad_probe 遗留第 3 项已同构补齐（loss Δ≤4e-7、梯度逐位复现、both 臂与主臂真实步逐位相同、
  5 类自检/控制全过）；且 update 口径显示 **select 并未被压成 1/500，而是以 ~1× 的步长实打实进入核** ——
  "select 信号有能力改变核"这半句比之前更有支撑。
- 不升级侧（实测）：**方向与净效应仍由老任务决定**（§①），且 select 的净贡献随训练衰减；
  grad_probe 的核心张力（"增益由 select 梯度直接驱动核"的朴素读法不成立 + R3 随机标签归零 ⇒ select 必要但极小）
  **本测没有解开**，关键缺口仍是**遗留第 2 项：缺"只让核学 select、不给老任务"那一档**，本测没跑。
- 不降级：本测没有出现与原机制相反的证据（老任务本身不产生增益的 R3 结论未被触碰）。

## 5. 本测的适用边界（必须连着结论读）

**这是"单步、从同一 (θ, 真实优化器状态) 出发"的局部量测，不等于 1800 步轨迹上的累积贡献。**
具体边界：
1. 三个取值点是轨迹上的**局部切片**；200~1800 步之间与 1800 终态**未量**（终态优化器状态未归档，补测需伪造状态，本测不做）。
2. 7 个臂**共享同一份动量历史**：`rel(both,old)` 抹掉的是老任务的**当前**梯度，**不是**它的全部历史；
   动量历史 (m,v) 无法分解成 select/old 两份 —— 因此"由老任务决定"里有一部分来自历史，而历史本身由老任务梯度累积而成（推断）。
3. 没有跑反事实轨迹（"只给 select 训 1800 步"），所以**不能**从本测推出"长期累积位移也由老任务决定"。
4. 单 seed（42）、单配方（clip=1.0 / lr_core=3e-4）；换 clip 或 lr 会改变当前梯度与历史的配比（实测 clip 对照差 92~94%）。
