# DTSeek 任务卡容量与有效秩预算测量实验报告 (Rank Budget)

本目录通过**不改变训练权重、不需要重新训练**的无损静态探针体系，对 DTSeek 当前多任务共享基座（`NanoDocEncoder`, D=128）与已拆分的四张任务卡（`pronoun`, `sentiment`, `relation`, `person`）进行容量和秩利用率体检，回答核心问题：**当前共享基座还能不能再塞任务卡？**

所有实验均已通过 `./run.sh` 固化，支持全自动复现，核心测量汇总至 `results.json`。

---

## 实验概览与判据标准

沿用 `dev-notes/03` 奇异值能量熵口径（Roy & Vetterli）：
- 有效秩：`erank(W) = exp(-Σ p_i ln p_i)`，其中 `p_i = σ_i / Σσ`。
- 满秩利用率：`util = erank / min(M, N)`。
- <30% 视为秩坍缩（冗余假参数），>70% 视为高负荷/吃力。

| 实验编号 | 测量对象 | 核心判据 | 测量结论 | 证据强度 |
| :--- | :--- | :--- | :--- | :--- |
| **E1** | 基座各层动态表征有效秩 | 末层 util < 50% ⇒ 低秩压缩，不可加卡 | 末层 util = **65.8% ~ 65.9%** (未坍缩) | 3 seeds (42, 43, 44) 配对 |
| **E2** | 四任务卡解码头参数有效秩 | util < 30% 浪费，> 70% 吃力 | 80 个矩阵 0 个 < 30%，均值 **89.2%**，97.5% 矩阵 > 70% | 确定性 SVD 权重全量分析 |
| **E3** | 卡片间任务向量子空间冲突 | \|cos\| 显著偏大 ⇒ 共享基座表征互扰抢夺 | sentiment 与 relation cos = **+0.17 ~ +0.23** (显著高于其它对) | 3 seeds (42, 43, 44) 真实梯度 |
| **E4** | 任务路由线性探针可分性上界 | ~99% ⇒ 路由极易，dispatcher 无独立做卡增量 | 4 类 Acc = **98.5% ± 0.4%**，5 类 (加中性池) = **98.7% ± 0.4%** | 3 seeds + 打乱标签/随机特征双负对照 |

## E1. 基座表征是否坍缩

- **问题**：当前 3 层 NanoDocEncoder 在承载 4 张任务卡时，深层表征是否已退化坍缩？
- **测法**：冻结基座，对各卡数据取样本前向，提取 `embedding`、`block_0`、`block_1`、`block_2` 及末层 `output` 的有效 token 隐向量矩阵 `[N_tokens, 128]`，做 SVD 计算每层有效秩 `erank` 与利用率 `util`。
- **判据**：末层 util < 50% ⇒ 严重低秩压缩，此时再加卡只会更挤。
- **实测数字 (3-seed 统计)**：
  - `embedding`：erank 117.54 ± 0.08，util = **91.8%**
  - `block_0`：erank 80.84 ± 0.10，util = **63.2%**
  - `block_1`：erank 75.04 ± 0.09，util = **58.6%**
  - `block_2`：erank 80.04 ± 0.14，util = **62.5%**
  - `output (末层)`：erank 84.27 ± 0.11，util = **65.8% ~ 65.9%**
  - 单任务单看：person 任务末层 util 最低 (53.7%)，sentiment 最高 (69.0%)，全部高于 50% 门槛。
- **结论**：**基座表征未坍缩**。基座在 block_1 经历了约 58.6% 的几何瓶颈后，在 block_2 与最终 Norm 输出端回升至 65.8%（有效维度约 84/128），未触碰 <50% 的压缩红线。
- **证据强度**：多 seed (42, 43, 44) 严格复核，跨 seed 波动 < 0.2 个百分点。

## E2. 每张卡的头部容量占用

- **问题**：拆分出来的 4 张任务卡解码器（`RobustARSliceDecoder`，各 20 个二维权重矩阵，约 63 万参数）是否存在参数冗余或容量吃紧？
- **测法**：使用 `scripts/analyze_card_rank.py`，遍历 `checkpoints/cards/{pronoun,sentiment,relation,person}.pt` 的全部 2D 权重矩阵（包括 cross-attention、self-attention、FFN linear1/linear2、pointer networks 等）并计算有效秩。
- **判据**：util < 30% 视为容量浪费（可剪枝/低秩分解）；util > 70% 说明该层参数展开充分、正在承载较大任务拟合压力。
- **实测数字**：
  - 全部 4 张卡共 80 个矩阵，**0 个矩阵 util < 30%**，0 个矩阵 util < 50%。
  - 全卡矩阵平均 util：person **88.5%**、pronoun **89.5%**、relation **89.3%**、sentiment **89.6%**。
  - util > 70% 的矩阵占比：pronoun 100%、sentiment 100%、relation 100%、person 90.0% (18/20)。
  - 最低 util 出现于指针网络与反馈层：`start_ptr` (68.8%~77.9%) 与 `feedback_proj.3` (78.2%~79.2%)。
- **结论**：**任务卡头部未出现容量冗余浪费，处于高负荷充分展开状态（吃力状态）**。当前每个任务头拥有独立的 63 万参数且已充分舒展，不能进一步盲目共享或缩小头部。
- **证据强度**：确定性 SVD 权重全量分析（无随机性）。

## E3. 卡片间子空间冲突

- **问题**：四张任务卡之间是否存在表征空间争抢？能否解释「sentiment 单卡 1 epoch 达到 85.9%，但四卡联合训 16 epoch 仅 76.6%」的负迁移现象？
- **测法**：对每张卡计算任务梯度向量（该卡任务损失对基座输出 `doc_memory` 的梯度在有效 token 上的全局均值，D=128），计算任务间两两余弦相似度；并提取各任务梯度的 top-16 主成分子空间，计算主夹角（Principal Angles）。
- **判据**：\|cos\| 偏大或主夹角过小 ⇒ 两张卡抢夺同一批基座特征流，联合反向传播时必然产生梯度干扰与震荡。
- **实测数字 (3-seed 统计)**：
  - 任务向量余弦相似度：
    - `sentiment <-> relation`: **+0.1737 ~ +0.2306** (均值 +0.203) —— **全矩阵唯一强正相关对**！
    - `pronoun <-> relation`: -0.0421 ~ -0.0150
    - `pronoun <-> person`: -0.1134 ~ +0.0499
    - `pronoun <-> sentiment`: +0.0061 ~ +0.1212
    - `person <-> sentiment`: -0.0362 ~ -0.0025
    - `person <-> relation`: -0.0450 ~ -0.0210
  - top-16 主夹角最小角度：
    - 所有任务对之间的最小主夹角均在 **41.1° ~ 47.6°** 之间（未完全正交 90°，存在显著子空间交叠）。
- **结论与现象解释**：
  - **精准解释了 sentiment 在四卡联合训练时的退化现象**：sentiment 与 relation 的梯度任务向量呈现出显著的正向共线性（cos ≈ +0.20，其它绝大多数任务对仅在 0 附近振荡）。两者都在争夺语义关系与情感极性词汇的上下文表征；在可训基座联合反向传播时，relation 的强结构监督（词对起止与双切片）持续扭曲基座特征，导致 sentiment 任务被严重拉扯压制，从单卡 85.9% 跌落至 76.6%。
  - `dev-notes/10` 中「冻结基座让 relation 从 82.6% 恢复至 92.9%、sentiment 从 83.2% 恢复至 89.5%」从机制上印证了这一结论：**只要基座被冻结，各头间的梯度拉扯就会物理隔断**。
- **证据强度**：3-seed 采样独立批次复核，cos(sentiment, relation) 的显著正值在所有 seed 下保持一致。

## E4. 路由可分性上界（最关键）

- **问题**：在冻结基座特征上，一段输入文本「属于哪个任务」是否已经线性可分？是否需要专门训练一张复杂的自回归 dispatcher 任务卡？
- **测法**：在冻结基座提取的文本全局表征（mean pooling，D=128）之上，训练标准逻辑回归（无隐藏层、单层线性探针），测试其在任务分类上的泛化能力。
  - 设置 1：4 分类（pronoun, sentiment, relation, person），各 600 条训练、200 条测试（共 800 测试样本）。
  - 设置 2：5 分类（加入中性真实语料背景池 neutral），共 1000 测试样本。
  - **真实独立负对照 1（打乱标签，Shuffled Labels）**：训练集破坏真实对应关系。
  - **真实独立负对照 2（随机高斯特征，Random Features）**：剥离基座语言学语义。
  - *关于 dev-notes/11 的无效对照教训*：本实验未采用正交旋转对照（因为正交矩阵保余弦保距离，逐位恒等）。打乱标签与随机特征能彻底打断自变量，对照测试准确率精确回落至 20%~25%（完全等价于随机猜测），证实了该负对照的真实验证效力。
- **实测数字 (3-seed 统计)**：
  - **4 分类线性探针**：
    - Accuracy: **98.50% ± 0.38%** (98.88%, 98.50%, 98.12%)
    - Macro-F1: **98.50% ± 0.38%**
    - 多数类/盲猜基线: **25.00%**
  - **5 分类线性探针 (+中性背景池)**：
    - Accuracy: **98.73% ± 0.42%** (99.20%, 98.40%, 98.60%)
    - Macro-F1: **98.73% ± 0.42%**
    - 多数类/盲猜基线: **20.00%**
  - **负对照实测**：
    - 打乱标签负对照 Accuracy: **21.96% ± 4.49%** (落在多数类基准 25% 附近)
    - 随机特征负对照 Accuracy: **25.92% ± 1.53%** (落在多数类基准 25% 附近)
- **结论**：
  - 任务路由在线性空间已具有 **~99% 的可分性**！冻结基座的隐表征已经清晰分流了不同任务的句式语体。
  - **判据落地**：根据设定判据（`~99% ⇒ 路由太容易，单独做 dispatcher 卡没有增量`），**完全不需要也不值得单独耗费资源去训练一张自回归 dispatcher 任务卡**！轻量单层分类头或规则过滤即可完美充当调度器。
- **证据强度**：多 seed 独立抽样 + 双重独立有效负对照，证据级别极强。

## 终局结论与判定

> ### **当前共享基座还能不能再塞一张卡？**
> 
> ### **答复：【能，但必须满足一个硬性工程前置条件：必须采用「冻结基座」方式单独加卡，严禁再对共享基座做全参联合训练】。**
> 
> **判定依据的几个核心实测数字：**
> 1. **基座表征利用率余量充足（E1）**：混合多任务末层特征有效秩利用率为 **65.8%**（有效连续秩约 84.3 / 128），未触及 <50% 的压缩坍缩红线，空间仍有 **~34%** 的正交冗余度可容纳新特征投影；
> 2. **头部承载已高度饱和（E2）**：现有四卡解码器 97.5% 的矩阵处于 util > 70% 的高负荷状态（均值 **89.2%**，最低 68.8%），说明任务头不能削减容量，新卡必须自备独立的 Decoder 结构；
> 3. **空间冲突机制已实锤（E3）**：基座输出端已存在强局部冲突（sentiment 与 relation 任务梯度余弦高达 **+0.20**，最小主夹角仅 **41.2°**）。若在 D=128 的小基座上继续引入第 5 张卡进行端到端全参联合更新，必将严重加剧梯度震荡并再次击穿容量墙；而一旦冻结基座，各任务头间完全解耦，即可安全吸纳新卡；
> 4. **路由隔离极度清晰（E4）**：基座语义层间线性探针达到 **98.5% ~ 98.7%** 的超高分类上限（相比 25% 随机对照），证明各任务输入在基座表征空间已有天然区分度，无需额外训练复杂调度卡。
