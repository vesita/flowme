## 4. H0–H5 逐条 + 判定 + 机制

- **H0 过（必报）**：见 §1 —— 参数 +3.39%/+6.77%、步时 +8%/+45%、wall 22.0–28.5 s、显存三臂同 .748 GB；**参数量差 < 10% ⇒ 可比**（来源已列）。
- **H1 不过（主判据）**：B−A、C−A **均为负、2 seed 同号、|Δ| > 2×SE** ⇒ **不是「没测出差异」，是显著更差**。
- **H2 过（带天花板）**：三臂 T_test 全 **1.0000（Δ=0）** ⇒ **未见退化**，没有「拿有真值能力换结构能力」；**但天花板 ⇒ H2 判别力受限，无法排除小幅退化（推断）**。
- **H3 过**：见 §2；**S/keep 地板 1.0000 ≥ 门槛 ⇒ 该出口不可作靶子（如实说明）**。
- **H4 见 §3**：**位置信息确实进了 B/C 的表示**（trig_pos +13.7~17.4pt，2 seed 同号，实测）—— 这是「新核把结构放进表示」的**直接证据**；但结构标签 `skel_id` 三臂线性读出 **.467–.516 < 免费规则 .8316**（**读出不构成增量**），最小对 pair_success 三臂**全部低于成对机会 .5**；**C−A 的 pair_success +.0161/+ .0161 同号为正但 < 2SE ⇒ 未测出（不是「没有效果」）**。
- **H5 过（负向）**：keep 出口 B/C **也显著掉**（−1.4 ~ −3.5pt）⇒ **不是 `select_pool` 那种「+5.6 结构 / −25 表内」的一得一失，而是两个出口同时掉**；train acc 基本持平。
- **M（机制自检，构造性）**：A 打乱后 **pred_agree = 1.0000、Δacc = 0.0000**（断言过 ⇒ A 严格置换不变）；B agree .907/.900（Δacc −.008/−.014）、C .893/.907（−.019/−.010）⇒ **B/C 确实读了顺序，打乱破坏它更差**。
- **机制（推断，2 seed 支持）**：结构通路把**位置**放进了表示，但**靶子不兑现顺序** —— 免费规则 R6 已 .6968、特指疑问类 A **.983** vs B/C **.955**（该类靠疑问词词表），说明「句式·遮蔽标点」由**词汇线索**主导；而 attention pooling 的标量加权和对 token 是**有损压缩**，在词汇主导任务上比 masked mean 丢分。
- **探索性（跑后，非预注册）**：按「R6 是否答对」拆分 —— 规则答错的 1819 行（30.32%）A .5558/.5569、B .5569/.5322、C .5607/.5476（混合）；规则答对的 4181 行 A .9065/.9067 > B .8795/.8852 ≈ C .8795/.8859。按类：**陈述类 B/C 更好**（.635/.672 vs A .611/.638），**特指疑问类 A 更好**。
