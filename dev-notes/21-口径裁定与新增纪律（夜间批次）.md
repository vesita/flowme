# 21. 口径裁定与新增纪律（夜间批次）

> 各实验的**数字在它们自己的 `REPORT.md` 里**。这份只记 **Lead 的口径裁定**与**由此产生的新纪律** —— 避免同一事实两个家。

## 1. 口径裁定（透明修订：**新旧两个数字都留**）

### 裁定 1：`n_slots → train 多数骨架` **并入 `max_naive`**

零训练、零标签即可算出（`seen_rate` 在 test/adv1/adv2 全为 **1.0**）：**test .8316 / adv2 .336**。

| 地板 | test | adv2 |
|---|---|---|
| 旧 8 条朴素规则 | .5329 | .182 |
| **新（含 `n_slots`）** | **.8316** | **.336** |

**后果**：基线 A **test −.1920 / adv2 −.1050（低于地板）**；U 仅 **+.0012/+.0024（test）**、**+.0130/+.0180（adv2）**。
依据：同类先例已有四次（锚定逐字 1.00、价值卡词表 1.00、B 族表内记忆、D4 `lex_member` 0.765），每次都并入。

### 裁定 2：N1「单片段 + 句末。」**并入免费规则基线**

**106/120 = 88.33%**（零骨架表、零自由句法、零学习）。

| 口径 | 覆盖 |
|---|---|
| 仅 Tier-1（闭合骨架表） | 36/120 = **30.0%** |
| **N1（免费规则）** | **106/120 = 88.33%** |
| 两级 | 108/120 = 90.0% |
| **⇒ 两级对 N1 的真实增量** | **+2 句 = +1.7pp** |

⇒ **"+60pp 覆盖率提升"里 58.3pp 由免费规则解释**。但两级的**保证（G1–G4 全 0 违例 + 对抗 14/14）不被免费规则解释**，是真成果。
⇒ **推论（待证）**：两级的真正价值可能是**消歧**（样例：`不。` 有两解 ⇒ 不计分；`不，不。` ⇒ 升序覆盖唯一 ⇒ 歧义被句式消掉），而**不是覆盖**。

### 裁定 3：`bag_modules` 的 F1 **字面成立、实质误导**

F1 统计：U−N = **+.0256~.0350**，4/4 > 2×SE、两 seed 同号 ⇒ 字面判「模块内容有独立贡献」。
但机制：**只打乱"内容"U 仅掉 .0056~.0180** « U−N；**随机标签 4/4 ≥ 真标签**；**只打乱内容 N 的 Δ 严格 = 0**。
⇒ **残差不是内容语义**（推断：旁路容量/优化 —— N 只能表达 4 个不同 logit 向量；非加性 N 未测）。
⇒ **正确表述**：**标签提供了一路容量，但承载增益的不是它的语义内容**；在完备地板下对"选骨架"的**实用价值 ≈ 0**。

### 裁定 4：`core_probe` = **证据不足**（我认同），并点出**构念效度**问题

方向几何（强：近正交 + 3 跑逐位重复）指向**可分离**；联合瓶颈下降（弱：0.2~1.0pt，落在**零共享 sanity ±0.0165 底噪内**，2/6 跨跑变号）指向**轻微竞争**。
**更关键**：`emo` 与 `logic` 的 `max_naive` = **1.0000（构造性满分 —— 标签本身由词表定义）** ⇒ 这两个任务的 probe 低于它，**什么都说明不了**。

## 6. 追加更正（来自 `label_construct_validity`，均**改动了既有结论**）

### 更正 A：`core_probe` 的 **`logic` 整列作废**

它的"标签"在加载时用 `LOGIC_WORDS`（19 词）**现算** —— `two_channel_head/data/train.jsonl` 里**根本没有该键**
⇒ **构念不存在** ⇒ 82.36% 与 `rule=1.0` **都无信息**。
**不是"低于免费规则"，是"没有这个任务"。**

### 更正 B：`core_probe` 的 `emo` **78.64% 不是新文本水平**

| 子集 | n | probe | 免费规则 | 真实余量 |
|---|---|---|---|---|
| 同文（test 文本在 train 出现过）| 1108 | 98.74% | **.9025**（多数类 class0）| **仅 +8.5pt** |
| **新文本** | 2892 | **71.44/71.61** | **0.0**（该子集**没有 class0**）⇒ 3 类 maj **33.5%** | **+38pt** |

⇒ **新文本应读 71.5±0.8%**（不是 78.64%）。
⇒ **但致命**：**class0（中性）1000/1000 = 100% 泄漏** ⇒ **中性类的新文本泛化完全没测到** ⇒ **不能说"四类都能泛化"**。

### 更正 C：`rule < 1.0` **必要但不充分**

反例：`person-id` 的 `rule = .3750`，但那是该代理**自实现的扫描器**，与生成器**不同源**
⇒ **不构成"来源独立"**。
⇒ 判"可用标签"须**同时**满足：**`rule < 1 − 2×SE`** 与 **来源独立于该规则**。

## 8. 反事实解释的实测（`counterfactual`）：**真实但不特异**

- **判定**：真实但不特异（C1 两模式 Δ ≤ 2SE **且同为负** ⇒ 如实写"不特异"）。
- **决定性数字**（我已从 `results/summary.json` 核过）：
  | 对照 | 改结论的概率 |
  |---|---|
  | 结构化扰动（换功能词/槽序/否定/数量）| **.5413** |
  | **随机换字符** | **.6446** ⇒ **Δ = −.1033（t = −3.33）** |
  | 随机换词 | .5744 ⇒ Δ = −.0331（t = −1.05）|
  **最小扰动大小中位 = 1 个 lev**（合计 p25=1 / p50=1 / p75=2 / max=22）。
- **合起来的表述（今晚最强的一次）**：
  > **最小对**（结构化、只差功能词）⇒ 模型 **79~85% 不变**（`skeleton_leak`）；
  > **随机字符扰动** ⇒ **64.5% 改结论**；
  > **结构化扰动**（54.1%）**反而低于随机**。
  > ⇒ **模型对「有意义的结构差异」不如对「无意义的表层噪声」敏感 ⇒ 它读的是表层，不是结构。**

## 9. 纪律 D7：**验证步骤必须与搜索用不同机制**

`counterfactual` 的 C0（验证失败率）报 **0/131**，看似"反事实 100% 真实"。
**但那是构造性必然**：搜索的定义就是"**找到第一个使输出改变的扰动**"，而模型**确定性（C3 不一致 = 0）**
⇒ **验证必然通过** ⇒ **C0 无信息量**。（我在规格里把它设计成了必然通过的一步 —— 我的错。）

⇒ **判据必须用与搜索不同机制的独立证据**（独立进程/不同实现/不同 seed/不同数据）。
⇒ **同类空测试今晚出现三次**：弱版"零幻觉"（逐字子串）、`n_slots` 旁路（随机标签 ≥ 真标签）、C0 恒真。
