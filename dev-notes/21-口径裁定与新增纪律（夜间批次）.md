## 1. 口径裁定（透明修订：**新旧两个数字都留**）

### 裁定 1：`n_slots → train 多数骨架` **并入 `max_naive`**

零训练、零标签即可算出（`seen_rate` 在 test/adv1/adv2 全为 **1.0**）：**test .8316 / adv2 .336**。

| 地板 | test | adv2 |
|---|---|---|
| 旧 8 条朴素规则 | .5329 | .182 |
| **新（含 `n_slots`）** | **.8316** | **.336** |

**后果**：基线 A **test −.1920 / adv2 −.1050（低于地板）**；U 仅 **+.0012/+.0024（test）**、**+.0130/+.0180（adv2）**。
依据：同类先例已有四次（锚定逐字 1.00、价值卡词表 1.00、B 族表内记忆、D4 `lex_member` 0.765），每次都并入。

### 裁定 2：N1「单片段 + 句末。」**并入免费规则基线**

**106/120 = 88.33%**（零骨架表、零自由句法、零学习）。

| 口径 | 覆盖 |
|---|---|
| 仅 Tier-1（闭合骨架表） | 36/120 = **30.0%** |
| **N1（免费规则）** | **106/120 = 88.33%** |
| 两级 | 108/120 = 90.0% |
| **⇒ 两级对 N1 的真实增量** | **+2 句 = +1.7pp** |

⇒ **"+60pp 覆盖率提升"里 58.3pp 由免费规则解释**。但两级的**保证（G1–G4 全 0 违例 + 对抗 14/14）不被免费规则解释**，是真成果。
⇒ **推论（待证）**：两级的真正价值可能是**消歧**（样例：`不。` 有两解 ⇒ 不计分；`不，不。` ⇒ 升序覆盖唯一 ⇒ 歧义被句式消掉），而**不是覆盖**。

### 裁定 3：`bag_modules` 的 F1 **字面成立、实质误导**

F1 统计：U−N = **+.0256~.0350**，4/4 > 2×SE、两 seed 同号 ⇒ 字面判「模块内容有独立贡献」。
但机制：**只打乱"内容"U 仅掉 .0056~.0180** « U−N；**随机标签 4/4 ≥ 真标签**；**只打乱内容 N 的 Δ 严格 = 0**。
⇒ **残差不是内容语义**（推断：旁路容量/优化 —— N 只能表达 4 个不同 logit 向量；非加性 N 未测）。
⇒ **正确表述**：**标签提供了一路容量，但承载增益的不是它的语义内容**；在完备地板下对"选骨架"的**实用价值 ≈ 0**。

### 裁定 4：`core_probe` = **证据不足**（我认同），并点出**构念效度**问题

方向几何（强：近正交 + 3 跑逐位重复）指向**可分离**；联合瓶颈下降（弱：0.2~1.0pt，落在**零共享 sanity ±0.0165 底噪内**，2/6 跨跑变号）指向**轻微竞争**。
**更关键**：`emo` 与 `logic` 的 `max_naive` = **1.0000（构造性满分 —— 标签本身由词表定义）** ⇒ 这两个任务的 probe 低于它，**什么都说明不了**。

## 2. 新增纪律

| # | 纪律 | 实测依据 |
|---|---|---|
| **D1** | **取卡必须验基座** | **两次独立实例**：`ctrl_idiom_s42.pt` 的 `doc_encoder` 与默认基座 **max\|Δ\|=0.0438**（换基座后 40 句里 **18 句锚点变**）；`e5c` 卡的 `doc_encoder` 与线上 `base_encoder.pt` **26/26 张量全不同**（对账 0.4414 vs 期望 0.9321）。**加载任何卡前比 sha256 / 逐张量对齐** |
| **D2** | **免费规则地板必须含"计数类"特征** | `n_slots` 使地板被低估 **test +.2987**；此前无人想到"数个数"是一条规则 |
| **D3** | **门槛不可达 ≠ 测量坏** | 合成对照 0.99 在 `d=128, n=4000` 下受 **√(p/n)** 下限约束（实测 .977/.978 FAIL）；正确处置 = **不改门槛 + 加测口径（n=20000 → .9966）+ 明示偏离** |
| **D4** | **构念效度先于能力结论** | 标签若由词表定义（emo/logic），`rule=1.0` ⇒ probe 低于它**无信息**。要测能力，**先有非构造性标签** |
| **D5** | **禁止计数泄露** | `n_slots` 泄露使基线 A **低于地板**（−.1920/−.1050）⇒ 任何"选型/选骨架"类任务都**必须报 `n_slots→多数` 的 acc** |
| **D6** | **探跑不得当结论** | 我犯过：拿 30 步快照报 "−5.4pt"，满长跑是 **+0.88pt/+0.04pt** |
