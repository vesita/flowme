# 模因判定特征体系（可算的诊断指标）

> 「模因」= `[n,d]` 张量，卡间唯一通信载体；卡内形状保持 `[n,d]→[n,d]`。
> 本文件把零散读数组织成**特征清单 + 关系 + 决策树 + 成本 + 陷阱 + 缺口**。
> **纪律**：**§1 中标"实测"的数字均引自仓内文件**（出处已写）；**其余为推断或未测**。

## §1 特征清单

> 写法：**【特征名】** 对象 ｜ 定义 ｜ 怎么算 ｜ 诊断什么 ｜ 已知实测值 ｜ **证据强度/独立 n** ｜ ★陷阱

**【F1 PR 有效维度】** 模因整张（池化后 `[K,d]`，K=样本数）
- 定义：`PR = (Σλᵢ)² / Σλᵢ²`，λᵢ 为奇异值（等价于方差谱的参与比）
- 怎么算：**零训练**，取模因 → PCA/SVD → 一步算完；成本 秒级
- 诊断什么：表示实际用了几个自由度（是否被压缩成低维流形）
- 实测：**池化后 3–5**（d=128，5 桶 ckpt；`logs/26_full.log`）
- 证据强度/独立 n：**n=18**（S30 去重后 `ρ(PR,EM)=+0.5748, p=0.0126`；**由桶身份驱动、无双 seed 配对**）
- ★ 陷阱：**池化会掩盖结构** ⇒ 必须同时看 **F2 逐位置 PR**

**【F2 逐位置 PR】** 逐位置
- 定义：对每个位置 `i` 取其 `[K,d]` 子矩阵算 PR，再对 i 取均值与分布
- 怎么算：零训练；秒级
- 诊断什么：**低维是"整体压缩"还是"少数位置承载"**
- 实测：未测（**缺口**）
- 证据强度/独立 n：**未测**
- ★ 陷阱：位置数 `n` 随样本变化 ⇒ 需按相对位置或分桶

**【F3 谱熵】** 模因整张
- 定义：`H = −Σ pᵢ log pᵢ`，`pᵢ = λᵢ/Σλ`
- 怎么算：零训练；秒级
- 诊断什么：能量分布的平坦度（与 F1 同族）
- 实测：未测
- 证据强度/独立 n：**未测**（且与 F1 同源 ⇒ 不独立）
- ★ 陷阱：**与 F1 高度相关，不可当独立证据**（`manifold_enhancement.md` §2.5）

**【F4 集中度（前 20% 因果占比）】** 逐位置 + 逐维度块
- 定义：单元 = 模因的位置与 16 维块；对每单元做**非破坏性单点清零**，测 `|Δ数字每步正确率|`；
  按 Δ 降序，取前 `max(1, round(0.2N))` 个单元的 Δ 之和 ÷ 全部 Δ 之和
- 怎么算：**需干预**（前向多次）+ 多个单元；**零训练**；21 号脚本口径（`stages/21_info_causal_curve.py`）
- 诊断什么：**有效计算是否集中在少数单元**（信息是否因果可用）
- 实测：**合并池 50.7%**；add_3d 44.4/49.6%；add_1d 66.6%（`logs/21_info_causal_curve.log`）
- 证据强度/独立 n：**n=18**（S30/E4：`ρ(集中度,EM)=−0.0464, p=0.85` ⇒ **与能力无关、已降级**）；S22-A 前20% n=2（`logs/33_report.txt:22`）
- ★ 陷阱：**EM≈0 时集中度是噪声底**（S22 实测：B/C/D/E 臂 EM≤1.25% 时的集中度不可与 A 同口径比较）

**【F5 局部可读性 vs 局部因果的 ρ】** 逐位置/逐块
- 定义：`ρ(局部探针准度, |局部因果效应|)`（Spearman）
- 怎么算：零训练 + 干预；需探针训练（可小）；分钟级
- 诊断什么：**"读出≠会用"**（信息是否因果可用）
- 实测：**0.316（n=255, p=0.0000）**；同 ckpt 内可读性 98.5%→0.013pp vs 69.2%→65.20pp（`logs/18_finegrained.log`）
- 证据强度/独立 n：**单 ckpt（n=255 点）** ⇒ 非多 ckpt 独立证据
- ★ 陷阱：**破坏性干预下 |Δ|≈基线成绩** ⇒ 该 ρ 会退化成"探针 vs 模型好坏"（S17：0.28→0.74）

**【F6 门 B（恒等中介 Δ）】** 整卡
- 定义：把目标卡换成 `Identity` 并**重训** ⇒ 报配对 `ΔEM`（R16 口径）
- 怎么算：**需训练**（重训一臂）；GPU；分钟级
- 诊断什么：**该卡是否必要**（是否承载全部计算）
- 实测：S22 A 臂 **ΔEM=+37.25/+31.13pp**（Identity ⇒ EM=0）；S16 推理期恒等 add_1d −43.62pp
- 证据强度/独立 n：**强**（S22 五臂 n=10；E4 `logs/33_report.txt:14`）
- ★ 陷阱：**推理期替换 ≠ 重训替换**（前者只测"即时依赖"，后者测"必要性"；R16）

**【F7 跨形式相似度】** 跨样本
- 定义：同内容、不同表面形式（模板/措辞/排版/语言）的模因相似度 − 随机配对相似度（配对 Δ±SE）
- 怎么算：零训练；秒级；**必须配正控**（同形式不同内容）
- 诊断什么：模因是否承载"内容"而非"表面形式"
- 实测：tpl **Δ=+0.0762±0.0017（45×SE）**、lang +0.0524、spc +0.0762；正控区分度 **4.0–9.9×**（`logs/26_results.json`）
- 证据强度/独立 n：**S26：3 ckpt × 3 族（9 行 = 3×3 计数，非 9 份独立证据）**
- ★ 陷阱：**正控不过则度量无区分度 ⇒ 判决作废**（R29 精神）

**【F8 跨任务 CKA（跨桶一致性）】** 跨任务
- 定义：不同任务桶的 ckpt 产出的模因矩阵之间的线性核 CKA
- 怎么算：零训练；秒级；需 ≥2 个桶的 ckpt
- 诊断什么：是否存在**共同坐标系**
- 实测：对角 0.798 vs 非对角 0.647±0.014（严格同数字）/ 0.443±0.030（尺度归一）（S29）
- 证据强度/独立 n：**S29 原产物在 `/tmp`（未入库，R32）⇒ 不可从仓库复现**
- ★ 陷阱：**必须与随机行置换对照**（对照本身就有 0.04–0.07）

**【F9 线性可对齐性】** 跨 ckpt
- 定义：在 train 半区拟合线性映射 `W`，在 test 半区算余弦 `(iii)`；与原始 `(i)`、去均值 `(i')` 并列
- 怎么算：零训练；秒级；需成对样本
- 诊断什么：两者是否在**同一线性子空间**（差异是否只是可线性吸收的重参数化）
- 实测：跨桶 **0.130 → 0.799**（II-S）/ 0.133 → 0.481（II-N）；**同桶换 seed 也要过 W**（去均值 cos≈0.02）
- 证据强度/独立 n：**S29 原产物在 `/tmp`（未入库，R32）**
- ★ 陷阱：**W 必须用配对样本拟合**（用随机配对拟合时增益只剩 +0.011~+0.048）

**【F10 公共分量占比（原始 − 去均值余弦）】** 跨样本/跨 ckpt
- 定义：`(i) − (i')`，或等价地"所有样本对的平均余弦"
- 怎么算：零训练；秒级
- 诊断什么：模因里有多少是**与内容无关的巨大公共均值方向**
- 实测：随机配对 cos **0.77–0.94**（S29）⇒ 原始余弦**几乎全被公共分量占据**
- 证据强度/独立 n：**S29 原产物在 `/tmp`（未入库，R32）**
- ★ 陷阱：**直接用原始余弦比较模因=错**（会把跨桶误判成比同桶跨 seed 还相似）

**【F11 逐位置方差 / 变异能量位置集中度】** 逐位置
- 定义：各位置在样本间的方差分布；`前 20% 位置的方差占比`
- 怎么算：零训练；秒级
- 诊断什么：**换形式/换内容主要改动哪些位置**
- 实测：方差<10%max 的位置占 28–36%；spc 前 20% 位置占 51–60%（峰在算子/数字附近）；tpl 从尾对齐 34–44%（S26）
- 证据强度/独立 n：**未定价**（S26；与 F4 的数值呼应未做相关分析）
- ★ 陷阱：恒定前缀（如「题干：」）会贡献零方差 ⇒ 需先剔

**【F12 模因 RMS / 范数 / 尺度】** 模因整张
- 定义：逐样本 RMS `sqrt(mean h²)`、总范数
- 怎么算：零训练；毫秒级
- 诊断什么：**尺度是否稳定**（跨 ckpt/跨任务可比性前提）；也用于判断干预幅度是否可忽略
- 实测：RMS≈4.19（S26）；加噪 σ=0.1 仅占 RMS 的 **2%** ⇒ Δ≈0 是真结果（S16）
- 证据强度/独立 n：**未定价**（S26/S16 单点实测）
- ★ 陷阱：尺度差异会让**点积/欧氏距离跨 ckpt 不可比**（余弦/归一化后再比）

**【F13 位置间互信息（新增）】** 逐位置对
- 定义：对模因位置 `(i,j)` 的向量做互信息/相关估计（如线性 CKA 或 kNN MI），得 `n×n` 矩阵
- 怎么算：零训练；秒–分钟级（需 K 够大）
- 诊断什么：**信息在位置上是否冗余**（高度冗余 ⇒ 位置未被分工）
- 实测：**未测（新提）**
- 证据强度/独立 n：**未测**
- ★ 陷阱：K 小则估计偏差大（<100 不稳）

**【F14 对齐矩阵 W 的奇异值谱（新增）】** 跨 ckpt
- 定义：对 F9 的 `W` 做 SVD，看奇异值衰减（有效秩、条件数）
- 怎么算：零训练；秒级
- 诊断什么：**两个模因坐标系之间的"重参数化有多贵"**（谱平 ⇒ 只是旋转；谱陡 ⇒ 有真实信息损失）
- 实测：**未测（新提）**
- 证据强度/独立 n：**未测**
- ★ 陷阱：W 依赖拟合样本量与正则强度，需与随机基线 W 对照

**【F15 模因的 batch 一致性（新增）】** 同一输入
- 定义：同一 prompt 在 `batch=1` 与 `batch=N` 下的模因 `max|Δ|`（相对 RMS）
- 怎么算：零训练；秒级
- 诊断什么：**前向是否有批内泄漏/归约序敏感**（是 R28 在"模因层"的推广）
- 实测：**5.2e-6 ~ 6.7e-6**（相对 1.2e-6，浮点归约序；S26/S29）；同 prompt 两次前向 **max|Δ|=0（精确）**
- 证据强度/独立 n：**未定价**（S26/S29；S29 原产物在 /tmp）
- ★ 陷阱：**生成口径的 batch 依赖远大于模因口径**（生成 EM 差 8 倍，见 §5-P1）

**【F16 逐样本熵 / 稀疏度（新增）】** 逐样本
- 定义：对每个样本的模因向量做 softmax 或归一化后算熵 / Gini / top-k 能量占比
- 怎么算：零训练；秒级
- 诊断什么：**单个样本是否只激活少数维度**（与 F1/F3 的"总体"视角互补）
- 实测：**未测（新提）**
- 证据强度/独立 n：**未测**
- ★ 陷阱：熵对尺度敏感 ⇒ 必须先归一化

## §2 特征之间的关系

**同源组（可能只留一个）**
- **G1 {F1 PR, F3 谱熵, F16 稀疏度}** —— 都在量"能量/自由度的集中度"；谱熵与 PR 已知高度相关（调研结论）
- **G2 {F4 集中度, F5 ρ, F11 位置集中度}** —— 都在量"不均匀性"；S21 与 S26 的数值呼应（50.7% ↔ 51–60% ↔ 41.5%）
- **G3 {F9 线性可对齐性, F10 公共分量}** —— 同一现象的两面（"有公共方向"↔"必须映射才能对齐"）
- **★ G1 与 G2【不合并】（S30/E4 已判，2026-10-08）**：`ρ(F1 PR, F4 集中度) = −0.1352`（**n=18, p=0.59**）
  ⇒ `|ρ| < 0.3` ⇒ 两者**独立** ⇒ 决策树里必须**分别检查**（依据 `logs/33_rho.json` n18_dedup）。

**★ 能力定价（S30/E4，n=18 去重；`logs/33_rho.json` · 提交 `f49a069`）**
- **F4 集中度【降级】**：`ρ(集中度, EM) = −0.0464`（**n=18, p=0.85**）⇒ **与能力无关**，
  **不能当"好不好"的判据**（n=23 那份 `+0.0907` 是重复计数，勿引用）。
- **F1 PR【保留为容量指标】**：`ρ(PR, EM) = +0.5748`（**n=18, p=0.0126**）⇒ 保留；
  但**注明"由桶身份驱动、无双 seed 配对"** —— 不可读成容量轴的单变量因果。

**互补组（必须一起看）**
- **{F1, F2}**：总体低维 vs 逐位置低维（池化会掩盖结构）
- **{F6 门 B, F4 集中度}**：门 B 说"卡整体必要"，集中度说"卡内不均" —— **两者都必要但不互相替代**
- **{F7 跨形式, F8 跨任务}**：前者测"同任务内的内容不变性"，后者测"跨任务的坐标系一致性"

**必须配对读（否则误判）**
- **{F4 集中度, 能力 EM}**：**EM≈0 时 F4 是噪声**（必须先过能力底线）；★ 且 n=18 上 `ρ(集中度,EM)=−0.0464`（p=0.85）⇒ **F4 已降级、与能力无关**（见上"能力定价"）
- **{F10 公共分量, F7/F8/F9}**：**不看 F10 就用原始余弦 ⇒ 结论会反**
- **{F1 PR, 任务难度}**：PR 低可能是"任务简单不需要高维"或"接口容量不足" —— **单独看无法区分**

## §3 诊断决策树（评估新卡内结构 / 新接口卡）

```
第 0 步（先决条件，不过就停）看【能力】EM / 数字每步
   阈值：EM ≥ 同任务地板 + 2SE 且 2 seed 同号；数字每步 > 随机基线（如 14%）
   依据：S22（EM≤1.25% 的臂，其后续特征全部不可读）
   不通过 ⇒ 停：先修能力，任何模因特征都别读

第 1 步 看【F12 RMS】+【F15 batch 一致性】
   阈值：RMS 稳定（同量级）；batch 一致性 max|Δ|/RMS ≲ 1e-5；同 prompt 两次前向 Δ=0
   依据：S26/S29 实测 5.2e-6~6.7e-6
   不通过 ⇒ 停：前向/归约有问题（仪器层），先修仪器（R28）

第 2 步 看【干预有效性（R29 非零冒烟）】
   阈值：单点清零的 Δ 非零比例 ≥ 90%；**互换两行必须被判"无效轴剔除"**（|Δlogits|≈2–6e-6）
   依据：S18/S21/S22 实测（互换轴非零 0%）
   不通过 ⇒ 该干预口径作废，换口径（不是"效应为 0"）

第 3 步 看【F6 门 B（重训-替换）】
   阈值：ΔEM ≥ 2SE；若 Δ≈0 ⇒ 该卡"可整块移除"（冗余/装饰）
   依据：S22 A 臂 +37.25pp；S16 推理期恒等仅 −2.38pp（口径不同）
   不通过 ⇒ 该卡不是必要模块 ⇒ 回到设计

第 4 步 看【F1 PR + F2 逐位置 PR】
   阈值：**暂定** —— 若目标卡参数占比很低（如 7.9%）而 PR 只有 3–5 ⇒ 疑"容量不足"
   依据：S26 PR 3–5（实测）；"低 PR 的含义"未定（见 §6）
   不通过 ⇒ 考虑扩容目标卡（层/ff），**不是**加 d

第 5 步 看【F4 集中度】+【F5 ρ（读出≠会用）】
   阈值：F4 暂定 ≤30%（当前 41–51% 视为偏集中）；F5 ρ < 0.5 视为"读出≠会用"成立
   依据：S21 实测 50.7% / ρ=0.316（n=255）
   注意：F4 的"能力定价"已降级（n=18 上与 EM 无关，见 §2）⇒ 只作辅助诊断、不作"好不好"判据
   不通过 ⇒ 有效计算过度集中 ⇒ 优先打通通路（残差/绑定），而非加资源（S13 已否容量）

第 6 步 看【F7 跨形式 + 其正控】与【F9/F10（跨 ckpt/跨任务）】
   阈值：跨形式 Δ ≥ 2SE 且正控区分度 ≥ 3×；跨任务须先估 W，且 (iii) 明显高于 (i)
   依据：S26（4.0–9.9×）· S29（0.130→0.799）
   不通过 ⇒ 模因不可跨用 ⇒ 该卡只能服务单一任务（限制可组合性）

最终判定
  好：0–6 步全过 ｜ 可改进：能力过但 F1/F4 显示容量或集中度问题 ｜ 坏：第 0/1/2 步不过
```

## §5 已知陷阱汇总（每条含怎么避免）

- **P1 `batch=N` 使生成 EM 差 8 倍**（0.27% vs 2.17%）⇒ **生成/EM 一律用 `batch=1`（R28）**
- **P2 破坏性干预下 |Δ| ≈ 基线成绩**（差 ≤0.01pp）⇒ 该 ρ 变成"探针 vs 模型好坏" ⇒ **用非破坏性单点干预**
- **P3 互换两行模因是无效轴**（|Δlogits| 2–6e-6，自注意力对行置换代数严格不变）⇒ **先做非零性冒烟并剔除该轴（R29）**
- **P4 原始余弦被巨大公共均值分量吃掉**（随机配对 cos 0.77–0.94）⇒ **必须用去均值余弦或 CKA**
