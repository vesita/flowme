## §2 判别性实验（5 条；每条都能一次分开一个分歧）

### E1 ★A 的 P0：单体 2.5M vs 三类卡闭环（防欠训版）
- **分歧点**：卡片化到底有没有增量（A 的 P0/B3/B8 vs B 方案 8）。
- **设计**：任务 add_3d（泄漏 2.0%，唯一干净桶）+ add_1d（100% 泄漏，作阴性对照）；臂 = (a) 三类卡闭环 e2e、res=on、k=1；(b) 单体 decoder-only，d=128、ff=512、层数调到总参数 **2.50M 对齐**（2 层左右），**同词表、同生成器 seed、同训练 seed**；步数阶梯 **{3000, 6000, 12000} × seed{1234,5678}**；评估一律 batch=1、**SEEN/UNSEEN 分开报 EM**。两任务共 24 run。
- **判据（写死）**：只在**每个任务自己的最大步数**上判，且先验证两条 EM 曲线已平（相邻两档 |Δ|≤1SE，防 S25/S28 的欠训基线）：|ΔEM| ≤ 1SE 且 2 seed 同号 ⇒ **卡片化零增量（B 对）**；闭环 Δ ≥ 2SE 且 2 seed 同号 ⇒ **卡片化有增量（A 对）**。
- **成本**：add_3d ≈ 17.4min/seed ⇒ 35min；两任务 ≈ **70min**。
- **若双方都错**：若 12000 步两条曲线都没平，或双方都停在机会水平 0.2% ⇒ 该任务族在 2.5M/12000 步尺度上不可学，瓶颈是任务与优化；此时应换任务，而不是再加对照。

### E2 分开「B2：PE/迭代是同一个决定算子」与「A：PE/迭代不重要」
- **分歧点**：S20 的 −34.9pp 到底是「sin-PE 的绝对位置语义有害」还是「任何加在思维卡输入上的身份信号都有害」。
- **设计**：add_3d、res=on；PE 三态 = `sin_pe`（现状）/ `learned row-embedding`（可学习行嵌入，无绝对位置语义）/ `none`；k ∈ {1,2,4}；每格 2 seed、3000 步 = **18 run**。
- **判据**：① learned 与 sin 在 k=1 都崩到 ≈2%（Δ vs none ≥2SE、方向为负）⇒ 「别碰 PE」对，B 的行序机制解释错；② learned 在 k=1 保住 ~37% 而 sin 崩 ⇒ 有害的是 sin 的绝对位置语义，B 对、A 的优先级排序错；③ k=4 一律用**双侧判据**（|Δ|≥2SE 即算有效应、方向照报），修掉 S15 的单侧门槛。
- **成本**：18 run × ~2.7min ≈ **49min**。
- **若双方都错**：若 PE 三态都崩、learned 与 sin 无差 ⇒ 崩因不在位置语义，转去查共享权重下的梯度尺度/激活尺度，而不是继续改架构。

### E3 验证 A5（PR 是容量指标）与 A3（公共线性子空间）
- **分歧点**：PR/CKA 是在测能力与共享结构，还是在测桶身份 + 同一样本上拟合的自由度。
- **设计**：(A5) 固定 add_3d，人为造容量梯度 d ∈ {64,128,256}（其余不动）× 2 seed × 3000 步 = 6 run，在**同任务内**算 ρ(PR,UNSEEN_EM) 与 ρ(conc,UNSEEN_EM)。(A3，零训练) 取 /tmp/s29 的 K=128 提示集，把 W 的拟合/评估做 **5 折交叉**（现脚本 `stages/29_cross_task_meme.py:123-124` 已有 train/test 与 derangement），并加「桶标签置换」零分布，报折间 SE。
- **判据**：同任务内 ρ(PR,EM) ≥ +0.6 且 p<0.05 ⇒ A5 对；|ρ| ≤ 0.3 ⇒ 跨桶 ρ 只是桶身份。5 折后 (iii) 对角−非对角 Δ 仍 ≥2SE ⇒ A3 对；消失 ⇒ 是 W 过拟合。
- **成本**：6 run ≈ **16min**（d=64/256 墙钟需实测）+ CPU ~5min。
- **若双方都错**：若 PR 同任务内无关、且 (iii) 交叉验证后 Δ 消失 ⇒ 项目的「表示度量」不承载能力信息，应停用 PR/CKA 系列、只报 EM。

### E4 ★廉价检查：W2「共用训练」到底高估了多少证据
- **分歧点**：A 承认 W2 但没量化；B 说三条「独立实验」是同一次训练。折扣有多大？
- **设计**：零训练、只读。① 对每个被当作「独立证据」的 ckpt 做**参数级**比对（文件 sha256 + `max|Δθ|`），不要用文件 sha；② 把每条结论的证据单元按 (生成器 seed, 训练 seed, 步数, 结构) 去重，重算「独立证据数」；③ S30 这类 23 点相关分析改用去重后 n=18 重算（我已做：ρ(PR,EM) +0.562→**+0.575**、ρ(conc,EM) +0.091→**−0.046**）。
- **判据**：去重后某结论独立证据数 ≤1 ⇒ 它只有「复算」没有「复现」（S28_eval 的「复核通过」正是此类）；去重后 n 23→18 若使 ρ 的 p 由 0.005 掉到 >0.05 ⇒ A5 的显著性不成立。
- **成本**：**<3min**（I/O）。
- **若双方都错**：若去重后每条结论的证据数都 ≥2（不同数据 seed）⇒ W2 被夸大，此前的「多实验互证」是真互证。

### E5 ★补 S28 缺的那一格：frozen@6000 vs e2e@6000（我把它排最前）
- **分歧点**：A8（单卡训练>端到端不成立）与 B⑦（瓶颈是算力还是对照硬度）。
- **设计**：add_3d，臂2(frozen) **从 0 训 6000 步**（S28 只训到 3000）× seed{1234,5678} = 2 run；对照是已存在并被 S31 复评的 `28_ckpt_e2e6000`（85.62/74.38%，`31_seen_unseen.log:92-93`）。等步数、同数据、同 seed，评估 batch=1。
- **判据**：Δ=frozen−e2e：Δ ≥ 2SE 且 2 seed 同号 ⇒「单卡训练>端到端」在等算力下成立、**A8 被推翻**；|Δ| ≤ 1SE 同号 ⇒ 两法在饱和点等价、M2 主张不能外推；e2e 显著更好 ⇒ A8 成立且 **B⑦「训练量不是瓶颈」被证伪**。
- **成本**：2 run × ~5min = **10–12min**。
- **若双方都错**：若两者都到 85%+ 且相等 ⇒「哪种训练方式」是伪问题，价值全在「训够 + 无泄漏」，项目叙事应从「闭环 vs 单卡」转向预算与泄漏控制。

**Top-3 理由**
1. **E4 最便宜且是元证据**：它不改任何模型，只重定价已经被引用的结论；如果不先做，E1–E3 的结论会被同一批重复权重污染（n=23→18 已经把 A5 的 ρ(conc,EM) 从 +0.091 翻到 −0.046）。
2. **E5 是「一边数字已存在、只缺另一格」的 12 分钟判决**：它一次分开 A8 的措辞错误与 B⑦ 的算力论断，且直接决定 M2 里程碑是否还站得住——性价比高于任何新架构实验。
3. **E1 是框架层面唯一的干净证伪**，但它比前两条贵 6 倍，且必须在 E4 确认对照权重不重复之后才有意义；A 把它放 P0 方向对、次序错。

## §4 双方都漏掉的（4 条，都有依据）

**M1 所有「最佳步」都是测试集选出来的。** `logs/28_train.log:41`「臂2 seed=1234 训练末 EM=80.38% **最佳 EM=80.38%@step3000**」——代码每 750 步在同一个 800 条 test 上评一次并取最大；`logs/28_train.log:24/27/30/33` 同理。缺 dev 集，S25/S28/S31 报出的 EM 都可能是 test-selected。A、B 都没把这当协议问题。

**M2 每个桶自己的地板从未进判据。** `logs/31_seen_unseen.log:7-11` 给出机会水平：add_1d **27.5%** / sub_2d 5.6% / add_2d 2.8% / mul_2d 1.1% / add_3d 0.2%；而全项目判据仍在用 S11 时代的 1.89% 地板（`logs/11_genfix.log`）。add_1d 的 96.9% 相对**自己的地板**只有 +69pp；跨桶 EM 排序里混着地板排序，A5 的 ρ(PR,EM) 也吃这个混淆。B 用「泄漏率」近似了困难度，但没有把地板写进任何判据。

**M3 全项目没有一次跨任务功能迁移实验。** 「卡片/模因可复用」的操作定义只能是「任务 A 训卡 → 冻结 → 只训目标/输出卡去学任务 B，对比随机初值」。S25 的锚点是**同一个任务** add_3d（`stages/25_single_card_train.py:16-18`），S29 量的是表示相似度而非迁移增益。这是框架的**核心主张**，A 的 P0–P5 与 B 的 8 条方案里一条都没有。

**M4 词表与分隔符卫生被当成常量。** `logs/25_single.log:6`「分隔符 '→' 词表外 ⇒ 单 token `<unk>`(id=129)」；一个只有约 20 个符号的任务用了 V=8192 WordLevel。结构分隔符没有独立 id，意味着 prompt 结构信息被 `<unk>` 吸收且与所有其它未知符号不可分。A、B 都把 tokenizer 视为固定背景。
