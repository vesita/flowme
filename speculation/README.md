# speculation —— 待验证的推测

> **这里放"大胆假设"；`methodology/` 放"小心求证过的结论"。**
> 二者**不许混写**：往 `methodology/` 里写的每一条，都必须能指出**它的实测证据**。

## 为什么要有这个文件夹

今晚反复出现同一类错误：**把推导当结论用**（"中介保真"被当成前提推了三轮实验），
以及**把实测当结论引**（一条"77.4%"被 withdrawn 后仍在旧文档里被引用）。
⇒ **推测与结论住在一起时，两者都会退化。** 所以物理分开。

## 提升规则（speculation → methodology）

一条推测要**毕业**，必须同时满足：

| # | 条件 |
|---|---|
| **1** | **有实测证据**：给出可复现的命令 + 原始输出（不是摘要）|
| **2** | **过了判据门槛**：配对 `Δ ≥ 2×SE` **且 2 seed 同号**（或等价强度的独立出口）|
| **3** | **有免费规则地板对照**：`max_naive`（**含计数类特征**），并报出地板分 |
| **4** | **消融口径正确**：组件消融必须 `retrain-without`；**推理期干预（patching）可替代**，但须说明 |
| **5** | **明确写出它证伪了什么**（否则不知道它约束了什么）|

**不满足 1–3 的，一律留在这里。** 不许"看起来合理"就搬过去。

## 降级规则（methodology → 这里，或作废）

- 实测**不可复现** ⇒ **标"不可复现"并撤回**（今晚已有先例：那条被撤回的百分比）；
- 发现**口径被混杂**（如步数随难度自适应）⇒ **降为推测**，注明混杂项；
- 依据被人为修改过（如"修正后的数字"）⇒ **重算或撤回**。
