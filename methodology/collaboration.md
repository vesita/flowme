# collaboration —— 文档与协作准绳

> 四行格式与引用缩写见 [`README.md`](./README.md)。
> 本项目是**多会话并行**的：同一目录可能有别的会话在写，纪律的目的不是形式，是**避免互相覆盖与重复劳动**。

## 1. 写入边界

### 每个实验 / 每篇笔记只写**自己声明的那几条路径**，边界写进产物文件本身
- **为什么**：边界若只存在脑子里，事后无法对账"谁改了什么"；本项目所有 PREREG / REPORT 都自带"边界"段。
- **怎么用**：开工前在 PREREG 写死「只写 `experiments/<自己>/`、`logs/<自己>_*`、`/tmp`；**不改** `src/`、`training/`、`tests/`、`dev-notes/`、其它 `experiments/`」；收尾时用 `git status --porcelain` 复核并把结果写进 REPORT。
- **证据**：规范（多实验统一执行，含实测复核）＋ `experiments/cumulative_add/PREREG.md:134-136`、`experiments/core_ndb/PREREG.md:88`、`experiments/core_keep/PREREG.md:209`、`experiments/capability_map/REPORT.md:149`（"`git status --porcelain` 无任何已跟踪文件被修改；未执行任何 git 写操作"）。
- **边界/反例**：确实需要改公共文件时**先协商再改**，不要靠"顺手"；改完在 REPORT 里单列一条。

## 2. 写者唯一

### 同一处只有一个写者：**不绕过别人持有的锁**，改用独立文件名写自己的部分
- **为什么**：两处现场 —— ① `src/dtseek/tasks/builtin/__init__.py` 的 3 行注册被另一会话的独占锁（c_63）挡住、**4 次编辑被拒，未绕过策略**，训练/评测改走显式 import 注册，**协议与他人代码均未改**；② `experiments/selection_cards/` 被另一会话**独占声明**（c_62），本代理**以独立文件名写入**。
- **怎么用**：拿不到写权限 ⇒ 不要换工具硬写，改**自己的文件名 / 自己的入口**；被挡住的公共改动记成待办，等锁释放后再补。
- **证据**：实测（两次现场留档）＋ `experiments/selection_cards/results.md:94`、`experiments/selection_cards/results_cand_embed.md:117`。
- **边界/反例**：**"改用独立文件名"只适用于互不冲突的产物**；同一份文件的两半仍要串行，不能靠改名绕开。

### 同一文档只有一个写者；读代码期间文件被别人改过，**行号必须锚定版本（md5）**
- **为什么**：`src/dtseek/tasks/engine.py` 被另一会话从 252 行改成 284 行（新增编码缓存，mtime 14:51）⇒ 不锚版本的话，已写下的 `文件:行` 会**静默错位**，结论看起来有出处、其实指向另一版代码。
- **怎么用**：引用行号时同时记录**文件行数 / md5 / mtime**；发现现场变了就重新定位，并在文里写明"本文结论基于 X 行的当前版本（md5 …）"。**一个会话只写自己那一个文件**（本篇笔记的现场纪律即"只写了本文件"）。
- **证据**：实测（现场变化留档）＋ `dev-notes/17:9-13`、`dev-notes/17:219-225`（F5：旧 docstring 曾与代码相反，本轮被并发改对）。
- **边界/反例**：md5 锚定**只对被引用的文件**做；对整仓做会因为无关文件变动天天失效。

### 他人产物**不代笔、不改写**，只在自己的文件里标注「非本代理改动」以便对账
- **为什么**：代笔会让"这条结论是谁在什么时点下的"无法追溯；对账需要知道哪些数字不是自己跑的。
- **怎么用**：发现别处的产物混进自己的结论范围，就单列一条「**非本代理改动（实测，供对账）**」，写清文件 + mtime + 自己只做过 read/grep；他人留下的待办（如待补的两行注册）原样转交，**不替他完成**。
- **证据**：实测（两处留档）＋ `experiments/select_semantic_joint/REPORT.md:140`、`experiments/compose_ops/results.md:139`、`experiments/selection_cards/results.md:94`。
- **边界/反例**：**对账标注不是免责** —— 拿别人的数字下结论时，证据强度按**那个数字自己的强度**记（单 seed 就写单 seed）。

## 3. Git 纪律

### 子任务**不做任何 git 写操作**（`commit` / `stash` / `checkout` / `restore` / `clean` 一律禁止）
- **为什么**：多个会话共享工作树，任何一次 `stash`/`checkout`/`clean` 都会把别人正在写的东西卷走；提交要有统一的口径与说明。
- **怎么用**：子任务只读 `git status` / `git diff` 用于对账；改动落盘即可，**提交留给主会话统一做**。禁止清单原样写进 PREREG。
- **证据**：规范（PREREG 明文）＋ `experiments/cumulative_add/PREREG.md:137`（"禁止 `git commit/stash/checkout/restore/clean`"）、`experiments/capability_map/REPORT.md:149`（实测：未执行任何 git 写操作）。
- **边界/反例**：⚠️ "**提交由 Lead 做**"这半句**在仓库内找不到出处**（见本目录来源说明与交付报告的「未纳入」），本条只固定"子任务不写 git"这一半。

## 4. 结论的写法（跨文档一致）

### 笔记里的每条结论**自带证据分级**：【事实】/【实测】/【推断】分开标，"哪些是推断"要单独成节
- **为什么**：混标会让读的人把推断当结论用；本项目的做法是**把推断集中列在文末一节**，一眼能看清哪些没测。
- **怎么用**：写笔记时三档标注（读代码带 `文件:行` / 本次跑出来的带原始输出 / 我的解释）；文末加一节「哪些结论是推断（不是实测）」逐条列出。
- **证据**：规范（`dev-notes/17` 的写法已成范式）＋ `dev-notes/17:7-8`（三级证据定义）、`dev-notes/17:675-684`（§8 推断清单，8 条）。
- **边界/反例**：分级**不能替代出处** —— 【实测】也必须给命令与原始输出位置；【事实】必须给 `文件:行`。

### 预注册与结果**分开落盘**：判据在 `PREREG.md`，数字只往 `RESULTS.md` / `REPORT.md` 追加
- **为什么**：判据与数字混在一个文件里，事后无法证明"判据没被数据改过"。
- **怎么用**：PREREG 写落盘时间 + "本文件一旦落盘即为判据来源；后续只允许在 RESULTS 里追加实测数字，**不许回头改这里的阈值**"；REPORT 里给"落盘时间 < 首训时间"的证据。
- **证据**：规范（多实验统一）＋ `experiments/core_keep/PREREG.md:3-4`、`experiments/cumulative_add/PREREG.md:3-4`、`experiments/core_ndb/PREREG.md:3-5`。
- **边界/反例**：判据**可以订正**，但订正要按 [`experiment-design.md`](./experiment-design.md) 的留痕规则走 —— 这与"不许回头改阈值"不冲突，后者指**为过线而改**。
