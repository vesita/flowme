## 2. 仪表自检（**跑前必过**；任一条不过 ⇒ 不许进正式跑）

| # | 检查 | 门槛 |
|---|---|---|
| **N1** | **惰性对照**：把新通路的权重设 0，loss 必须与旧路径**逐位相同**（同批同 RNG 状态） | `max\|Δ\| ≤ 1e-6` |
| **N2** | **输入不是金标**：新通路喂给模型的输入必须**不等于**金标输入 | 不同位置占比 ≥0.5 |
| **N3** | **随机流**：两臂同 seed 的数据序与 RNG 消耗一致 | 逐位 |
| **N4** | **张量契约**：形状/首列（如 BOS）/移位对齐逐条断言 | 必须真 |
| **N5** | **梯度截断**：`lg1.grad_fn is None`、`pred.requires_grad is False`（抓"漏写 `no_grad`"） | 必须真 |
| **N6** | **全局 RNG 不变式**：两臂各走一步后 `torch.get_rng_state()` 逐位相同（抓 dropout 随机流分叉） | 逐位相同 |

## 7. 跑批与产物

- 脚本 `runs_<题>.sh`：**fail-closed 预检**（产物/驱动/选项齐不齐，缺即退出）+ 顺序跑 + **跑后核验**（每 run 必须出 `[RUN-FINAL]`，缺则整批非零退出）。
- 判据表 `stages/NN<m>_<题>_verdict.py`：读 per-run JSON 出判词；★ **必须能用伪造结果逐档驱动真实判词函数**（R48）。
- ★ **输出文件名必须含全部区分维度**（含新开关），否则两臂产物**同名静默覆盖**（本项目踩过）。
- 长跑用 `systemd-run --user --unit=<名> --collect`（抗会话重启；`setsid nohup` 会被 cgroup 杀）。

## 三条硬经验（本模板的全部价值）

1. **判据写死了 ≠ 判据是对的** —— 开跑前**由另一个单元独立读一遍**（`AGENTS.md §2`）。本轮实测：独立复核抓出"n=200 功效不足"与"dropout 随机流分叉"两条，都不是跑出来能看出的。
2. **"改了 ≠ 改上了"** —— 新通路必须能被**惰性对照/假结果**证明真的接上线（N1/N2 与 R48）；自检本身也可能无判别力（本轮 N2 第一次跑就抓到这点）。
3. **事后解释不算证据** —— 归因必须被**直接对照**隔离（本项目两次被自己的控制臂推翻：共享不是机制、压力位置不是原因）。
